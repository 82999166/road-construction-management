# 道路施工承包管理系统

本项目面向道路施工承包业务，提供以**项目数据范围**与**岗位权限**为边界的 PC 超级管理后台和移动端现场工作台。系统覆盖劳务、机械、运输、采购仓储、工程计量、财务成本、现场影像、消息待办与系统设置等业务模块。

## 核心能力

| 业务域 | 已提供能力 |
| --- | --- |
| 权限与后台 | 角色、菜单、操作、字段脱敏、项目/组织范围、授权有效期、审计记录与超级管理员守卫 |
| 采购与仓储 | 固定 12 类采购字典、申请、订单、收货、入库、领用、退库、库存台账、供应商与分次结算 |
| 运输 | 车辆档案、方量换算、GPS 趟次、影像证据编号、服务端异常预警与日报打印 |
| 工程计量与财务 | 申报、审核、结算、收入确认、工程回款、资金流水、成本归集、现金流及项目利润汇总 |
| 现场取证 | 影像上传、S3 归档、OCR 人工复核、项目权限、浏览器相机/定位连接器配置与服务端定位校验 |
| 系统设置 | 外部密钥加密托管、掩码返回、消息模板、配置草稿、校验、发布、版本回滚和审计 |

## 本地验证

在项目根目录执行以下命令：

```bash
pnpm test
pnpm exec tsc --noEmit
pnpm build
```

移动端巧克力主题的关键文字对比度可执行下列命令复核；脚本会在任何色对低于 `4.5:1` 时返回失败状态。

```bash
node /home/ubuntu/contrast-check.mjs
```

## 安全说明

外部服务密钥仅由服务端使用 AES-GCM 加密托管；读取 API 只返回掩码值，客户端与审计快照不应包含明文。请在发布前通过系统设置配置真实企业微信及外部连接器，并使用具备项目/组织范围的真实角色完成端到端复测。
