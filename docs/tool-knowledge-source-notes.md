# 工具知识中心：混凝土材料估算依据

## 外部依据

- 《普通混凝土配合比设计规程》JGJ 55-2011，住建部发布，2011-12-01 实施。公开查阅页：<https://www.codeofchina.com/standard/JGJ55-2011.html>
- 规程明确，普通混凝土配合比设计应满足配制强度、拌合物性能、长期性能和耐久性能要求；应使用工程实际原材料，并进行试配、调整和确定。
- 规程术语中，水胶比为用水量与胶凝材料用量的质量比；胶凝材料由水泥及活性矿物掺合料构成；外加剂掺量相对胶凝材料质量百分比。
- 规程提及普通混凝土干表观密度范围为 2000—2800 kg/m³；质量法计算时，混凝土拌合物假定质量常在 2350—2450 kg/m³范围内并需按实测修正。
- 规程对高强混凝土（强度等级不低于 C60）要求配合比经试验确定；C60—C80 参考水胶比、胶凝材料和砂率也需通过试配确定。

## 产品使用边界

工具中心的 C20、C30、C35、C40、C50、C60 数值必须标示为“可编辑的工程估算参考值”，仅用于材料计划和成本预估。实际下料、采购、施工与质量验收必须优先采用项目试验室签发的配合比通知单，并结合水泥强度、砂石级配与含水率、外加剂、坍落度、泵送、耐久性和现场试配结果调整。

## 税费利润计算口径

税费计算器仅按用户输入的含税单价与税率做数学换算：未税金额 = 含税金额 ÷ (1 + 税率)；税额 = 含税金额 − 未税金额；应纳增值税（简化口径）= 销项税额 − 可抵扣进项税额；税前经营利润 = 未税收入 − 未税成本。该结果不自动判断可抵扣资格、简易计税、附加税、企业所得税、发票合规性或税收优惠，必须由财税人员复核。
