# 运输安全阈值与单次闭环权限修复记录

运输线路的最短运输时间、卸土定位范围及各自的“硬拦截 / 仅提示”开关继续由既有超级管理后台的“运输闭环与安全阈值”组件维护。移动端已移除该系统级配置入口，避免现场人员在运输调度页面修改项目安全策略。

“刷卡发票即完成整车运输闭环”项目级开关已改为服务端超级管理员专属。非超级管理员调用接口会被拒绝；超级管理员可在后台配置。路线保存同样禁止普通运输人员修改既有路线安全阈值或在新路线中设置非默认安全规则，避免绕过后台安全控制。

定向回归通过 41 项，完整发布级门禁通过。正式服务器已采用原子发布，服务和 HTTPS 首页验证正常。

## 入口可见性补充修复

后台运输管理页原先仅在当前项目已存在路线时才渲染“运输闭环与安全阈值”卡片，导致超级管理员在尚未配置路线的项目中无法找到入口。本次改为：只要已选择项目且具备超级管理员配置资格，卡片即固定显示在“运输管理 → 线路配置”之后。

当项目尚无启用路线时，卡片会明确提示先新增装土点、卸土点和运输路线；单次刷卡闭环的项目级开关仍可查看和配置。路线安全阈值在路线创建后再逐条维护。移动端保持隐藏，服务端超级管理员鉴权保持不变。
