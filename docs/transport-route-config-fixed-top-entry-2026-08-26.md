# 运输路线配置固定顶部入口修复

用户在正式 PC 超级管理员后台截图中确认，运输全台账可以正常显示，但“装卸土点与运输路线配置”整体没有出现，导致其内部的“运输闭环与安全阈值”入口无法访问。

根因是 `TransportRouteConfigurationEditor` 被放入车辆台账和运输趟次查询共同的加载/错误条件之内。将其改为运输项目选择器之后的独立固定区域后，只要已选择授权项目，配置入口即会单独加载；台账查询加载、失败、为空或被服务端拒绝时，线路配置不再随之隐藏。

| 验证项 | 结果 |
|---|---|
| 固定入口 | 已位于“运输项目范围”选择器之后、统计和运输台账之前。 |
| 加载提示 | 配置模块独立加载时显示“正在加载装卸土点与运输路线配置…”。 |
| 安全设置 | 配置卡内部继续显示超级管理员专属说明与“运输闭环与安全阈值”摘要入口。 |
| 权限边界 | 移动端未增加系统级配置入口，服务端超级管理员鉴权未改变。 |
| 自动化验证 | 定向 5 项测试及 `pnpm verify:release` 通过。 |
| 正式发布 | 已按 release/current 原子切换发布；服务 active，本机后台路由 HTTP 200，前端分包包含固定入口标记。 |

本次不涉及数据库迁移、数据库写入、业务数据变更或服务器切换。

发布后浏览器可正常打开正式域名，页面标题为“悦信云智管”。沙箱浏览器未携带用户的后台登录会话，因此最终“线路配置”可见性仍应以已登录超级管理员页面刷新后的截图为准。
