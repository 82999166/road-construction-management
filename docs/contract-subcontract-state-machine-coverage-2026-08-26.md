# 合同与分包状态机回归覆盖记录

本次补充了合同、分包包件及分包应付结算单状态机的服务端契约回归测试。测试不连接数据库、不创建业务数据，直接校验路由中状态迁移、项目范围、权限与职责分离规则。

| 业务对象 | 覆盖的关键规则 |
|---|---|
| 外包合同 | 草稿仅可启用或作废；启用后可暂停、到期或关闭；暂停后可恢复、关闭或作废；编辑仅限草稿与暂停状态。 |
| 分包包件 | 草稿到分配、分配到确认；禁止跳过应付结算单直接结算；价格倒挂必须留痕并双岗复核。 |
| 分包付款结算单 | 草稿、提交、审批、已付的顺序迁移；提交人与审批人、审批人与付款人职责分离；封存日期禁止付款。 |
| 财务闭环 | 付款在事务中同步更新包件结算状态并建立财务记录，状态写入保留并发条件。 |

新增 6 项回归测试，定向测试与 `pnpm verify:release` 均通过。该次只增加测试与质量保障代码，不改变现有接口、数据库结构或业务运行逻辑。
