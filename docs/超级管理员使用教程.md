# 悦信云智管道路施工承包管理系统
## 超级管理员详细使用教程

**适用对象：** 正式超级管理员。  
**适用入口：** `https://您的正式域名/admin/login`。  
**核心原则：** 超级管理员可进行全局治理，但每一笔业务数据仍应有项目、人员、状态和审计依据；不要以临时扩权、模拟数据或绕过审批代替正式操作。

> 超级管理员登录入口与普通业务登录入口相互独立。正式本地超级管理员使用已授权的 11 位手机号和口令登录；临时超级管理员入口处于关闭状态时，不能因访问该页面而被重新启用。首次登录若系统提示改密，请先完成改密后进入后台。

---

## 1. 登录、首页与权限边界

### 1.1 正式登录步骤

1. 在电脑浏览器打开 `/admin/login`。
2. 输入正式超级管理员的**已授权手机号**和口令，点击“登录全局管理后台”。
3. 系统在服务端校验账号启用状态、超级管理员角色、密码摘要与失败限流状态；正确后建立 8 小时受签名会话。
4. 如账号要求首次改密，输入当前口令和新口令后进入后台。新口令应至少 12 位，并同时包含字母、数字和符号。
5. 使用结束后，在系统内执行“安全退出”；不要把浏览器保持在公共电脑上。

若连续多次输入错误，系统会暂时限制继续尝试。请等待限制窗口结束，不要反复提交、共享口令或开启临时入口。正式账号无法登录时，优先核对账号状态、手机号、角色与登录入口；外部邮箱认证账号的密码由所属身份服务管理。

### 1.2 后台分区说明

后台左侧菜单按以下治理分区组织。菜单名称和操作按钮可能会随当前账号、已选项目或数据状态显示；服务端始终会再次校验权限，前端显示不等同于授权。

| 分区 | 主要职责 | 常用模块 |
|---|---|---|
| 经营业务 | 总览、合同、施工与经营数据治理 | 经营看板、合同、工程计量、项目经营统计 |
| 资源与现场 | 项目资源、车辆、机械、施工现场与影像 | 组织项目、车辆维护、机械、运输、柴油、现场取证 |
| 业财结算 | 采购、劳务、成本、结算、发票与回款 | 采购仓储、工资、财务、分包应付、车辆/机械结算 |
| 风险与通知 | 消息、通知、风险整改与审计线索 | 消息中心、风险整改、通知渠道、服务号绑定 |
| 平台治理 | 账号、角色、系统设置、备份和审计 | 权限管理、系统设置、配置版本、数据库备份、审计日志 |

## 2. 首次启用顺序

建议按“**组织 → 项目 → 人员 → 角色范围 → 资源主数据 → 业务流程 → 配置连接器 → 真实验收**”的顺序启用。不要先创建业务单据再补项目范围或岗位授权。

| 顺序 | 管理动作 | 完成标准 |
|---|---|---|
| 1 | 维护组织、部门和项目 | 项目有唯一编码、所属组织与有效状态 |
| 2 | 创建或核对人员 | 人员、手机号、本地账号状态和登录终端明确 |
| 3 | 分配岗位、业务模块和项目范围 | 每人只具有实际需要的模块和项目权限，设置有效期 |
| 4 | 维护车辆、机械、供应商、施工队、合同等主数据 | 关键资源状态为启用，归属项目正确 |
| 5 | 配置业务参数与外部能力 | 草稿保存、测试成功、发布后才生效 |
| 6 | 用真实授权账号核验 | 菜单、项目范围、状态操作、打印和审计均正确 |

## 3. 组织、项目、人员与权限管理

### 3.1 组织与项目

在“组织 / 项目”维护集团、公司、项目部、部门、班组及项目层级。新增项目时，应填写项目名称、编码、所属组织、状态和必要的成本归属信息。项目编码必须唯一；停用项目后，不应继续作为新业务单据的可选范围。

有父子关系的项目应先建立上级节点再建立下级节点。调整组织关系前，请先核查该节点下的人员授权、车辆机械、合同和历史业务单据，避免把仍在使用的项目误停用。历史记录保留原始审计，不应通过删除项目清除业务痕迹。

### 3.2 管理人员与本地账号

在“人员与权限”中可以创建普通管理人员的本地账号、维护显示姓名、手机号、启停状态及 PC/手机/双端登录方式。普通账号只能进入服务端已授权的业务工作区，不得访问全局系统设置、审计或跨项目主数据。

创建普通账号后，应立即完成角色和项目范围授权；仅创建账号而未授权时，移动端可能显示“暂无授权项目”，这是保护性空态而不是系统故障。停用账号会阻断该账号后续受保护访问；删除前系统会检查授权、业务和审计关联，关联未清理时应使用停用而不是破坏性删除。

### 3.3 岗位、角色、数据范围与有效期

角色授权应明确选择岗位、适用项目或组织范围、状态和有效期。推荐“一个人一个职责范围”的最小授权方法：施工管理只授予施工相关项目；财务人员只授予财务与结算职责；司机仅使用手机号移动端账号。

| 场景 | 推荐范围 | 注意事项 |
|---|---|---|
| 项目经理 | 指定项目 + 项目管理岗位 | 不应因为部门归属而自动看到其他项目 |
| 运输管理员 | 指定项目 + 运输岗位 | 可见车辆、线路、趟次和结算取决于项目范围 |
| 财务负责人 | 指定项目 + 财务岗位 | 结算、回款、发票和敏感字段仍受服务端限制 |
| 劳资管理员 | 指定项目 + 劳务岗位 | 只能处理相应项目人员、考勤和工资流程 |
| 司机 | 绑定车辆手机号 + 手机端 | 仅使用本人车辆、运费、柴油与消息视图 |

授权保存后，应让被授权人员重新登录或刷新会话，在移动端“我的”核对角色、项目和业务模块。若授权未生效，按“账号启用 → 角色启用 → 授权状态 → 有效期 → 项目/组织范围 → 重新登录”的顺序检查，不能直接放开超级管理员权限。

## 4. 主数据与现场资源管理

### 4.1 车辆、司机与运输线路

车辆档案用于维护车牌、车型、货厢尺寸或方量、司机、手机号、状态和项目范围。司机手机号应与车辆绑定信息一致，避免微信绑定时误绑车牌。变更车牌、司机或手机号前，先检查未完成运输趟次和 NFC 记录。

运输线路配置由超级管理员维护起止点、里程、阶梯运价与安全阈值。线路价格应在启用前复核单位、间隔、起步价和递增规则；已生成趟次会保留当时的运价快照，不应通过修改线路规则回算历史金额。

### 4.2 NFC 写卡与现场刷卡

在“车辆射频写卡管理”中登记写卡器、车辆卡与写卡任务。当前写卡流程为受控人工确认：准备写卡、执行物理写入、确认成功或失败。`准备完成` 不代表实体卡已写入，只有确认后才是有效卡状态。

装土/卸土现场刷卡会校验卡号、车辆、司机、项目和趟次状态。重复、乱序、未绑定或已停用卡不会直接改变趟次，而是保留人工复核信息。超级管理员应定期查看异常，而不是通过手工修改前端状态跳过闭环。

### 4.3 机械、柴油与容量风险

机械档案区分自有、外租及租赁计价方式，并关联司机、维修、油料、进退场和成本。柴油管理须维护资源、供油方式、指导价、油量、金额、表数、小票影像以及是否扣减运输运费。

对车辆和机械的核定油箱容量应如实维护。容量、价格异常和领用频率风险由服务端规则检查；未维护容量的资源会被提示不能参与相应合理性检测。风险整改应选择真实责任人和期限，逾期升级计划只在已保存并启用后运行。

## 5. 经营、采购、劳务与结算管理

### 5.1 施工日报与工程计量

施工日报记录施工日期、区域、天气、工作内容、安全事项、问题和进度。日报通常从草稿开始，依次提交、审核、驳回或锁定。锁定后不能无审计修改；如需修正，应按系统允许的退回或重新办理流程处理。

工程计量和项目收方用于记录工程量、位置、计量方法、证据和复核意见。收方或计量达到审核、收入确认、锁定等状态后，金额与状态不能由浏览器直接回退。回款登记必须关联真实可收款金额，系统会限制超过应收余额的录入。

### 5.2 采购与库存

采购流程包括申请、审批、订单、收货、入库、领用、退库、库存及供应商结算。日常采购使用固定分类字典；管理员可维护供应商和采购主数据，但不应在业务端随意更改既定分类。

采购结算前核对订单、收货、已结算与剩余余额。对于已完成收货或结算的记录，应使用系统提供的受控状态操作，不能删除历史订单或修改前端金额绕过结算约束。

### 5.3 劳务、考勤与工资

劳务管理覆盖人员档案、实名状态、班组、进退场、证照、考勤、工资核算、工资条、会计审核和发放。身份证、银行卡等敏感字段会按角色脱敏显示；完整信息只向必要岗位和受控用途开放。

工资一般按“草稿 → 提交 → 会计审核 → 发放 / 作废”的状态流转办理。工资条导出和打印使用当前筛选的真实服务端数据，状态和人员类型显示为中文；银行卡等高敏感字段仍遵循单独的权限约束。

### 5.4 合同、分包与车辆/机械结算

合同管理负责合同草稿、审核、签订、履约和归档。分包应付管理关联施工队、包件、工作项、批次、应付、付款和发票信息。车辆结算和机械付款按当前筛选的项目、期间、资源和状态统计，并保留结算日期与支付方式的中文业务展示。

已结算或已付款的业务记录应遵循终态保护。发生错误时，优先使用系统允许的冲销、作废或审计修正步骤；不要删除附件、篡改金额或把状态改回草稿。

## 6. 财务、发票、打印与导出

### 6.1 财务与发票

财务台账记录收入、费用、成本归集、现金流、发票和每日会计日结。录入时应选择正确项目、发生日期、类别、金额、来源单据和证据；OCR 结果只作辅助提取，必须经人工复核后再用于记账。

每日会计日结会按项目和中国业务日固化收入、费用、发票及快照信息。已封存日期如需反结账，须填写授权原因并保留版本与审计记录；不能直接修改历史流水抵消差异。

### 6.2 当前筛选导出与 A4 打印

车辆、机械、运输、劳务工资、采购仓储、分包结算及柴油等模块均采用统一规则：先在顶部设置项目、日期、资源、状态等筛选，再执行“导出当前筛选”或“打印当前筛选明细与汇总”。

| 操作 | 输出范围 | 使用要点 |
|---|---|---|
| 导出当前筛选 | 当前服务端真实查询结果 | 导出前再次核对项目、期间、车牌/机械/施工队等条件 |
| 打印当前筛选明细与汇总 | 独立 A4 横向文档，逐条明细 + 末行合计 | 浏览器调用打印即可；不打印整个后台页面 |
| 运输日汇总 | 当前项目、当日真实运单和汇总 | 移动端用于查看；需要正式文件时由授权管理端核对打印 |
| 柴油汇总 | 当前日期、资源、供油方式、供应商等筛选结果 | 作废记录保留追溯，但不计入有效油量与金额汇总 |

打印或导出为空时，首先检查筛选范围和账号项目权限；不要通过清除项目限制获取其他项目数据。保存 PDF 后，请用真实业务记录核验条数、时间、明细和末行合计。

## 7. 系统设置、外部配置与通知

### 7.1 配置草稿、测试、发布与回滚

进入“系统设置”后，按“新建或编辑草稿 → 填写非敏感值与加密密钥 → 保存 → 测试 → 发布 → 业务复核”的顺序操作。配置清单、历史版本与回滚入口默认收纳在折叠区，便于集中治理。

| 配置类别 | 常见内容 | 特别要求 |
|---|---|---|
| 服务号与消息推送 | AppID、AppSecret、Token、EncodingAESKey、回调地址、模板映射 | 密钥加密托管；先做服务端测试再发布 |
| 短信 | 阿里云或腾讯云服务商、签名、模板与开关 | 未配置或模板未审核时不得声称已送达 |
| OSS 照片存储 | 地域、标准 Bucket 公网 Endpoint、Bucket、对象前缀、RAM 密钥 | 使用标准 Bucket Endpoint；“测试 OSS 连接”只读探测对象元数据 |
| OCR / 地图等连接器 | 服务商凭据与业务开关 | 仅服务端调用，浏览器不读取密钥 |
| 业务参数 | 指导价、安全阈值、通知开关等 | 变更前评估是否影响新业务单据与历史快照 |

敏感值保存后仅显示掩码。留空通常表示保留已保存密钥；不要为了确认内容而反复覆盖或在截图中暴露密钥。若测试失败，先停用或保持草稿，检查 Endpoint、RAM 权限、模板审核、域名白名单和审计摘要后再修复。

### 7.2 通知与消息中心

系统包含站内消息及可配置的服务号、短信等通知通道。通知是否送达取决于已发布配置、模板可用性、收件人绑定和平台规则。关键业务以数据库成功写入为准；外部通知失败会保留最小化审计，不会回滚已经成功的业务单据。

管理员查看消息时，应先进入消息详情，再根据业务深链打开原始单据。不要把消息点击直接视为业务办理完成。司机刷卡、运输、柴油、审批等场景请按真实收件人绑定状态验收。

## 8. OSS 照片与现场证据

照片和票据以私有对象存储方式保存，系统数据库只保存对象引用与业务关联。超级管理员在“系统设置 → 阿里云 OSS 照片存储”填写地域、标准 Bucket 公网 Endpoint、Bucket、对象前缀和受限 RAM 密钥后，依次保存、测试并发布。

“测试 OSS 连接”不会创建、覆盖或删除业务照片，仅检查保留探测对象的元数据读取能力。上传成功后，使用已授权业务账号打开受控预览；确认历史附件、非影像文件与原对象前缀不受影响。不要把 Bucket 设为公共读，或在前端代码中配置 RAM 密钥。

## 9. 审计、备份与问题处理

### 9.1 审计工作台

“审计”用于查看配置发布、组织授权、关键业务与敏感数据访问的受控摘要。审计时间按中国标准时间显示；日志只展示必要的模块、动作、目的和数量，不展示原始口令、密钥、身份证、银行卡或定位原文。

出现争议时，先记录单据编号、项目、操作时间、操作者和审计记录，再按业务状态机处理。不得删除审计记录、直接修改数据库掩盖操作，或把完整日志导出给无关人员。

### 9.2 数据库备份

数据库备份属于超级管理员和服务器管理员共同负责的高风险操作。执行前确认存储空间、备份范围、加密和访问控制；备份完成后要进行离线验证。代码检查点不能替代数据库备份，检查点回滚也不会还原数据库业务数据或系统设置。

### 9.3 故障排查顺序

| 问题 | 首先检查 | 处理原则 |
|---|---|---|
| 用户看不到模块 | 账号状态、角色、有效期、项目/组织范围、重新登录 | 不直接提升为超级管理员 |
| 页面无数据 | 项目与日期筛选、服务端项目范围、状态条件 | 不跨项目查询或修改历史范围 |
| 状态不能操作 | 当前单据状态、角色职责、终态锁定 | 按作废、退回或冲销流程处理 |
| 打印/导出不符 | 当前筛选、真实明细、末行汇总、浏览器 PDF 设置 | 用真实已授权记录验收 |
| 照片或通知失败 | 设置是否已发布、连接测试、模板/绑定/权限、审计摘要 | 不在聊天或日志中传递密钥 |

## 10. 超级管理员每日与每月例行清单

| 频率 | 建议动作 |
|---|---|
| 每日 | 核对风险整改、运输异常、柴油异常、待审核工资/计量、未读重要消息 |
| 每周 | 检查人员授权有效期、停用离场账号、抽查项目范围、核验一次备份可读性 |
| 每月 | 审阅成本、车辆/机械/分包结算、发票与回款；使用当前筛选导出或打印归档 |
| 配置变更后 | 完成草稿、测试、发布、审计和真实业务复核；失败时先停用并保留证据 |
| 代码发布后 | 核验 HTTPS 首页、登录、后台、一个移动业务深链、权限范围及关键打印 |
