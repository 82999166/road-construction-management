# 发布核验记录

## 移动消息页展示层安全提示批次

正式 HTTPS 深链 `/mobile/messages` 已于本批原子切换后打开。首帧显示中文“正在同步业务消息…”加载提示，静态资源未见加载异常；认证降级的最终状态仍需在会话初始化完成后复核。

后续核验确认，未登录状态稳定显示“消息中心”“登录后可查看与您岗位、审批和业务单据相关的通知”“重新加载”和“前往登录页”，不展示业务数据或原始错误文本。`/mobile` 首帧也正常显示中文“正在同步您的岗位工作台…”加载提示，未见静态资源加载异常。

`/mobile` 在认证初始化完成后稳定显示“悦信云智管移动工作台”“请先通过企业统一身份登录，系统将按您的岗位展示可办理业务”“重新加载”和“前往登录页”。该未登录核验不读取或展示任何工作台、考勤或项目业务数据。

独立考勤深链 `/mobile/attendance` 在初始化后稳定显示“上下班考勤”“请使用企业统一身份进入已授权项目完成每日打卡”“重新加载”和“前往登录页”。该未登录核验不读取或展示考勤、定位或项目业务数据。
