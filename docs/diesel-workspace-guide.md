# 柴油管理四栏目使用说明

入口：管理后台 → 柴油管理。柴油工作区只处理真实加油、柴油金额、油价、供应商采购和对应票据，不再展开全项目资金账本、综合发票、会计日结、授权反结账或财税资料。

## 四个栏目

| 栏目 | 内容与操作 |
| --- | --- |
| 加油台账 | 保留原车辆／机械加油登记、加油员、供油方式、升数、单价快照、金额、加油时间、票据照片、价格预警及运输扣油。日期默认北京时间当天，可按车辆、机械、供油方式、资源和供应商筛选。 |
| 油价与预警 | 原指导价维护、指导价生效记录、现金油价波动阈值；价格历史按状态和关键词查询。 |
| 供应商对账 | 按顶部“供应商对账月份”读取真实月度柴油采购汇总，并按供应商和异常状态筛选。显示升数、金额、加权价格、价格区间、原始凭证和异常数量。 |
| 柴油票据 | 按同一加油日期、车辆／机械和供应商范围查看真实柴油凭证，区分原始加油小票与正式发票的关联核验。没有真实关联时不以供应商名称、金额或备注猜测发票。 |

## 汇总、打印与导出

长列表分页显示，每页可选20、50或100条。分页只改变屏幕显示，不截断当前筛选的全部汇总、打印或导出结果。加油明细使用原柴油打印模板；油价和供应商对账复用统一标准报表预览。

作废记录不能再次计入有效柴油金额。供应商整体均价按总金额除以总升数计算，不能直接平均各供应商的均价。

供应商月度对账与加油台账的自定义日期范围分别展示，请不要将两种范围混为一谈。项目部指导价按真实生效日期匹配，不按统计月份重新计算历史加油金额。

## 财务和税务归属

“前往财务发票管理”进入现有财务管理的发票栏目，并保留选定项目。全项目资金账本在“财务管理 → 收支账本”，会计封账在“财务管理 → 日结对账”，纳税主体、项目税务和专业辅助资料在“财务管理 → 财税交接”。

柴油当天汇总不等于全项目会计日结。原始加油小票不等于正式发票；显示税额或票据图片不表示已完成抵扣、申报或缴税。

## 原业务规则不变

本次分类改造不改写历史加油金额、项目部指导价快照、现金实际单价、运输扣油、结算锁定、权限或审计记录。登记加油及维护指导价继续调用原服务端流程。
