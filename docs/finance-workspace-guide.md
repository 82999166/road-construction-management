# 财务管理七栏目使用说明

入口：管理后台 → 财务管理。进入后默认打开“财务总览”，顶部保留项目、会计月份、刷新统计和报表打印。此次调整为界面分类和读取优化，不迁移数据库，不改变历史金额、审核状态、付款凭证、权限或封账规则。

## 栏目与操作

| 栏目 | 主要用途 |
| --- | --- |
| 财务总览 | 查看资金收入、支出、发票、应收应付、现金净流和收支差额。业务来源摘要按需展开，快捷按钮进入结算、成本和发票。 |
| 收支账本 | 按收支方向、资金细项、结算状态、来源、关键词查询；明细分页，状态与细项汇总按需展开。 |
| 结算收付 | “待付款／待收补款”核对服务端余额；“付款记录／凭证”查看真实付款与凭证。可进入原结算资金窗口，付款记录默认只读，不推断新的付款授权。 |
| 成本分析 | “成本分类／小类目分析”切换；按分类下钻原始业务明细。柴油完整登记及供应商对账仍在柴油管理。 |
| 发票管理 | 按状态和发票号码／往来单位筛选，查看分页台账和当前筛选的有效发票金额、税额；打印和导出全部筛选结果。 |
| 日结对账 | “日结封存”办理原封账、授权反结账、快照与装订页；“月度内部对账”按实际付款月份核对和导出。 |
| 财税交接 | “资料／交接批次／专业复核”分类；纳税主体、项目税务档案为按需展开配置。保留人工辅助资料、快照、回执和原专业复核，不自动申报。 |

## 日期和金额口径

会计月份用于月度财务、成本、发票和月度付款对账；结算余额另有“截至日”，日结另有“封存日期”。所有默认业务日期按北京时间生成。

成本分类明细仍默认当天，同时提供“当天”和“查看本月”。上方月份汇总与下方明细日期范围均明确显示，切换日期后请核对当前范围。

应收金额、待收车辆补款、业务成本、应付和实际支付不是同一种口径，不能互相替代或重复相加。收支差额不等于经营净利润。月度对账为系统内部付款台账核对，不代表已经完成银行自动对账。

## 分页、打印与导出

明细每页可选择20、50或100条；改变筛选、项目或月份会重置页码，记录缩短时自动回到有效页。

当前页只是显示切片。资金账本、发票、成本、付款对账的汇总、打印、CSV和Excel均使用全部筛选结果，不只打印第一页。付款凭证批打仍仅处理有效付款凭证，冲正记录不计入有效实际收付。

“报表打印”集中提供资金总账、发票、成本分类、小类目、支付账号账单、付款凭证及日结对账入口。报表读取未完成时显示等待或重试，不展示旧项目、旧期间的打印数据。

## 未保存与权限保护

切换财务栏目保留已经打开过的子页面状态，隐藏页面不继续发起业务查询。

财税资料有未保存内容时，切换项目或月份需要确认。取消切换保留草稿；确认切换后按新项目、月份重建录入作用域，不将旧资料提交给新项目。付款窗口打开时禁止切换财务项目或月份。实际支付继续使用原受控凭证流程，并由服务端重新校验项目权限和余额。
