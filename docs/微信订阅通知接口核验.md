# 微信订阅通知接口核验

核验日期：2026-08-13

## 真实故障结论

当前已发布的私有模板标识 `wYecuEUJcdxtQBryEJ-ARwWY1LgGg00X98l2_ZbBz3w` 在微信私有模板库中显示标题为“订阅模板消息”。系统使用传统服务号模板消息接口 `/cgi-bin/message/template/send` 向已激活绑定账号投递时，微信真实返回 `40037`，即 `invalid template_id`。因此，群发失败不是收件人姓名、岗位或内部账户编号造成的，而是当前模板和发送接口/权限未形成可下发组合。

## 官方接口边界

微信官方传统模板消息接口要求使用可下发的模板 ID；`40037` 表示模板 ID 不合法。[1] 新版“订阅通知”要求用户在图文或认证服务号网页中主动订阅，然后开发者通过 `sendNewSubscribeMsg` 下发；一次性订阅只允许对应的一次下发，长期订阅仅对限定公共服务领域开放。[2] 订阅通知的官方发送路径为 `/cgi-bin/message/subscribe/bizsend`。[3]

系统已加入传统模板接口返回 `40037` 时对订阅通知接口的受控回退，但当前微信私有模板仍返回 `40037`，说明需要在微信平台选用并发布实际可下发的合规模板，或完成该订阅模板对应的用户主动订阅流程。系统不得伪造订阅同意或将投递失败误记为“已通知”。

## 系统处理

群发审计会把真实微信错误码保存为脱敏失败原因。成功投递后，收件人需要在系统内点击“确认收到”；后台只在有实际确认时间时将其计入已确认，避免把发送尝试或已读误认为到位。
