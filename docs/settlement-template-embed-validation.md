# 计量模板嵌入验证记录

更新时间：2026-08-19

土石方结算模板与附属工程结算模板均可通过项目静态资源地址独立打开，页面包含其各自的可编辑计算字段、计算按钮和打印按钮。此前页面内显示“Not found”的原因是引用了已失效的静态资源版本；替换为当前上传资源后，若未允许同源访问，模板依赖的浏览器本地存储初始化会使内嵌框架呈现空白。

当前工程结算与分包工作区使用受限框架配置 `allow-same-origin allow-scripts allow-forms allow-modals`，使两份用户提供的静态模板能在页面内完成其本地计算与自动保存初始化。每个模板同时保留“新窗口打开”入口，作为嵌入环境异常时的独立使用兜底。模板不调用项目业务接口，不能读取、修改或替代施工队、分包批次、工程量、财务结算和审计数据。
