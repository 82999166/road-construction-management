# 超级管理后台工具知识按需加载记录

超级管理后台的“工具知识”原先由 `AdminPage` 内联承载其工作区说明及三个测算/知识子组件的加载声明。该工作区不属于运营概览、组织、权限或业务主数据的首屏关键路径，现已拆为独立的 `AdminMeasurementToolsPanel` 懒加载边界。

进入“工具知识”菜单后，后台保留原有路径、标题、测算工具、知识库、打印能力和全局超级管理员路由守卫。独立面板会继续按需加载施工辅助计算、结算模板计算和公铁知识库；弱网等待期间展示“正在加载工程测算工具”提示，未修改任何 tRPC 查询、写入、权限或业务状态。

| 构建指标 | 优化前 | 优化后 | 变化 |
|---|---:|---:|---:|
| `AdminPage` 原始分包 | 1,137.36 KB | 1,131.19 KB | -6.17 KB |
| `AdminPage` gzip 分包 | 158.98 KB | 158.10 KB | -0.88 KB |
| 工具知识独立分包 | 内联于后台页面 | 8,788 B | 仅访问菜单后下载 |

新增后台分包静态回归，并复跑工具知识既有组件测试和 `pnpm verify:release`。类型检查、全量测试、两类构建、迁移卫生及生产依赖审计均通过。后台主分包仍然较大；更大范围的各业务工作区拆分需要在后续独立改造中逐一迁移状态、查询和对话框，不能以简单移动代码代替。
