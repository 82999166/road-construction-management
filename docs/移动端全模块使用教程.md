# 悦信云智管道路施工承包管理系统
## 移动端详细使用教程

**适用对象：** 项目管理人员、施工人员、劳资人员、机械管理员、运输管理员、采购人员、财务人员、分包管理人员与司机。  
**建议设备：** 具备网络、浏览器、相机权限且系统时间正确的 Android 或 iPhone。  
**移动端入口：** `https://您的正式域名/mobile`。

> 移动端显示的模块、项目、按钮和数据，均由服务端按“账号状态 + 岗位 + 授权有效期 + 组织/项目范围 + 单据状态”裁决。看不到某个卡片或出现“暂无授权项目”时，不要借用其他账号；请联系超级管理员核对授权范围。

---

## 1. 通用使用规则

### 1.1 登录与进入工作台

普通管理人员和司机使用已开通的 11 位手机号账号登录；已完成服务号绑定的账号可按后台配置使用微信授权登录。登录成功后，系统将进入“移动工作台”，卡片只显示您获授权的真实业务模块。

| 情况 | 正确处理 |
|---|---|
| 账号提示错误或被限制 | 检查手机号和口令；多次失败后等待限流窗口结束，不要反复提交 |
| 显示“暂无授权项目” | 联系超级管理员核查账号启用状态、岗位、项目范围、有效期；重新登录后再查看 |
| 页面长时间加载或网络变化 | 使用页面“重新加载”或“重新登录”入口；确认手机网络后重试 |
| 不属于本人的项目或单据 | 不尝试录入、审核或修改；系统会拒绝跨项目访问 |

### 1.2 项目、日期和时间

进入业务模块后，先确认顶部或表单中的**项目**。系统用户可见日期和打印生成时间统一按中国标准时间展示；新建表单的日期/时间默认取手机设备系统时间。请在使用前把手机“自动设置日期和时间”打开，避免凌晨录入落入错误业务日。

业务时间存储为系统统一时间戳，因此编辑历史记录时请以页面显示的中国标准时间为准，不要自行把日期再加减 8 小时。

### 1.3 防止重复录入

保存、提交、刷卡、收货、付款、审核等按钮被点击后，请等待提示结果再继续操作。网络卡顿时不要连续点击同一按钮，也不要刷新后重复录入。运输刷卡和部分业务操作带服务端幂等保护，但用户仍应先在列表搜索单号、日期或车辆，确认是否已生成记录。

### 1.4 拍照、附件与 OCR

需要上传照片时，请允许浏览器使用相机或从相册选择 JPG/PNG。照片会关联项目、业务来源与拍摄时间；权限不足、相机被后台停用或文件不符合限制时，页面会提示原因。OCR 识别只能协助读取票据文字，**不得直接替代人工核对金额、日期、单位或发票信息**。

### 1.5 消息、状态与打印

业务状态以中文显示，例如“草稿”“待审核”“已确认”“已结算”“已作废”。状态按钮只在您有岗位权限且单据处于允许流转状态时显示；无法操作不代表页面出错，可能是项目范围、角色或终态锁定正在保护历史数据。

移动端的运输日汇总、施工、计量和财务汇总可生成独立 A4 横向打印文档。打印内容仅包含当前项目、当前日期或当前筛选条件下的真实服务端数据；不要使用浏览器“打印整个页面”代替系统打印入口。

## 2. 移动工作台与底部导航

打开 `/mobile` 后，先等待授权与项目资料加载。工作台提供业务卡片、待办概览、消息入口和“我的”入口；不同岗位可见卡片不同。

| 入口 | 作用 | 使用要点 |
|---|---|---|
| 工作台 | 进入已授权业务模块 | 先核对当前项目；卡片缺失优先检查后台授权 |
| 消息 | 查看站内通知、未读数和业务深链 | 先阅读消息详情，再点击业务内容进入原单据 |
| 我的 | 查看姓名、岗位、项目范围、账户安全 | 项目范围与岗位显示异常时截图并联系管理员 |
| 安全退出 | 清除当前设备会话 | 在公共设备、离职、换手机或异常登录时使用 |

## 3. 考勤管理

**入口：** `/mobile/attendance`。  
**适用岗位：** 获授权的劳资、项目管理或考勤人员。

### 3.1 上下班打卡

1. 选择已授权项目和当日人员信息。
2. 在“上班打卡”或“下班打卡”区域核对当前状态。
3. 根据现场要求允许定位或补充备注。
4. 点击保存后等待“成功”提示，再返回列表确认记录已出现。

上班和下班状态由服务端顺序校验。未完成上班打卡时，下班打卡会被拒绝；已经成功打卡后再次提交会被保护性拦截或提示，避免重复出勤记录。

### 3.2 考勤台账

按项目、人员和日期查看出勤天数、工时与备注。管理员在后台可查看汇总；移动端人员只应查看授权项目和职责范围内的数据。若后台与手机端显示不一致，记录打卡日期、人员、项目和当前状态后联系管理员核查，不要删除或重复补打。

## 4. 施工日报与现场管理

**入口：** `/mobile/construction`。  
**用途：** 记录当日施工进度、作业区、天气、人员/机械投入、安全事项、质量问题和现场说明。

### 4.1 新建日报

1. 选择项目，确认日报日期为手机当天日期；如补录历史日报，应手工选择真实施工日期。
2. 填写作业区域、施工内容、进度数据、安全与质量事项、问题和处理建议。
3. 如现场要求取证，上传对应照片并核对项目、时间和业务关联。
4. 先保存草稿进行复核；内容完整后按权限提交审核。

日报通常按“草稿 → 已提交 → 已审核 / 已退回 → 已锁定”流转。已审核或锁定的日报不能直接修改；如被退回，应根据退回意见修改后再提交。

### 4.2 日报汇总打印

在已选项目和日期范围内使用“打印汇总”入口。打印单据使用独立 A4 文档，不会打印手机导航或无关页面内容。保存 PDF 后核对项目、日期、日报条数、状态与汇总字段。

## 5. 劳务与工资

**入口：** `/mobile/labor`。  
**适用岗位：** 劳资管理员、会计、财务负责人和获得授权的项目管理人员。

### 5.1 人员与实名资料

可查看授权项目内人员、班组、实名状态、进退场记录和证照。身份证、银行卡等敏感字段会根据岗位脱敏；看不到完整信息时不要要求他人截图或导出，应由有授权的岗位在受控流程中处理。

### 5.2 工时、工资条和状态流转

按照项目和工资期间查看考勤汇总、工资计算和工资条。工资状态通常经历草稿、提交、会计审核、发放或作废等受控步骤。各岗位只会看到自己职责范围内的操作：劳资人员整理并提交，会计审核，财务负责人办理发放或受控作废。

已审核、已发放或作废记录不能通过修改浏览器页面回退。发现人员、出勤或金额错误时，按退回、作废或重新办理流程处理，并保留原因和审计。

## 6. 机械管理

**入口：** `/mobile/machinery`。  
**用途：** 管理机械台账、租赁规则、成本、维修、进退场和月度结算。

### 6.1 机械台账与成本录入

选择项目后查看本项目机械。根据权限可登记机械名称、来源（自有/外租）、司机、状态、计价方式、维修或成本事项。涉及费用时应核对发生时间、金额、来源凭证和所属项目；油料、维修、加班、进退场等类别要按真实业务选择。

机械计价方式可包括月租、日租、小时、台班等。系统依据已保存规则计算或汇总，用户不能通过前端直接覆盖历史结算快照。

### 6.2 月度结算

按项目、机械和期间查看成本和付款结算。提交或确认前，核对计费方式、数量、单价、金额和结算状态。已结算记录受终态保护；需要修正时联系有权限的结算岗位，按审计流程处理。

## 7. 渣土运输与司机管理

**入口：** `/mobile/transport`。  
**适用岗位：** 运输管理员、现场管理员、调度人员及授权项目管理人员。

### 7.1 先处理发票闭环入口

运输页面在选择项目后，顶部优先显示：

| 操作 | 用途 | 注意事项 |
|---|---|---|
| 刷 NFC 发票 | 读取运输卡并按服务端规则校验车辆、项目、趟次和闭环状态 | 保持设备稳定；重复、未绑定、停用或乱序刷卡会进入人工复核，不会强行完成趟次 |
| 拍照车牌发票 | 通过相机采集车牌/票据关联信息 | 确认相机权限、项目与车牌；OCR 结果须人工核对 |
| 运输线路 | 查看已授权项目的路线、里程和运价依据 | 线路和阈值由超级管理员维护，历史趟次保留原计算快照 |

### 7.2 录入运输趟次

1. 选择项目、车辆、司机、线路或起止点。
2. 核对装土时间、卸土时间、里程、方量/重量等真实信息。
3. 必要时补充现场影像、备注和异常说明。
4. 保存草稿或提交；列表中确认单号、车辆、金额和状态。

运输流程通常为“草稿 → 已提交 → 已核验 → 已结算”，并可按规则作废。运费、方量和价格由服务端规则与历史快照计算；不要手工改写金额或为跳过卸土而伪造刷卡。特殊“刷卡发票即完成闭环”仅在超级管理员已发布的运输配置允许时生效，装土间隔和异常规则仍会校验。

### 7.3 装卸刷卡与异常处理

正常顺序为装土刷卡后再卸土刷卡。网络重传、重复刷卡、未绑卡、车辆停用、项目不符或顺序错误不会造成重复运输记录；页面会显示中文校验结论，必要时交由管理员人工复核。

### 7.4 日汇总与详情

按日期查看趟数、方量、运费和异常。点击运单卡片可进入详情，核对路线、司机、刷卡轨迹、影像和状态。使用“打印日汇总”会生成该项目与日期的独立 A4 横向汇总，实际保存 PDF 前请核对逐条运单和合计。

## 8. 柴油管理

**入口：** `/mobile/diesel`。  
**用途：** 记录车辆和机械的柴油领用、现金加油、指导价、票据、表数及运输扣款关联。

### 8.1 登记柴油领用

1. 选择项目和资源（车辆或机械），确认当前资源处于有效状态。
2. 加油时间默认采用手机系统当前时间；补录时选择真实发生时间。
3. 选择供油方式，例如项目部供油或加油站现金加油。
4. 填写油量、单价、金额、加油机表数、供应商和必要备注。
5. 现金加油上传真实小票影像；如需扣减运费，核对关联运输趟次。
6. 点击保存后等待结果，返回列表检查资源、日期、油量、金额和状态。

系统会根据指导价、资源容量、时间间隔和规则提示异常。异常提示不等于可忽略，需核对真实票据和油量；作废记录保留审计追溯，但不计入有效油量和金额汇总。

### 8.2 查询与打印

在筛选区按项目、日期、车牌、机械、供油方式、资源类型或供应商查询。汇总与打印均以同一筛选结果计算。保存 PDF 后请核对有效记录数、作废追溯、油量、金额、表数与末行合计。

## 9. 采购仓储

**入口：** `/mobile/purchasing`。  
**用途：** 办理采购申请、订单、收货、入库、领用、退库、库存与供应商相关业务。

### 9.1 采购申请与订单

1. 选择项目和固定采购分类，填写物料、规格、数量、用途和申请说明。
2. 提交前核对项目、数量、预算或审批要求。
3. 申请批准后，由有权限人员创建或确认采购订单。
4. 收货时填写真实收货数量、日期、凭证和差异说明。

订单与申请状态以中文显示，未知内部值会以“待处理”保护性展示。未批准申请、未收货订单或已结算订单均会受到服务端状态约束。

### 9.2 库存操作

办理入库、领用或退库时，先选择授权项目、库存物料和数量。系统按真实库存和项目范围校验，不能通过负数、跨项目或重复提交绕过。查看库存时，注意库存余额是查询时刻的服务端结果；离线状态下不要继续提交收发操作。

## 10. 工程计量与项目收方

**入口：** `/mobile/measurement`。  
**用途：** 工程量申报、项目收方、审核、收入确认与回款登记。

### 10.1 收方与计量申报

1. 选择项目和业务期间，期间默认使用中国业务月份。
2. 填写工程部位、工程量、计量方法、位置、说明和关联证据。
3. 如使用照片或 OCR，先核对结果后再保存。
4. 保存草稿后提交审核；退回时根据意见修改并再次提交。

常见流转为“草稿 → 已提交 → 已审核 → 已锁定”，也可能退回或驳回。锁定后的记录不能任意改写工程量或证据。项目收方日期默认使用手机设备日期，补录必须如实选择现场日期。

### 10.2 回款与汇总打印

在收入确认满足条件后登记真实回款，金额不能超过剩余应收。使用“打印汇总”前确认当前项目、期间、计量状态和回款范围；生成的独立 A4 文档按中国时区显示日期和生成时间。

## 11. 合同与分包管理

### 11.1 合同

**入口：** `/mobile/contract`。合同页面用于查看已授权项目的合同、相对方、金额、期间、履约与状态。移动端以查询和受控操作为主；合同签订、归档、变更或终态处理应按后台授权与审计要求办理。

合同达到审批、签订或归档状态后，不要通过新建重复合同替代变更流程。发现合同日期、金额或相对方错误时，向合同管理人员发起受控修改或版本办理。

### 11.2 分包与应付

**入口：** `/mobile/subcontract`。选择项目后可查看施工队、包件、工作项、结算批次、应付、付款和发票状态。批次、付款与票据状态以中文业务标签显示；未知值为保护性中文提示，不代表用户可自行修改状态。

新增或确认分包结算前，请核对施工队、包件、工作内容、数量、单价、累计已付和剩余应付。已付款或已结算记录受终态保护；移动端不能凭页面隐藏/显示跨越付款授权。

## 12. 财务与发票

**入口：** `/mobile/finance`。  
**用途：** 查看或办理已授权项目的收入、费用、成本、发票、现金流、日结和受控调整。

### 12.1 财务流水与发票

选择项目和期间后查看汇总和明细。录入收入或费用时，要核对发生日期、收支方向、类别、金额、来源单据、往来单位和证据。发票登记应填写真实发票类型、号码、日期、金额、税额与状态；作废、红冲或冲销需要保留业务原因与审计。

系统以中文展示票据类型和状态。OCR 识别内容不得直接作为付款或记账依据；必须将实物票据与页面字段逐项核对。

### 12.2 财务汇总打印

点击“打印汇总”后，系统使用当前受控项目和期间数据生成独立 A4 横向文档。打印前确认筛选范围，打印后核对收入、费用、净额、发票和明细条数。页面显示时间和打印生成时间均按中国标准时间展示。

## 13. 水印取证与影像查看

**入口：** `/mobile/evidence`。  
**用途：** 施工、运输、采购、计量、财务等业务的现场照片、票据与水印证据采集。

1. 从关联业务页面进入，或选择项目和业务来源。
2. 使用手机后置相机拍摄或选择原始图片；保持照片清晰、票据信息完整。
3. 如项目要求定位，允许浏览器定位并确认现场位置；未能获取定位时按页面提示处理。
4. 填写说明后上传，等待受控存储返回结果。
5. 打开预览确认图像、项目、时间和关联单据正确。

影像预览使用受控授权链接，不能把链接转发给未授权人员。OSS 配置、对象前缀与 RAM 密钥由超级管理员在后台维护；移动端不显示也不应索取这些密钥。

## 14. 消息中心

**入口：** `/mobile/messages`。  
**用途：** 查看站内业务提醒、安全事件、审批、运输、柴油、工资、权限和系统通知。

### 14.1 正确阅读消息

1. 打开消息列表，优先查看未读和时间较新的消息。
2. 点击消息先进入**消息详情**，阅读类型、摘要、到达时间和处理提示。
3. 如消息包含业务深链，再点击内容进入对应运单、日报、申请、工资条或配置页面。
4. 在业务页面按实际权限处理，不要因收到消息就假定自己拥有审核权限。

通知时间按中国标准时间展示。外部服务号或短信是否收到，取决于后台发布的渠道、模板、平台审核与收件人绑定；站内消息可用于保留处理线索，但不等同于对外短信或服务号已送达。

## 15. 我的与账户安全

**入口：** `/mobile/profile`。  
**用途：** 查看账号身份、岗位中文名称、数据范围、项目授权、绑定状态与账户安全入口。

请定期核对姓名、手机号、岗位、项目范围和账户状态是否与实际工作一致。发现岗位代码、范围或账号异常时，不要自行修改历史业务；将页面信息和发生时间反馈给超级管理员。需要换手机、离职、发现异常登录或结束公共设备使用时，执行“安全退出”。

正式本地账号可通过受控“修改密码”流程变更口令；旧口令和新口令仅在 HTTPS 请求中提交给服务端校验，不应写在便签、截图或群聊中。

## 16. 司机专用入口与服务号绑定

**司机入口：** `/driver-portal`。  
**绑定入口：** `/driver-wechat-bind`（通常由服务号菜单或自动回复链接进入）。

司机应使用车辆台账登记的手机号账号登录，先绑定本人车辆和微信，再查看本人运费、趟次、柴油扣款、已付/未付费用、日汇总和消息。绑定时手机号必须与车辆档案一致；车牌或手机号不匹配、账号停用、重复绑定都会被保护性拒绝。

| 项目 | 司机可查看 | 司机不应操作 |
|---|---|---|
| 运输 | 本人授权车辆的趟次、状态、日汇总、运费 | 跨车辆、跨项目结算或改写运价 |
| 柴油 | 本人关联车辆的柴油扣款与明细 | 修改指导价、容量规则或他人领用 |
| 消息 | 本人可见的业务与刷卡提醒 | 查看项目财务、人员或管理员审计 |
| 微信绑定 | 本人与已登记车辆的授权绑定 | 用他人手机号或车牌建立绑定 |

## 17. 常见问题与现场验收清单

| 问题 | 优先检查 | 正确做法 |
|---|---|---|
| 找不到模块 | 岗位、项目范围、有效期、重新登录 | 联系超级管理员配置，不借用账号 |
| 保存失败 | 网络、必填项、项目、当前单据状态 | 记录提示和时间，确认列表后再重试 |
| 打印为空 | 当前筛选、授权项目、日期范围、浏览器 PDF 设置 | 先核对真实列表和末行汇总 |
| 加油时间不对 | 手机自动时间、录入日期、历史补录 | 修正设备时间后重新核对；不改写历史时间戳 |
| NFC 刷卡异常 | 卡状态、车辆、司机、项目、刷卡顺序 | 保留异常记录，交管理员复核 |
| 消息未收到 | 站内消息、服务号绑定、渠道发布、模板审核 | 不伪造成功；查看消息与审计线索 |
| 照片上传失败 | 相机权限、网络、文件格式、项目和后台 OSS 状态 | 不发送密钥；联系管理员检查设置和测试结果 |

每个岗位首次上线时，建议在**已授权真实项目**完成一次“登录 → 选择项目 → 查看现有记录 → 新增一笔真实允许业务 → 查看状态/消息 → 打印或导出（如适用）”的验收。真实 PDF、外部通知、OSS 图片预览、NFC 实体卡与现场定位必须由现场授权人员实际操作确认，系统不应以模拟数据代替。
