# 运输 NFC 双设备闭环核验记录

## 核验结论

运输 NFC 双设备闭环已由服务端状态机实现并具备定向回归覆盖。装土点读卡设备首次刷卡仅在设备、地点、项目、现场管理员、车辆射频卡、车辆状态、路线和运价均有效时创建唯一在途票据；同车再次在装土设备刷卡会被拒绝。卸土点第二次刷卡只可关闭相同项目、相同车辆、相同路线卸土点的未完成在途票据。

| 控制项 | 核验结果 |
|---|---|
| 设备与地点 | 读卡设备须登记、启用、绑定项目和装卸地点。 |
| 现场身份 | 地点指定管理员或运输/项目负责人方可刷卡。 |
| 卡与车辆 | 卡 UID 指纹必须绑定启用车辆，且车辆处于可调度状态。 |
| 唯一在途 | 使用 NFC 在途键和车辆在途唯一键，重复装土刷卡受拒绝。 |
| 卸土闭环 | 必须存在同一车辆的在途票据且卸土点匹配；条件更新防止并发重复关闭。 |
| 取证与安全 | 两端设备、地点、管理员、时间和卡 UID 指纹进入受控事件与审计；卸土仍受最短运输时间和地理围栏规则保护。 |
| 移动深链 | 仅解析签名令牌并委托相同服务端双设备校验，不接收原始 UID。 |

## 验证

已运行 `pnpm check` 与 `server/transport-nfc-dual-device.test.ts`。类型检查通过，定向回归 3 项通过。该核验未创建任何业务运输记录或模拟现场刷卡数据。
