# 柴油重复录入防护与移动运输安全设置发布记录

本次正式发布同时完成两项移动端受控改进：柴油加油录入的短时间防重复保护，以及仅超级管理员可见的运输安全设置入口。两项均保持服务端权限和项目范围校验为最终边界，未迁移数据库、未修改业务数据。

| 功能 | 实现与边界 |
|---|---|
| 柴油短时间防重 | 服务端在同一事务内检查同项目、同车辆或机械、同供油方式、相同加油升数且加油时间相差不超过 5 分钟的有效记录；命中后以冲突错误拒绝写入，不创建柴油记录、机械成本记录或审计重复项。 |
| 移动端重复提醒 | 登记窗口根据最近柴油记录提前识别同资源、同油量、相近时间的重复项，显示原记录编号并禁用保存；用户调整时间或升数后可重新判断。服务端仍会拦截并发、刷新、重试等绕过前端的请求。 |
| 移动运输安全设置 | 移动运输首页在项目范围选择后仅向超级管理员显示“超级管理员设置 → 运输闭环与安全阈值”卡片；组件按需加载。普通运输管理员不显示入口，保存接口仍由服务端超级管理员鉴权。 |

定向柴油服务端/移动端测试与移动运输安全设置测试均通过，随后执行 `pnpm verify:release`，类型检查、全量测试、前端构建、自建服务器构建、迁移卫生及生产依赖审计均通过。正式服务器按 release/current 原子切换发布，历史前端分包已保留，应用服务 active，正式 HTTPS 首页和后台路由均返回 HTTP 200。

发布脚本首次因前端完整性检查的提示文本不一致而自动回滚，未切换正式版本；修正脚本校验文本后重新执行并成功切换。该过程未触及数据库或业务记录。
