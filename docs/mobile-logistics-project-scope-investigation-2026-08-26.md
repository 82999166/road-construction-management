# 移动后勤项目范围核验与发布记录

针对手机端后勤管理显示“暂无授权项目”的反馈，已在正式主机对目标本地管理账号执行一次性只读诊断。诊断脚本仅从运行中的应用进程读取已有数据库连接，并输出去标识化的授权汇总；脚本执行后立即删除，未修改账号、岗位、项目、部门、权限、数据库或业务数据。

| 核验维度 | 结果 |
|---|---|
| 账号状态 | 已启用。 |
| 有效岗位 | 存在有效的直接项目岗位授权。 |
| 项目范围 | 直接关联项目仍为有效项目，不是归档项目。 |
| 采购操作权限 | 存在用户专属采购操作授权，覆盖读取和办理所需动作。 |
| 采购部门范围 | 未配置采购部门范围；当前系统设计允许“直接项目岗位 + 用户专属采购权限”形成受控项目范围，不会扩展到其他项目。 |

现有服务端范围规则可以基于上述交集返回该项目。为避免网络瞬断、旧会话或请求失败被错误渲染为“暂无授权项目”，移动采购页已增强如下行为：项目范围查询在重新挂载时主动刷新、失败后有限重试；查询失败与真实无项目范围分别显示；两种空态均提供“重新获取授权项目”按钮。该改动不放宽服务端项目或操作权限。

已通过移动采购定向 4 项回归和完整 `pnpm verify:release`；正式服务器已按 `release/current` 原子切换发布，服务 active，正式首页与移动采购路由均返回 HTTP 200。仍需该账号在手机端强制刷新后点击“重新获取授权项目”完成最后真实界面验收。
