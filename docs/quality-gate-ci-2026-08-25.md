# 质量门禁与持续集成记录

## 覆盖范围

项目的 GitHub `Quality Gate` 工作流现在在推送至 `main` 以及面向 `main` 的拉取请求中，执行锁定依赖安装、类型检查、迁移卫生检查、全量回归测试、标准生产构建、自建服务器构建和生产依赖审计。

| 门禁 | 执行命令 | 目的 |
|---|---|---|
| 类型检查 | `pnpm check` | 阻止 TypeScript 类型错误进入主分支。 |
| 迁移卫生 | `pnpm db:check` | 验证迁移文件与迁移日志一致。 |
| 全量测试 | `pnpm test` | 执行业务、权限和安全回归。 |
| 标准构建 | `pnpm build` | 验证标准生产构建链路。 |
| 自建服务器构建 | `pnpm build:self-host` | 验证 CommonJS 自建服务器包及备份运行时脚本归档。 |
| 生产依赖审计 | `pnpm audit:prod` | 检查生产依赖漏洞阈值。 |

## 本地验证

2026-08-25 已在项目工作区运行 `pnpm verify:release`。类型检查、全量测试、标准构建、自建服务器构建、迁移卫生检查和生产依赖审计均通过；生产依赖审计结果为 critical、high、moderate、low 均为 0。自建服务器构建会继续将完整备份与离线验证脚本归档到运行包。

该工作流不包含生产部署、数据库写入或密钥读取步骤；正式发布仍使用既有的受控原子发布流程。
