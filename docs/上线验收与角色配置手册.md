# 道路施工承包管理系统：上线验收与角色配置手册

本文档面向超级管理员、项目经理、财务负责人和各业务岗位。系统以**组织—项目—岗位—数据范围—授权有效期**为访问控制主线；在完成项目与人员授权前，业务页面会明确显示“暂无授权项目”，而不会回退到无范围的数据列表。

| 验收维度 | 当前实现 | 管理动作 |
| --- | --- | --- |
| 组织与项目 | 组织、项目、标段与作业面构成数据归属层级 | 在“超级管理后台 → 组织”维护组织与项目，避免无项目归属的业务数据 |
| 岗位与数据范围 | 菜单、路由与服务端查询同时校验岗位、项目范围和授权有效期 | 在“超级管理后台 → 权限”分配角色、项目范围与有效期 |
| 审计与配置 | 关键新建、状态流转、结算和配置发布均记录审计摘要 | 在“超级管理后台 → 审计 / 设置”核验操作链路与配置版本 |
| 移动工作台 | 菜单由服务端根据有效岗位和项目范围动态返回 | 用各岗位真实账号登录 `/mobile`，确认无越权菜单 |

## 1. 上线前基础配置

先建立组织节点、项目、标段和成本中心，再将人员加入相应组织。项目经理负责配置本项目的业务归属；超级管理员负责角色、菜单、数据范围和授权有效期；财务负责人或会计负责资金、回款、结算与成本确认。普通人员不应以 PC 超级管理后台作为业务入口，系统会将其引导回移动工作台。

> **重要原则：** 前端隐藏菜单不是权限边界。所有项目范围、状态流转、金额上限和敏感信息过滤均由服务端再次校验。

| 岗位示例 | 建议业务范围 | 关键验收点 |
| --- | --- | --- |
| 劳务负责人 / 会计 | 劳务台账、实名制、考勤、工资核算、工资统计与工资条 | 仅能访问被授权项目；身份证、手机号和银行卡全程脱敏；工资金额与审核状态以服务端计算为准 |
| 采购负责人 / 仓储人员 | 采购申请、订单、入库、领用、退库和库存 | 仅能访问被授权项目；固定采购分类不可绕过；库存余额由流水汇总 |
| 运输负责人 / 司机 | 车辆、运价、趟次、运输日报 | 司机仅能处理本人车辆；趟次自动保留运价与定位快照 |
| 计量负责人 / 会计 | 工程计量申报、审核、收入确认、回款 | 已确认申报不可回退；回款仅能登记在已结算收入且不超过可回款余额 |
| 财务负责人 / 出纳 | 日常开支、资金流水、采购结算、项目成本 | 金额、期间和项目范围均由服务端校验；现金流与收入确认分口径展示 |

## 2. 核心业务验收路径

采购、运输、计量和财务均使用状态机和不可变流水建立闭环。请使用**真实项目、真实角色和真实金额**进行复测；不要在生产项目中插入演示数据，也不要通过浏览器绕过状态操作。

| 模块 | 业务闭环 | 预期结果 |
| --- | --- | --- |
| 采购仓储 | 申请 → 批准 → 生成订单 → 确认 → 收货 → 分次结算 → 入库/领用/退库 | 采购订单仅可由已批准申请生成；仅已收货订单允许分次结算；超出待结算余额会被拒绝 |
| 运输管理 | 车辆/运价 → 趟次录入 → GPS 与现场影像关联 → 核验 → 结算 → 日报 | 运价、理论方量和运费由服务端快照计算；缺少影像、GPS、收工时间或存在异常方量、里程时会提示预警 |
| 工程计量 | 申报 → 复核 → 会计审核 → 收入确认 → 回款登记 | 核定金额必须填写；已确认/已结算状态不可回退；累计回款不得超过已确认收入 |
| 财务成本 | 日常开支、资金流水、采购结算、计量收入与工程回款 → 项目/期间汇总 | 收入确认、实际回款、应收余额、现金流入、现金流出和净现金流分别展示，避免重复计入 |
| 劳务工资 | 已实名人员 → 真实考勤 → 工资核算 → 提交 → 会计审核 → 工资统计/打印 | 人员敏感信息保持脱敏；工资金额由服务端汇总；已审核单据不支持客户端回退或篡改 |
| 现场资料 | 水印取证 → 项目、时间与定位元数据 → OCR 人工复核 → 业务单据关联 | 影像不可跨项目关联；OCR 结果需人工复核后再作为业务凭据使用 |

## 3. 移动端复测步骤

移动端入口为 `/mobile`。登录后先检查“我的业务”仅显示该账号在当前有效授权内可访问的菜单；再进入劳务工资、采购仓储、运输调度、计量结算、财务成本和水印取证逐项执行下列操作。若账号尚未配置项目，页面应显示“暂无授权项目”，这属于正确的权限降级行为。全程仅使用已授权项目中已经存在的真实人员、真实考勤和真实业务单据，**不得为验收目的创建模拟人员、模拟考勤、模拟工资或演示单据**。

| 页面 | 真实数据复测动作 | 预期结果 |
| --- | --- | --- |
| 劳务台账 | 用劳务负责人账号选择一个已授权项目，查看一名已存在人员的实名、班组、进退场与证照状态 | 仅展示当前项目人员；身份证、手机号、银行卡均以脱敏格式显示；无项目权限时不返回人员清单 |
| 考勤管理 | 选择系统中已有的真实人员和已发生的工作日，核对出勤天数、工时与备注；仅在确有更正授权时提交真实纠正记录 | 考勤记录受项目范围校验；非授权人员和跨项目人员不可读写；工时与出勤值通过服务端规则校验 |
| 工资统计与打印 | 在已有的真实工资期间查看应发、实发、待审核汇总与工资条；使用打印入口核对项目、期间和生成时间抬头 | 汇总金额与工资条使用服务器返回口径；敏感字段不出现在打印视图；已会计审核工资条不可回退为草稿 |
| 采购仓储 | 选择已收货订单，登记部分付款，再登记余额付款 | 页面展示服务端返回的待结算余额；超额金额被拒绝；财务流水与采购订单可追溯 |
| 运输调度 | 在允许定位的手机上录入趟次，附带现场影像编号并保存 | GPS、影像编号和原始参数进入趟次快照；缺失字段显示服务端预警，但不篡改历史运价 |
| 计量结算 | 对已结算计量申报登记一笔回款 | 回款后应收余额减少；超过剩余应收金额的输入被拒绝 |
| 财务成本 | 选择相同项目与期间，核对收入确认、实际回款和现金流指标 | 实际现金流入不应把未到款收入重复计入；打印报表应使用服务器返回的汇总口径 |
| 水印取证 | 拍摄或上传真实现场材料并完成项目关联 | 影像展示项目、时间、定位和人工复核状态；不得关联到其他项目单据 |

## 5. 上线后首日复核

上线后，请由超级管理员用一个项目经理账号、一个劳务负责人账号、一个采购或仓储账号、一个司机账号、一个计量或会计账号和一个财务账号分别登录。每个账号应只看到被分配的项目和模块。劳务负责人应先复核既有真实人员、真实考勤和已有工资期间的统计与打印口径；随后由项目经理在正式项目中完成一条采购申请、一条运输趟次、一条计量申报和一条现场影像取证；财务人员再完成一笔采购结算和一笔工程回款。最后核对审计日志、项目成本汇总、应收余额和现金流是否可追溯至原始单据。

如需启用企业微信、地图、OCR 或外部业务 API，请先在“超级管理后台 → 设置”中创建相应配置草稿并通过安全发布流程启用。密钥仅在服务端受控保存和掩码展示，禁止将密钥写入移动端、浏览器存储或项目源码。
