# 施工、运输、机械、采购仓储工作区说明

本次改造将原来的长页面拆成独立栏目。菜单位置不变；请先选择项目，再进入相应栏目。列表分页只影响屏幕显示，打印与导出采用当前栏目完整筛选结果，不只输出当前页。

## 一、施工管理

| 栏目     | 查看与操作                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------------- |
| 日报台账 | 按日期、提交管理员、状态、关键词查询；新建、详情、现场照片和原权限允许的编辑操作。                       |
| 审核待办 | 集中查看待审核日报，默认不限制业务日期，避免漏掉历史待办；审核、退回等操作仍由服务端检查权限。           |
| 现场问题 | 查看日报中原有的质量、协调、安全记录及审核回复。没有独立整改依据时，不将“已回复”或“已归档”当作“已整改”。 |
| 归档查询 | 查看已归档日报及原审核人、审核时间与回复，保留历史资料。                                                 |

“查看详情 / 照片”集中展示完整施工内容、安全情况、问题、审核结果和照片。照片直接站内预览，不要求下载。

打印、导出超过250份时显示覆盖全部记录的分批清单。逐批操作即可继续输出后续记录；未生成的批次不会标记完成。“已送交打印”表示已经打开打印文档，不代表打印机一定出纸。

## 二、运输管理

| 栏目           | 查看与操作                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------ |
| 运单台账       | 日常运单查询、完整筛选统计、详情、原始装土/卸土证据和现有业务操作。                        |
| 核验与异常     | 按真实运输闭环及异常依据核验；存在异常时走相应处理，不跳过最短运输时间或位置校验。         |
| 运费结算       | 从真实已核验运单进入结算，查看运费、柴油及资产扣款、净应付、实际付款、待收补款和剩余余额。 |
| 合同运价       | 独立维护运输计价规则，不再与日常运单堆在同一页面。                                         |
| 场站路线与终端 | 装卸土点、运输路线、安全校验设置、读卡终端及RFID写卡管理。                                 |

运单的“运输完成 / 已核验”和结算单的“已付款”不是同一个状态。只有实际付款记录和受控凭证才能证明付款；历史运单标记已结算但没有真实结算关联时，必须核对原始资料，不自动推定付清或重付。

装土与卸土照片在授权范围内直接预览。刷卡/拍照发票与刷卡/拍照卸土的既有互通流程保持不变。

## 三、机械管理

| 栏目     | 查看与操作                                                                                   |
| -------- | -------------------------------------------------------------------------------------------- |
| 机械档案 | 一台机械一条主档，查看合同、老板、驾驶员、操作员、状态及历史有效费用；档案不按创建日期隐藏。 |
| 司机加班 | 按机械、日期和状态查看加班小时、小时单价、金额和驾驶员；保留原提交、审核与结算权限。         |
| 费用统计 | 按所选月份、机械和状态查看真实成本明细、全筛选汇总及打印导出。                               |
| 租金结算 | 月租金快照、结算及分笔付款台账；列表、汇总和打印采用一致的月份及机械筛选。                   |

单机详情分为“基本、加班、费用、维保采购、结算”五个分区。合同月租和日租折算、原始加班、独立成本、配件采购、租金应付与实际付款分别显示，不能直接相加当成同一笔支出。月租按自然日折算只供查看，不擅自重算已经审核的历史结算。

## 四、采购仓储

| 栏目       | 查看与操作                                                                         |
| ---------- | ---------------------------------------------------------------------------------- |
| 采购总览   | 看申请、订单、验收、库存和付款的真实状态，区分业务金额与实际付款。                 |
| 申请与订单 | 申请审批、从申请下单及订单详情；筛选采购者、上传人、类别、日期、发票情况等。       |
| 验收与入库 | 维护订单实际验收依据，关联入库凭证与真实入库记录，避免只改“已收货”而没有入库记录。 |
| 库存与收发 | 查看入库、领用、退库和累计库存余额；流水日期筛选不截断当前累计库存快照。           |
| 结算与票据 | 查看实际采购付款、未付余额、原采购证据及正式发票的真实关联。                       |
| 供应商     | 查看及维护供应商档案，不因业务日期筛选隐藏历史供应商。                             |

订单“已关闭”不自动代表已经付款。实际采购付款按真实财务流水核对；小票或采购照片不自动当成正式发票或付款凭证。

“业务详情、附件和操作”保留原采购数量、单价、关联资产、上传管理员和证据入口。原半A4报销详单保持一份半张A4，金额大写按本订单真实金额自动生成；标准A4表格打印用于完整筛选结果。

旧Excel模板和历史导入入口继续保留，导入先预检，仍保留原条数限制和确认写入流程；导入草稿或补传附件不自动通过审批。

## 五、共同规则

- 各栏目分别显示相关内容和必要查询，低频合同、路线、终端配置不再堆在日常台账下面。
- 保留现有项目范围、账号角色、操作权限与服务端校验；隐藏操作按钮不代替服务端权限检查。
- 表单存在未保存资料时，切项目需要先保存或关闭；业务模块内部的栏目切换尽量保留输入。离开页面的提示不代表已经保存。
- 打印、导出只针对当前栏目实际筛选，不输出完整账户、附件签名地址或内部存储路径。
- 旧工资、结算、付款、运单、维修、库存和审计历史不删除、不批量更改。历史库存估值保留旧规则标识，新业务按新规则记录，不追溯重写历史金额。
