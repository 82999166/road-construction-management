# 微信服务号模板消息接口要点

来源：[微信官方文档：模板消息](https://developers.weixin.qq.com/doc/offiaccount/Message_Management/Template_Message_Interface.html)。

微信服务号模板消息用于向用户发送重要服务通知，只能用于符合要求的服务场景，不支持广告或营销类骚扰消息。认证服务号需要先申请并获得模板消息能力，设置服务类目后可从公共模板库选用模板；账号下可同时使用的模板数量有限。系统接入时必须使用服务号的模板 ID，并按模板正文中 `{{字段.DATA}}` 的字段名提交对应 `data` 参数。

本项目在对接时应遵循以下规则：模板字段必须与微信后台已选模板字段名完全一致；系统测试消息必须明确标注为“系统测试”，不得伪造采购、运输、工资、合同等真实业务事件；投递失败只能写入通知审计，不得回滚主业务。微信返回 `47003` 时通常表示模板 `data` 中某个字段值不符合字段类型约束，需要根据模板正文里的 `thing`、`const`、`time`、`amount`、`character_string` 等字段类型修正映射和值格式。
