# 道路施工承包管理系统：部署与外部连接器配置指南

本文档供**超级管理员**在上线、配置外部能力、进行故障止损和组织真实数据验收时使用。系统采用托管运行环境；保存一个已验证的检查点后会自动发布当前代码版本。业务数据与配置数据不会由检查点回滚，因此每次发布前都应先执行本指南中的配置和验收步骤。

> **安全边界：** 密钥、令牌、密码和 Webhook 地址必须以“加密托管”方式保存。后台列表、配置历史与审计日志只显示掩码或摘要，不能把原始值粘贴到移动端、浏览器本地存储、项目源码或截图中。当前系统**不提供配置导出或快照下载接口**；任何读取路径都只能返回非敏感值或敏感项的掩码，密文仅留在服务端数据库中供受控测试与回滚使用。

## 1. 上线前准备

先确认生产组织、项目、人员和岗位已准备完毕。项目经理只应管理其项目范围内的数据；超级管理员负责组织、角色、授权有效期和系统配置；财务负责人负责结算、成本和回款。请使用正式账号完成验收，**不要为了验证而向生产项目写入演示数据**。

| 检查项 | 操作 | 通过标准 |
| --- | --- | --- |
| 组织与项目 | 在“超级管理后台 → 组织 / 项目”维护正式节点 | 每个业务项目均归属组织与成本中心，项目编码不重复 |
| 角色与范围 | 在“超级管理后台 → 权限”绑定岗位、项目、组织和有效期 | 各账号只可见授权模块和项目；过期授权不再生效 |
| 审计 | 在“超级管理后台 → 审计”查看最近操作 | 角色分配、配置草稿、发布、停用、回滚和关键业务动作均有摘要记录 |
| 业务入口 | 用业务岗位账号登录 `/mobile` | 无授权时显示“暂无授权项目”，不得显示全量业务数据 |

## 2. 系统设置的标准发布流程

所有运行参数都通过“超级管理后台 → 设置”管理。配置项先以草稿保存；确认格式后再发布。发布时版本号递增，并保存仅供服务端恢复的历史快照。对涉及外部网络的项目，应使用“测试”操作验证连通性；对于密钥类项目，测试只检查服务端可安全解密，不会把原值返回浏览器。

| 步骤 | 管理动作 | 要点 |
| --- | --- | --- |
| 1 | 新建配置草稿 | 填写分类、配置键、显示名称和业务说明；配置键使用大写字母、数字、下划线、冒号、点或短横线 |
| 2 | 选择安全等级 | API 密钥、令牌、密码、私钥和 Webhook 必须勾选“加密托管” |
| 3 | 保存草稿 | 草稿可修改，不会改变当前已发布版本的版本号 |
| 4 | 测试配置 | 对企业微信 Webhook 发起不含业务数据的连通性消息；对一般 HTTPS 地址执行受限可达性检查 |
| 5 | 发布 | 通过验证后发布；记录版本、操作人和审计摘要 |
| 6 | 复核 | 用对应业务账号验证功能；不要通过开发者工具查看或复制密钥 |

若外部服务异常，应优先使用“停用”使该配置停止生效，保留历史和审计证据；确认原因后再修复并发布。若需要恢复到历史版本，选择对应版本执行“回滚”。回滚也会生成新版本和审计记录。

## 3. 受支持的配置键与连接器

以下配置键是当前版本的标准约定。默认情况下，现场影像使用浏览器文件选择或手机后置相机能力，浏览器定位为可选；管理员可在发布配置后启用必填定位或整体停用某项能力。

| 配置键 | 分类建议 | 是否加密托管 | 允许值 / 格式 | 运行效果 |
| --- | --- | --- | --- | --- |
| `WECHAT_WORK_WEBHOOK` | `notification` | 是 | 企业微信机器人官方 HTTPS Webhook，且包含 `key` 参数 | 发布后可用于系统通知；测试只发送无业务数据的连通性文本 |
| `EVIDENCE_CAMERA_PROVIDER` | `connector` | 否 | `browser` 或 `disabled` | `browser` 允许移动端拍摄/选择 JPG、PNG；`disabled` 时服务端拒绝上传 |
| `EVIDENCE_LOCATION_PROVIDER` | `connector` | 否 | `browser` 或 `disabled` | `browser` 允许移动端请求浏览器定位；`disabled` 时不请求浏览器定位 |
| `EVIDENCE_LOCATION_REQUIRED` | `connector` | 否 | `true` 或 `false` | 仅在定位提供方为 `browser` 时生效；`true` 时服务端拒绝无经纬度影像 |
| `MAP_API_KEY` | `external_api` | 是 | 对应地图服务供应商的密钥 | 仅作为受控地图连接器密钥保存；不得由移动端直接读取 |
| `OCR_API_TOKEN` | `external_api` | 是 | OCR / 识别服务令牌 | 仅供服务端识别流程使用；识别结果仍需人工复核 |
| `MESSAGE_TEMPLATE_*` | `message_template` | 否 | 经审批的业务通知文案 | 作为非敏感业务参数保存；建议在文案中禁止包含身份证号、银行卡号等敏感字段 |

> **当前能力说明：** 现场取证仅支持受后台开关控制的浏览器相机/文件选择与浏览器定位。未配置上述三项时，系统按 `browser / browser / false` 的安全默认值运行。系统不承诺调用未配置的原生相机 SDK、私有定位服务或任意第三方 Webhook。

## 4. 企业微信机器人配置

企业微信通知采用机器人 Webhook。系统只接受官方域名 `qyapi.weixin.qq.com`、路径 `/cgi-bin/webhook/send` 且包含 `key` 查询参数的地址，避免系统设置被用作任意外部请求工具。

1. 在企业微信群中创建机器人，并从企业微信后台复制机器人 Webhook。
2. 打开“超级管理后台 → 设置”，新建 `WECHAT_WORK_WEBHOOK` 草稿，勾选“加密托管”。
3. 保存草稿后执行“测试”。测试消息不含项目、人员、金额或单据信息。
4. 确认群内收到测试消息后发布配置。
5. 在业务环境触发一条不敏感测试通知，并在审计日志中检查配置测试与发送结果。
6. 如更换机器人或群聊，先停用旧配置，再保存、测试和发布新配置。

## 5. 现场取证与定位验收

移动端“水印取证”将影像字节归档到对象存储，数据库仅保留文件键、项目、业务关联、拍摄时间、定位、水印元数据和 OCR 复核结果。上传、查看和 OCR 均受项目范围与岗位授权控制。OCR 是辅助提取，不得直接作为记账或结算依据。

| 场景 | 配置 | 手机端操作 | 预期结果 |
| --- | --- | --- | --- |
| 常规取证 | 不配置连接器，或发布 `browser / browser / false` | 选项目，拍摄/选择 JPG 或 PNG，可选读取定位后上传 | 成功归档，影像显示项目、时间和已读取的定位 |
| 强制定位 | 发布 `EVIDENCE_LOCATION_REQUIRED=true` | 不读取定位直接上传 | 移动端禁用提交，且即使绕过前端，服务端也拒绝无定位上传 |
| 临时停用相机 | 发布 `EVIDENCE_CAMERA_PROVIDER=disabled` | 打开水印取证并尝试选择文件 | 选择与提交入口被禁用，服务端同样拒绝上传 |
| OCR 复核 | 上传真实票据或验收单影像后主动点击识别 | 查看结果并由业务人员校对 | 结果始终标记为“需人工复核”，不得自动入账 |

## 6. 真实数据复测与故障处理

上线后的首次验证应在一个已授权的真实项目中进行，涉及采购、运输、计量、财务和现场资料的每个岗位至少一次。建议按下表完成，并保存业务单据编号和审计记录以便追溯。

| 模块 | 真实数据复测 | 服务端保护点 |
| --- | --- | --- |
| 采购仓储 | 申请、批准、订单、收货、部分结算、余额结算及库存收发 | 固定分类、项目范围、收货前禁结算、超额结算拒绝 |
| 运输调度 | 录入一条有定位和影像编号的真实趟次 | 方量/运费快照、司机与项目范围、缺少影像/定位/收工时间的异常预警 |
| 工程计量 | 完成申报、审核、收入确认和一笔回款 | 已确认状态不可回退、回款不得超过剩余应收 |
| 财务成本 | 核对项目与期间汇总及打印报表 | 收入确认、实际回款、应收、现金流入/出分口径统计，避免重复计入 |
| 现场资料 | 上传一张有明确项目和时间的材料 | 项目范围、文件签名、8MB 限制、对象存储归档、OCR 人工复核 |

发生异常时，应先记录访问账号、项目、时间、页面操作和审计记录 ID；随后在设置中心查看配置是否已发布、是否已停用以及测试结果。不要在浏览器控制台、日志截图或即时通信中传递密钥原文。若问题涉及人员权限，先检查授权有效期、组织范围和项目范围，而不是绕过权限临时扩权。

## 7. 发布前最后检查

每次代码或配置变更完成后，超级管理员应确认自动化测试、类型检查和生产构建均通过；再以桌面与手机尺寸检查关键页面。当前项目采用自动发布机制，保存通过验证的检查点即会发布代码。发布后请保留检查点版本号，并在管理界面观察运行状态；若代码需要回退，应使用检查点回滚，配置和业务数据则按其各自的审计流程处理。
