# 微信服务号新版消息与事件推送要点（2026-08-23）

本笔记仅保存外部官方文档要点，用于排查“服务号发送 `绑定` 未自动回复”的配置路径与生效条件，不包含任何系统密钥、OpenID、Token 或用户隐私数据。

## 官方入口迁移

微信官方《服务号「开发接口管理」升级说明》说明，旧路径 **微信服务号平台 → 服务号 → 设置与开发 → 开发接口管理** 已迁移到 **微信开发者平台 → 我的业务 → 服务号**。其中“服务器配置”迁移到 **服务号 → 基础信息 → 域名与消息推送配置**。

| 功能 | 新版路径 | 关键说明 |
| --- | --- | --- |
| 服务器配置 / 消息推送 | 微信开发者平台 → 我的业务 → 服务号 → 基础信息 → 域名与消息推送配置 | 启用后，用户发送的消息将转发至该地址，网站中设置的自动回复和自定义菜单将失效。 |
| API IP 白名单 | 服务号 → 基础信息 → 开发密钥 | 调用服务号接口时，请求 IP 必须加入白名单，否则微信 API 会返回 40164。 |

来源：微信官方文档《服务号「开发接口管理」升级说明》：https://developers.weixin.qq.com/doc/service/guide/dev/migration.html

## 消息与事件推送配置

微信官方《服务号消息与事件推送介绍》说明，服务号消息推送可在 **微信开发者平台 → 我的业务 → 服务号 → 消息与事件推送** 或新版基础信息页的 **域名与消息推送配置** 中配置。开发者需要填写以下字段：

| 字段 | 官方含义 | 本系统对应 |
| --- | --- | --- |
| URL | 接收微信消息和事件的接口 URL，必须以 `http://` 或 `https://` 开头，支持 80/443 端口。 | `https://yx.maomaoyx.com/api/official-account/messages` |
| Token | 用于签名处理，微信 GET/POST 请求中的 `signature` 会与 Token、timestamp、nonce 共同校验。 | 系统后台“域名与消息推送配置”中加密保存的 Token。 |
| EncodingAESKey | 消息体加解密密钥，可手动填写或随机生成。 | 系统后台保留加密托管入口；明文模式下不参与当前验签。 |
| 消息加解密方式 | 明文模式、兼容模式、安全模式。选择兼容/安全模式需实现加解密。 | 当前按明文模式处理。 |
| 数据格式 | 服务号消息体格式仅支持 XML。 | 当前只处理 XML 明文消息。 |

来源：微信官方文档《消息与事件推送介绍》：https://developers.weixin.qq.com/doc/service/guide/dev/push/

## 用户发消息后的 POST 行为

微信官方《接收普通消息》说明，当普通微信用户向公众账号/服务号发消息时，微信服务器会将 XML 数据包以 **POST** 方式发送到开发者配置的 URL。若服务器 5 秒内没有响应，微信会断开连接并总共重试三次。

对本项目而言，司机在服务号聊天窗口发送 `绑定` 后，预期应在正式服务器 Nginx 访问日志看到类似：

```text
POST /api/official-account/messages?signature=...&timestamp=...&nonce=... 200
```

若只有 GET 验证成功而没有真实 POST，说明微信侧用户消息尚未实际推送到业务 URL，需继续检查消息推送是否真正启用、是否配置在当前服务号、用户是否向同一服务号聊天窗口发送消息，以及是否启用了安全/兼容模式导致当前明文处理不适配。

来源：微信官方文档《接收普通消息》：https://developers.weixin.qq.com/doc/service/guide/product/message/Receiving_standard_messages.html
