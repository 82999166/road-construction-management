# PDF 打印空白问题记录

## 复现证据

用户于 2026-08-26 上传的 `悦信云智管.pdf` 共 7 页，页面均为空白。该文件来自运费明细的浏览器“打印 / 保存 PDF”流程。

## 原因与修复

原实现直接在 Radix 对话框中调用页面级 `window.print()`，并通过 `body * { visibility: hidden }` 与选择器重新显示对话框内表格。浏览器在处理 Portal 对话框、打印分页和全局可见性覆盖时未稳定保留目标 DOM，导致空白页面。

现已将运费、柴油和机械汇总打印统一改为：在用户点击时打开独立浏览器文档，写入经过 HTML 转义的真实受控查询结果、固定 A4 横向样式、表头、逐条明细与末行合计，再触发该独立文档的打印。此方式不再依赖原页面或对话框的打印可见性样式。

## 验收点

- 独立打印页应包含项目、筛选条件与生成时间。
- 每条真实记录单独占一行，跨页重复表头。
- 最后一行显示相应金额、数量、趟数或车辆/机械数合计。
- 打印窗口应仅显示新文档的 A4 横向内容，而非系统后台页面。
