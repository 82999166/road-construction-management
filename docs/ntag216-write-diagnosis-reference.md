# NTAG216 写卡诊断参考

本文件仅记录本轮用于定位 uTrust 4701 F 写卡问题的公开外部资料要点；不得据此修改动态锁定位、配置页、口令页或制造商区。

- NXP 的 NTAG213/215/216 文档说明，NTAG216 的动态锁定位于 **0xE2 页**；该页必须只读采集，不能作为常规 NDEF 用户区写入目标。[1]
- NTAG216 的 NDEF 可用容量由 CC（能力容器）中的容量字段定义。本项目现场卡 CC 为 `E1 10 6D 00`，对应 872 字节 NDEF 容量；从第 4 页开始等价于 218 页数据区，正常写入范围截止于第 221 页，不能清空至动态锁定或配置页。
- 静态锁定位一旦写入不可逆；任何正式修复都必须先读取状态字与锁定页证据，不得通过写锁、改 AUTH0、设置口令或更改配置区规避失败。

## 下一步只读取证范围

在不写入卡片的前提下读取：CC 第 3 页、静态锁定位所在制造商区相关页、动态锁定第 0xE2 页和配置页的 PC/SC APDU 状态字。仅记录受控状态摘要，不输出运输深链、RC3 业务内容、卡 UID 原文或任何口令资料。
