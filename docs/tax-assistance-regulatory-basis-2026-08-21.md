# 财税辅助控制法规依据（系统设计备忘）

> 本文件仅记录系统字段、资料清单与风险提示的设计依据。道路施工承包管理系统不生成纳税申报、不会自动确认应纳税额；任何实际申报、税率适用或抵扣判断须由持证会计师或税务师复核。

| 控制主题 | 官方依据与系统落地边界 |
| --- | --- |
| 工资薪金累计预扣 | 国家税务总局公告2018年第56号明确：居民个人工资薪金按累计预扣法计算并按月全员全额扣缴申报；系统应保存工资期间、人员、应发/扣除/实发、项目所在地与外部交接/回执引用，辅助导出而不是自行申报或替代个税专项扣除判断。[1] |
| 累计预扣率参数 | 税务机关公开的居民个人工资薪金预扣率表一列示累计应纳税所得额分档、预扣率和速算扣除数。系统将该参数固化在服务端测算快照中，并随公式版本、来源金额和人工扣除项一起留痕；任何政策变化均须由会计复核后更新版本。[5] |
| 异地工程人员个税 | 国家税务总局公告2015年第52号明确：跨省异地施工单位对工程作业人员工资薪金向工程作业所在地办理全员全额扣缴明细申报；系统需要按项目所在地与工资来源提供交接清单，避免重复归集提示，不直接向税务机关报送。[2] |
| 印花税资料 | 《中华人民共和国印花税法》规定应税合同等范围及计税依据；应税合同的计税依据为合同所列金额（不包括列明的增值税税款）。系统保留合同、合同不含税金额、凭证和回执引用，实际税目和税率由专业人员确认。[3] |
| 跨地区建筑服务预缴 | 税务机关跨区建筑服务管理规则要求按项目、计税方法、收入、分包款、扣除凭证和完税凭证等建立资料与台账。系统通过项目税务档案、分包扣除凭证、跨地区预缴辅助事项和交接批次提供资料准备能力，不自动套用历史税率公式、不认定已预缴。[4] |

## 系统设计结论

1. 财税辅助台账的金额必须来自已登记业务事实或人工确认资料；空值表示**未确认**而不是零。
2. 系统生成的 CSV 是提供正式财务软件或电子税务局办理前的资料交接清单；交接批次保存字段快照和 SHA-256，后续只能登记真实外部回执引用。
3. 跨地区预缴、印花税、工资薪金与分包扣除均以“待处理资料事项”管理，并显式区分资料金额、计税依据、参考税率和已确认税额，避免将暂存数据误写成法定申报结果。
