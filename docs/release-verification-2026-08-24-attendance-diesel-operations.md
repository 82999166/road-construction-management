# 考勤台账与柴油移动操作窗口发布验证

本次发布将后台“全员上下班考勤台账”由单一工作区项目查询改为管理员已授权项目范围汇总，并增加项目列。因此，已真实写入且属于授权项目的移动打卡记录不会再因后台当前工作区项目不同而遗漏。

移动柴油模块完成核心“柴油领用登记”操作窗口。只有同时具备柴油领用登记权限、项目数据范围和水印影像取证能力的人员可完成登记；流程要求后置相机现场拍摄加油表，浏览器生成工程水印后归档为柴油凭证，服务端再复核项目、车辆或机械归属、有效指导价或实际单价、金额与审计记录。车辆选择“运输扣油”时，服务端还会额外核验柴油扣油结算权限。

| 验证项目 | 结果 |
|---|---|
| 类型检查 | 通过 |
| 全量回归、标准生产构建、自建服务器构建 | 通过 |
| 正式服务器服务与本机健康响应 | 正常 |
| 正式 HTTPS 首页与移动柴油前端分包 | HTTP 200 |
| 发布方式 | `release/current` 原子切换，保留历史静态分包与旧 release 回滚能力 |
