# 微信新版服务号通知入口调研

## 2026-08-13 初步结论

微信官方模板消息能力面向服务号的重要服务通知，且模板必须符合服务场景与用户触发/同意边界；它不是任意持续营销或无条件群发渠道。[1][2]

当前项目实测的服务号私有模板库仅返回“订阅模板消息”占位模板，使用传统模板接口和订阅通知接口均得到微信错误码 `40037`。因此该占位项已在系统中停用和隐藏，不能继续作为施工、采购、审批或财务持续业务通知模板。

第三方新版后台指引显示，服务号的实际消息模板入口可能位于“广告与服务 → 消息模板”，而非旧版“功能/功能插件 → 模板消息”。该路径必须由服务号管理员在微信公众平台实际页面中核对，不应根据旧版菜单臆测。[3]

## 后续核验方向

1. 登录微信公众平台服务号后台后，查找“广告与服务”“消息模板”“服务通知”或“订阅通知”等页面。
2. 仅选择与工程业务有关的模板，例如审核结果、业务流转、待办提醒、施工进度或结算通知；不得使用营销、福利或资料领取文案。
3. 模板加入服务号私有模板库后，在本系统读取模板库、生成草稿、发布模板 ID 与字段映射，再对单个已关注员工执行受控投递验收。
