# 统一人员档案使用说明

## 从哪里进入

超级管理后台 → **劳务工资 → 人员档案**，默认打开人员库；原来的考勤、日结、工资审核和付款，保留在同一页的 **考勤与工资结算** 标签中。账号权限页面也使用同一人员档案组件，不再维护第二套人员基础资料。

点击 **新增人员** 可录入公司人员、临时工、施工队人员或外部人员。再独立选择主要岗位、兼任岗位、项目及施工队。司机、机械操作员是岗位，不再被默认视为公司管理员。手机号和系统账号不是建档必填条件；关联账号不自动授权菜单或管理权限。

## 旧人员如何纳入

点击 **引入历史人员**，按系统中的真实账号、员工档案或劳务人员来源确认引入。已引入的来源直接打开同一主档。不会按姓名、重名或手机号猜测合并；不会删除历史档案、考勤、工资、保险、付款凭证或审计记录。未确认的身份冲突会提示人工核实。

## 统一详情可以做什么

| 栏目 | 能力 |
| --- | --- |
| 基础资料 | 姓名、状态、入离职日期、性别、出生日期、地址、联系人、备注、手机号、证件、收款信息维护；人员照片上传与受控预览 |
| 岗位归属 | 主要岗位、兼岗、项目、施工队和用工归属维护；保留任职变更记录 |
| 薪资 | 计薪方式、基础工资、公司是否发薪、生效日期；查看历史版本 |
| 考勤 | 查看所选月份的真实考勤天数、工时、加班与记录 |
| 工资结算 | 查看工资、日结、预支及实际付款流水；选月份和真实项目主体生成工资草稿；登记预支草稿；进入原审批和付款工作区 |
| 车辆机械 | 查看真实绑定设备及换人记录；维护同项目当前司机、操作员 |
| 证照保险 | 上传照片、证照、合同和保险附件；站内预览；登记、修改保费保额、有效期和状态；查看历史保单附件 |
| 收款变更 | 维护收款资料并查看档案变更记录 |

列表可按姓名/编号、用工归属、岗位（含兼任）、项目、施工队、状态和保险状态筛选，支持当前筛选 CSV 与 A4 打印。手机表单采用窗口内滚动，PC使用宽窗口。

## 工资与历史的保护规则

公司支付工资与外部车辆运费、机械租金分开。临时工走原日结流程，不重复生成月薪。工资标准按生效日期追加版本，不用今天的新标准覆盖过去；已经核定或付款的金额不能在人员详情直接修改。

调项目或改变用工阶段时，保留旧项目、类别、工资主体及来源记录，建立新阶段的兼容主体。跨项目同月按无重叠的真实任职阶段分别处理；同一人、同一项目、同一月份不能重复建两张月薪。若已有工资单后仍需更正，走原工资审核和调整流程，不通过重建人员规避。

资源换人当前为 **今日即时生效**，同日可多次换班并保留事件顺序；本次没有开放未来自动换绑或历史回填排程。换人不会授予新人员登录权限，旧人员不再保留新人员设备的访问绑定。

## 敏感资料与附件

手机号、证件、银行卡原值不在编辑表单回显；**留空保留，明确清空须二次确认**。重复手机号、身份证或已占用身份会被服务端阻止，不自动合并。版本冲突会提示刷新，同时保留未提交输入。

新人员附件加密存储，预览通过当前管理员身份校验及短时授权；旧保单附件同样再次核对人员来源、项目及完整性。列表、打印和 CSV 不携带原始证件、完整账号、存储路径或永久下载链接。
