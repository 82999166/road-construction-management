# 外部 AI API 配置约定

系统设置支持一组兼容 OpenAI Chat Completions 的外部 AI API 配置：API 基础地址、模型名称、API Key 和启用状态。API Key 仅以 AES-GCM 密文保存；列表、审计和前端均只显示脱敏状态，调用只能发生在服务端。

| 配置项 | 作用 | 保存规则 |
| --- | --- | --- |
| API 基础地址 | 兼容 OpenAI 的 `v1` 服务根地址 | 仅接受 HTTPS，禁止私有网段、回环地址和含账号密码的 URL。 |
| 模型名称 | 管理摘要使用的模型标识 | 限制为字母、数字、点、下划线和连字符。 |
| API Key | 外部服务认证密钥 | 首次必填，后续留空保留已加密密文。 |
| 启用状态 | 是否优先使用外部服务 | 未启用时继续使用内置 AI。 |

外部服务连接校验仅查询其 `/models` 兼容端点，不发送任何项目业务数据。风险摘要调用仅传入既有脱敏风险计数和财务分类汇总；外部调用失败、超时或返回非结构化内容时，系统自动回退到项目内置 AI，再回退到规则摘要，不阻断风险扫描、通知或整改流程。
