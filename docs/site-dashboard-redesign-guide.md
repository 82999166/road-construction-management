# 现场大屏与后台菜单使用说明

## 双视频窗口

现场大屏的现场影像区域分为左、右两个固定 16:9 窗口。桌面左右排列，手机自动上下排列。每个窗口可以独立选择视频、播放、暂停和全屏，切换右侧不会重置左侧。默认优先左侧展示已设定的默认视频，右侧展示另一条启用视频。

通过“配置视频”进入 **系统设置 → 现场大屏 → 视频管理**，选择当前项目后添加录像或受控上传视频。没有配置项目录像时，左侧显示带授权和非实时标识的固定样片；不足两条视频时，另一窗口显示“视频待配置”，不会伪造第二路现场监控。录像不代表实时摄像头直播。

## 工地天气

可直接点击大屏上的“天气配置”，自动进入当前项目的 **系统设置 → 现场大屏 → 天气接入**。选择 **MET Norway 免费天气**，不需要 API Key。先由有权管理员阅读并确认服务条款，提供真实的公司联系邮箱或可联系技术支持的公开 HTTPS 页面，再在“天气地点”填写工地名称和经纬度，保存配置后测试天气。系统不会擅自接受条款或使用手机定位。

MET Norway 官方 FAQ 明确允许商业使用；数据按 CC BY 4.0 标注来源。免费服务无到达保证或 SLA，网络不可用时会如实显示错误。系统从服务器读取并缓存预报，遵守接口缓存及限流要求，不会每次刷新大屏都重复调用外部服务。

- [官方 FAQ](https://api.met.no/doc/FAQ)
- [服务条款](https://api.met.no/doc/TermsOfService)
- [许可证](https://creativecommons.org/licenses/by/4.0/)

温度和风速属于模型预报，不是工地传感器实测。雨量明确显示预报时段；今日高低温仅涵盖今日剩余预报点。服务未提供的体感、阵风、降雨概率和能见度显示“未提供”，不会填零。系统作业提示不等于官方气象预警，也不自动判定停工。

## 统一布局和风险依据

大屏保留运输统计，上方为左右现场影像和工地天气，下方为施工日报与计划、现场风险总览、车辆登记资料。已移除“最近现场动态”版块；原运输台账及完整数量明细仍可查看。

点击风险条目可弹出原始依据并定位原运单或加油记录。登记加油量不是实际耗油量；缺少里程、耗油周期或运营基线时，不认定油耗或运营效率异常。最近完成的柴油修改、删除及结算锁定功能保持不变。

## 后台菜单分类

左侧菜单整理为五类：总览工作台、项目与人员、设备与运输、采购与结算、系统与工具。点击分类标题可展开或收起，进入业务页面时自动展开所在分类。收缩为图标侧栏后，所有已授权入口仍可访问。

只整理菜单分类和顺序，不改变业务路径、后台权限或管理员项目范围。普通管理员不会因菜单重排获得超级管理员功能。
