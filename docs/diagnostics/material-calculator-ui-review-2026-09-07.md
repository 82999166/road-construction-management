# 材料采购计算器界面核验记录

- 桌面端已按“实时总览—材料与供货口径—运费—税费利润—结算垫资—综合结果—逐月明细”形成清晰章节；关键总额、勾稽状态、应收峰值和资金峰值位于输入区前后可见位置。
- 手机端各输入区已单列排布，没有文字遮挡或控件超出；成本汇总和结果卡保持纵向可读。
- 逐月明细在手机端采用横向滚动宽表，首列固定；默认仅展示关键月份，避免长账期页面一次渲染过长，仍可手动展开全部月份。
- 页面已明确“整个合同总量”与“每月供货量（连续重复）”两种数量口径，并提供“运输数量跟随采购数量”开关，减少旧运输数量造成的结果误读。
- 页面已显示回款与现金流勾稽状态、计算边界和预计税费口径；视觉上未发现桌面或手机端阻塞性布局问题。
