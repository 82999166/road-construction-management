# 项目风险治理与真实扫描验收说明

项目风险预警只读取已经保存的施工日报、考勤、柴油领用和运输趟次；系统不会为验收生成模拟车辆、加油、运输或财务记录。管理员应先在车辆和机械档案中填入实际核定油箱容量，并在项目风险中心按项目保存现场认可的阈值，避免把缺失主数据误判为业务异常。

| 验收项目 | 必要真实数据 | 预期结果 |
| --- | --- | --- |
| 施工与考勤 | 已保存的待审核日报或未完成下班打卡 | 生成可回溯到原单据的待办预警。 |
| 柴油合理性 | 领用记录及对应车辆或机械的核定油箱容量 | 仅在加油量超过项目设定比例时生成预警。 |
| 运输合理性 | 含起止时间和实际公里数的完成趟次 | 对平均速度过高、耗时过长或起止时间倒置生成预警。 |
| 责任整改 | 项目范围内的有效管理人员 | 可指定责任人、整改期限，并保留确认、整改和升级提醒审计。 |

当前环境已存在有效项目、车辆、机械、施工日报和考勤数据，但尚没有柴油领用或运输趟次。因此，首次真实扫描可验证施工与考勤链路；柴油和运输规则应在业务人员录入真实单据后再执行验收。
