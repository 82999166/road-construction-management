# 真实账号与业务数据验收清单

## 验收原则

本系统不创建模拟账号、模拟项目或模拟劳务业务记录用于验收。企业身份密码、找回、重置和异常登录识别由企业统一身份平台负责；应用仅提供受控跳转、最小化审计和安全退出能力。

## 企业身份平台前置条件

| 项目 | 验收要求 | 验收证据 |
| --- | --- | --- |
| 恢复地址 | 超级管理员在“系统设置”中以已发布、非敏感配置保存企业身份平台的公开 HTTPS 恢复地址 | 配置状态为“已发布”；访问 `/api/identity-recovery` 仅重定向到该固定地址 |
| 密码找回与重置 | 在企业身份平台使用真实验收账号完成，不向本系统提供密码、验证码或恢复令牌 | 身份平台的审计记录或管理员确认 |
| 异常登录处置 | 在企业身份平台确认其异常登录识别、账号冻结或通知策略；本系统仅核验成功登录审计和最小化通知 | 身份平台策略截图或管理员确认；系统审计不含令牌、密码或邮箱 |

## 分级权限验收前置条件

| 账号类型 | 最小授权 | 必须验证的结果 |
| --- | --- | --- |
| 超级管理员 | `SUPER_ADMIN` 或模板 `admin`，全局项目范围 | 可进入 `/admin`，可查看与维护全局主数据、配置和审计；可办理已存在业务记录的更新、审批、结算、作废或冲销 |
| 普通管理人员 | 至少一个已启用部门、已授权业务模块和至少一个真实项目范围 | 仅看到获授权模块和项目；可在授权项目内新增业务记录与查看数据；尝试既有记录编辑、审批、结算、作废、冲销、跨项目访问及 `/admin` 均被拒绝 |

## 真实劳务数据验收前置条件

| 数据类别 | 最小真实数据 | 验收操作 |
| --- | --- | --- |
| 项目与组织 | 一个已启用组织和一个真实项目 | 确认普通管理人员只能看到已授权项目 |
| 劳务人员 | 至少一条真实、已获授权的劳务人员台账 | 查看脱敏字段、人员所属项目和实名状态 |
| 考勤 | 至少一条对应项目和人员的真实考勤记录 | 按日期查看与汇总；普通管理人员不得覆盖既有自然键记录 |
| 工资条 | 至少一个真实工资期间和工资条 | 查看统计与打印；普通管理人员不得提交、审核、发放或作废既有工资条 |

## 执行记录

验收时应记录账号标识（仅内部编号或受控别名）、项目编号、模块、操作时间、预期结果和实际结果。不得将密码、验证码、恢复令牌、身份证号、银行卡号、Webhook 或完整个人信息写入本文件、问题单或聊天记录。
