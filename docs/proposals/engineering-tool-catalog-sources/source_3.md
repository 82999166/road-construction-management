# 中国道路与铁路施工承包管理系统 - 工具知识分卷

## 专业域：土工、路基、边坡、排水、防护、压实、含水率、土石方、地基处理及土工试验

### 土工试验与换算

### SUB-01
- 二级分类：土工试验与换算  
- 名称：含水率（w，重含水率）  
- 定义与适用场景：  
  含水率为土样中水的质量与固体质量之比，常用来描述土的湿度状态、试验控制、压实控制及土的工程性质评估。适用于烘干法现场/室内试验、样品水分监测与换算。  
- 公式或操作步骤：  
  1. 取代表性土样，称量湿重 Mwet（g或kg）。  
  2. 将样品在105±5°C烘至恒重，称量干重 Mdry（g或kg）。  
  3. 计算含水率（以百分数表示）：  
     w (%) = (Mwet − Mdry) / Mdry × 100%  
     或以小数表示 w (decimal) = (Mwet − Mdry) / Mdry  
- 全部变量与单位：  
  - Mwet：湿样质量（g 或 kg）  
  - Mdry：烘干后固体质量（g 或 kg）  
  - w：含水率（% 或 无量纲小数）  
- 完整数值示例：  
  假设 Mwet = 125.0 g，Mdry = 100.0 g。  
  w = (125.0 − 100.0) / 100.0 × 100% = 25.0%  
- 结果解释：  
  25.0% 表示样品中水的质量相当于固体质量的 25%。用于比较试验状态与规范或压实控制值。  
- 注意事项与禁用边界：  
  - 烘干温度/时间应符合试验规程；含有有机物或挥发性物质的土样需注意挥发损失误差。  
  - 使用质量单位必须一致（g 或 kg）。  
  - 当样品含盐或化学试剂可能析出结晶时，烘干结果需谨慎解释。  
  - 含水率可大于100%（极非常湿样），计算公式仍适用。  
- 关联标准/规程：实施前复核现行版本  
- 建议页面控件：  
  - 数值输入：湿质量（带单位切换 g/kg）  
  - 数值输入：干质量（带单位切换 g/kg）  
  - 单位统一提示（强制相同单位）  
  - 计算按钮、结果显示（% 与小数）  
  - 异常提示（干质量≥湿质量警告）  
- 是否适合自动计算：是

### SUB-02
- 二级分类：土工试验与换算  
- 名称：湿密度（ρ）与干密度（ρd）换算  
- 定义与适用场景：  
  湿密度（或天然密度）为单位体积土的总质量，干密度为单位体积干土固体的质量。干密度常用于压实控制、承载力估算与土体工程性质计算。适用于压实试验、圈尺/比重瓶/托盘法测量后换算。  
- 公式或操作步骤：  
  - 若知道湿密度 ρ 与含水率 w（小数），则：  
    ρd = ρ / (1 + w)  
  - 反向：ρ = ρd × (1 + w)  
  - 若用质量与体积直接测得：ρ = Mtotal / Vtotal；ρd = Mdry / Vtotal  
- 全部变量与单位：  
  - ρ：湿密度（kg/m3 或 g/cm3）  
  - ρd：干密度（kg/m3 或 g/cm3）  
  - w：含水率（小数）  
  - Mtotal：总质量（kg 或 g）  
  - Mdry：干质量（kg 或 g）  
  - Vtotal：总体积（m3 或 cm3）  
- 完整数值示例：  
  若 ρ = 1980 kg/m3，w = 10% = 0.10：  
  ρd = 1980 / (1 + 0.10) = 1800 kg/m3  
- 结果解释：  
  干密度 1800 kg/m3 表示每立方米干固体质量为 1800 kg，常用于与设计压实度或标准贯入能量对应的目标值比较。  
- 注意事项与禁用边界：  
  - w 必须为小数（例如 10% = 0.10）；若输入为百分数需转换。  
  - ρ 与 ρd 的单位需一致；在 g/cm3 与 kg/m3 之间换算时注意因子（1 g/cm3 = 1000 kg/m3）。  
  - 若土中含有气泡或大块不均匀体积（石块），体积测量方式需对应（是否包含石块体积）。  
- 关联标准/规程：实施前复核现行版本  
- 建议页面控件：  
  - 数值输入：湿密度（单位下拉 kg/m3/g·cm−3）  
  - 数值输入：含水率（支持%或小数切换）  
  - 单位自动转换开关与即时校验（w>=0）  
  - 输出：干密度（并显示换算公式）  
- 是否适合自动计算：是

### SUB-03
- 二级分类：土工试验与换算  
- 名称：孔隙比（e）与孔隙率/孔隙度（n）换算  
- 定义与适用场景：  
  孔隙比 e = Vv / Vs（孔隙体积与固体体积之比），孔隙率 n = Vv / Vt（孔隙体积与总体积之比）。用于描述土的结构、渗透性、压缩性及其他强度—变形性质。适用于土工试验后由干密度与比重或由体积直接测定换算。  
- 公式或操作步骤：  
  - 若已知固体比重 Gs、干密度 ρd（与水密度 ρw），使用：  
    e = (Gs * ρw) / ρd − 1  
  - 孔隙率：  
    n = e / (1 + e)（无量纲，乘以100% 可得百分比）  
  - 可逆算 ρd：ρd = (Gs * ρw) / (1 + e)  
- 全部变量与单位：  
  - e：孔隙比（无量纲）  
  - n：孔隙率/孔隙度（无量纲或%）  
  - Gs：固体比重（相对密度，无量纲）  
  - ρd：干密度（kg/m3 或 g/cm3）  
  - ρw：水密度（常取 1000 kg/m3 或 1.0 g/cm3）  
- 完整数值示例：  
  取 Gs = 2.70，ρw = 1.0 g/cm3，ρd = 1.60 g/cm3：  
  e = (2.70 × 1.0) / 1.60 − 1 = 1.6875 − 1 = 0.6875  
  n = 0.6875 / (1 + 0.6875) = 0.407 ≈ 40.7%  
- 结果解释：  
  孔隙比 0.6875 表明固体体积的孔隙体积约为 68.75%；孔隙率 40.7% 表示总体积中约 40.7% 为孔隙（含水或含气）。  
- 注意事项与禁用边界：  
  - 单位须一致（g/cm3 与 ρw=1.0 一致或 kg/m3 与 ρw=1000）。  
  - Gs 应由比重杯/比重瓶等试验所得，非精确 Gs 会显著影响 e。  
  - 非饱和复杂结构（大块砾石、植物残体）时公式适用性受限；对含有大量有机质或孔隙连通性异常的土类需谨慎。  
- 关联标准/规程：实施前复核现行版本  
- 建议页面控件：  
  - 数值输入：Gs（无量纲）  
  - 数值输入：干密度（单位下拉）与水密度默认值（可修改）  
  - 输出：e、n（显示%）并标注计算公式来源  
  - 单位一致性校验与异常提示（例如 e<0 或 n>1 报错）  
- 是否适合自动计算：是

### SUB-04
- 二级分类：土工试验与换算  
- 名称：饱和度（Sr）计算  
- 定义与适用场景：  
  饱和度 Sr（通常以百分数表示）为孔隙体积中被水充满的比例。用于判断土体是否饱和、评估渗流/强度/孔隙压力条件及与压实、含水率控制的关系。适用于由含水率、孔隙比与固体比重换算得出饱和状态评估。  
- 公式或操作步骤：  
  - 常用公式（小数形式）：  
    Sr = (w × Gs) / e  
    或百分数表示 Sr(%) = 100 × (w × Gs) / e  
  - 计算步骤：  
    1. 获得含水率 w（小数）、固体比重 Gs 和孔隙比 e（或先算 e）。  
    2. 套用公式计算 Sr。  
- 全部变量与单位：  
  - Sr：饱和度（小数或%）  
  - w：含水率（小数）  
  - Gs：固体比重（无量纲）  
  - e：孔隙比（无量纲）  
- 完整数值示例：  
  取 w = 20% = 0.20，Gs = 2.70，e = 0.6875：  
  Sr = (0.20 × 2.70) / 0.6875 = 0.785 ≈ 78.5%  
- 结果解释：  
  Sr = 78.5% 表示孔隙体积中约 78.5% 被水充满，土样为非饱和但接近饱和状态。  
- 注意事项与禁用边界：  
  - 若 Sr > 1（100%）或 Sr < 0，说明输入数据有误（w、Gs 或 e 错置/单位不一致）。  
  - Gs、w、e 的测定误差会直接影响 Sr，尤其是 e 的误差敏感性高。  
  - 对饱和盐水或密度非标准水温环境，应调整 ρw/相关参数。  
- 关联标准/规程：实施前复核现行版本  
- 建议页面控件：  
  - 数值输入：含水率（%或小数切换）、Gs、e（或提供从ρd计算e的按钮）  
  - 输出：Sr（%）并给出警告（Sr>100% 或 <0）  
  - 自动单位/格式校验（确保 w 为小数）  
- 是否适合自动计算：是

### SUB-05
- 二级分类：土工试验与换算  
- 名称：饱和密度（ρsat）与饱和单位重（γsat）换算  
- 定义与适用场景：  
  饱和密度与饱和单位重用于评估饱和土体的自重、渗流及极限承载等。当土样或土层在完全饱和条件下，其总体质量与体积关系可由固体比重与孔隙比分解计算。适用于稳定问题、地下水位上升时的状态判断及计算。  
- 公式或操作步骤：  
  - 饱和密度（质量/体积）：  
    ρsat = ρw × (Gs + e) / (1 + e)  
  - 饱和单位重（常用 kN/m3）：  
    γsat = γw × (Gs + e) / (1 + e) ，其中 γw ≈ 9.81 kN/m3（或按现场水密度取值）  
  - 计算步骤：输入 Gs、e、ρw 或 γw，代入公式。  
- 全部变量与单位：  
  - ρsat：饱和密度（kg/m3 或 g/cm3）  
  - γsat：饱和单位重（kN/m3）  
  - ρw：水密度（kg/m3 或 g/cm3，常取 1000 kg/m3 或 1.0 g/cm3）  
  - γw：水单位重（kN/m3，常取 9.81 kN/m3）  
  - Gs：固体比重（无量纲）  
  - e：孔隙比（无量纲）  
- 完整数值示例：  
  取 Gs = 2.70，e = 0.6875，ρw = 1.0 g/cm3：  
  ρsat = 1.0 × (2.70 + 0.6875) / (1 + 0.6875) = 3.3875 / 1.6875 = 2.0074 g/cm3 ≈ 2007 kg/m3  
  γsat ≈ 2.0074 × 9.81 kN/m3 ≈ 19.7 kN/m3（按单位转换）  
- 结果解释：  
  ρsat ≈ 2007 kg/m3 表示在完全饱和时该土每立方米的总质量约为 2007 kg；γsat 为其对应的重力单位重。用于计算土体自重、孔隙水压力与稳定性分析。  
- 注意事项与禁用边界：  
  - 对含盐水、温度极端或非常规流体，ρw 与 γw 应作相应调整。  
  - 对富有机质或轻质礫石混合物，Gs 与 e 的概念需慎用或分别处理。  
  - 公式基于饱和假定；若实际非饱和不可直接使用。  
- 关联标准/规程：实施前复核现行版本  
- 建议页面控件：  
  - 数值输入：Gs、e、ρw（默认值可选 1000 kg/m3）或直接输入 γw  
  - 输出：ρsat（kg/m3/g·cm−3）、γsat（kN/m3）并显示来源公式  
  - 单位选择器与异常检测（e<-0.99 或 Gs<=0 等报错）  
- 是否适合自动计算：是

### SUB-06
- 二级分类：土工试验与换算  
- 名称：含水率换算与施工加水量计算（试验室配合比 ↔ 施工配合比 换算）  
- 定义与适用场景：  
  将实验室配合比（例如试验室最优含水率 w_lab）转化为现场施工所需的加水量，或根据现场初始含水率计算需加水体积/质量。适用于施工现场加水计划、压实控制与材料拌和量计算。强调：参考配比不得替代现场试配（现场湿度分布、填料回填方式、机具等影响显著）。  
- 公式或操作步骤：  
  常用基于干质量的计算：  
  1. 设目标含水率（w_target，小数）与现场初始含水率（w_initial，小数）。  
  2. 单位体积目标干质量 Md_v = ρd_target（kg/m3）。  
  3. 每立方米需添加水质量（kg/m3）：  
     Wadd_v = Md_v × (w_target − w_initial)  
     （若 w_target < w_initial，则为需抽水/干燥）  
  4. 将水质量换算为体积（升或 m3）：Vadd_v (L/m3) ≈ Wadd_v (kg/m3)（取水密度 ≈1 kg/L）  
  另：若以总土料质量（含水）为基准或以干土质量为基准，注意换算基底的一致性。  
- 全部变量与单位：  
  - w_target：目标含水率（小数）  
  - w_initial：现场初始含水率（小数）  
  - ρd_target：目标干密度（kg/m3）或按体积基准的干土质量（kg/m3）  
  - Wadd_v：每立方米需加水质量（kg/m3）  
  - Vadd_v：每立方米需加水体积（L/m3 或 m3/m3）  
- 完整数值示例：  
  设 ρd_target = 1800 kg/m3，w_initial = 8% = 0.08，w_target = 10% = 0.10：  
  Wadd_v = 1800 × (0.10 − 0.08) = 36 kg/m3 ≈ 36 L/m3  
  意味着每 1 m3 干土需加水约 36 L（若按湿土体积计需换算基底）。  
- 结果解释：  
  36 L/m3 表示为达到目标含水率，按每立方米干土质量计应加水 36 升；现场投加需考虑均匀性损失、蒸发和渗漏，通常需留有裕量并进行试配。  
- 注意事项与禁用边界：  
  - 强调：试验室配合比仅为参考，现场必须进行试配和确认（“参考配比不得替代试配”）。  
  - 基准必须明确：按“每立方米干土”或“每立方米湿土/原位体积”；混淆基准会导致加水量误差。  
  - 风干/蒸发、土料吸水性、颗粒级配与盐分会影响实际需水量；现场应分层试压或小区试配后确定最终加水量。  
  - 若 w_target < w_initial，公式得负值表示需抽水/干燥处理，施工上需采用机械干燥或更换材料。  
- 关联标准/规程：实施前复核现行版本；并符合工程施工试配要求与质量控制规范（现场必须记录试配数据）  
- 建议页面控件：  
  - 数值输入：目标干密度 ρd_target（kg/m3）  
  - 数值输入：w_initial、w_target（%或小数切换）  
  - 选择基准：按“干土质量/m3” 或 “湿土体积/m3”  
  - 输出：Wadd_v（kg/m3）、Vadd_v（L/m3）、总加水量估算（按工程体积）  
  - 试配提示框（强制提醒：必须试配并记录）  
- 是否适合自动计算：是

### 压实度与压实质量控制

- 编号：SUB-01  
  二级分类：压实度与压实质量控制  
  名称：压实度（基于最大干密度法）  
  定义与适用场景：  
  - 定义：压实度（又称压实率、压实度百分比）是现场土体干密度与试验室确定的最大干密度之比，表示现场压实达到设计/规范要求的程度。常用于路基、堤坡、填方等工程压实质量验收与控制。  
  - 适用场景：基于击实试验获取最大干密度后，对填方或路基分层进行现场干密度检测并按此计算压实度。  
  公式或操作步骤：  
  - 公式：η = (ρd_field / ρd_max) × 100%  
  - 操作步骤：1) 取得试验室击实试验确定的最大干密度 ρd_max；2) 现场按环刀法/沙锥法等测得现场干密度 ρd_field；3) 代入公式计算压实度。  
  全部变量与单位：  
  - η：压实度（%）  
  - ρd_field：现场干密度（kg/m3 或 g/cm3）  
  - ρd_max：试验室最大干密度（kg/m3 或 g/cm3）  
  完整数值示例：  
  - 已知：ρd_field = 1.78 g/cm3，ρd_max = 1.84 g/cm3  
  - 计算：η = (1.78 / 1.84) × 100% = 96.74%  
  结果解释：  
  - 若设计或规范要求压实度 ≥95%，则示例结果 96.74% 符合要求；若规范要求 ≥98%，则不合格。  
  注意事项与禁用边界：  
  - 必须使用同一湿度条件下或将湿密度换算为干密度后比较；湿含水率未换算时不得直接与ρd_max比较。  
  - 当土中砾石含量过高（例如>30%体积）或存在有机料、粘性含水异常时，常规击实ρd_max与现场ρd测值的代表性会降低，应采用专项方法。  
  - 对应不同击实能量（标准/改良）选取相应的ρd_max；不得混用不同击实等级的ρd_max。  
  关联标准/规程：实施前复核现行版本（现场与室内试验方法相关标准）。  
  建议页面控件：输入框（现场干密度）、输入框（最大干密度）、单位下拉（kg/m3/g/cm3）、阈值输入、结果显示（%）、合格/不合格灯号。  
  是否适合自动计算：是

- 编号：SUB-02  
  二级分类：压实度与压实质量控制  
  名称：最大干密度的确定（击实试验曲线法）  
  定义与适用场景：  
  - 定义：通过标准击实或改良击实试验，在不同含水率下进行压实，绘制含水率—干密度曲线，取曲线峰值对应的干密度为最大干密度（ρd_max），峰值对应的含水率为最优含水率（w_opt）。  
  - 适用场景：为压实质量控制提供基准值（ρd_max、w_opt），作为现场压实度计算和施工配合比制定依据。  
  公式或操作步骤：  
  - 操作步骤：1) 配制若干含水率试样（覆盖预期含水率范围）；2) 按照指定击实能量分别压实并测定试件湿密度ρ（或取湿重与体积）；3) 根据含水率w计算干密度ρd = ρ / (1 + w)；4) 绘制ρd—w曲线，取峰值为ρd_max，对应w为w_opt。  
  全部变量与单位：  
  - ρd_max：最大干密度（kg/m3 或 g/cm3）  
  - w_opt：最优含水率（% 或 小数）  
  - ρ：湿密度（kg/m3 或 g/cm3）  
  - w：含水率（按质量计，% 或 小数）  
  完整数值示例：  
  - 试验数据（示例）：w1=8%→ρ1=1.80 g/cm3→ρd1=1.80/(1+0.08)=1.6667 g/cm3；w2=10%→ρ2=1.88 g/cm3→ρd2=1.7091 g/cm3；w3=12%→ρ3=1.94 g/cm3→ρd3=1.7321 g/cm3；w4=14%→ρ4=1.92 g/cm3→ρd4=1.6842 g/cm3。  
  - 曲线峰值：ρd_max ≈ 1.732 g/cm3，w_opt ≈ 12%。  
  结果解释：  
  - ρd_max 为该土在所用击实能量下理论可达到的最高干密度；w_opt 为对应最佳施工含水率参考值。  
  注意事项与禁用边界：  
  - 必须标明所用击实能量（标准击实或改良击实）；不同能量不可混用。  
  - 试样应代表现场土（含粒径分布），含砾石量大时需说明试验方法的适用性或采取筛分修正。  
  - 试验室配合比为参考，不能直接替代现场试配（见第5项）。  
  关联标准/规程：实施前复核现行版本（室内击实试验相关标准与方法）。  
  建议页面控件：数据表格输入（含水率、湿密度或湿重/体积）、绘图显示（ρd—w曲线）、峰值自动识别按钮、击实能量选择（标准/改良）、导出报告按钮。  
  是否适合自动计算：是

- 编号：SUB-03  
  二级分类：压实度与压实质量控制  
  名称：湿密度与干密度互算（现场含水率换算）  
  定义与适用场景：  
  - 定义：利用土的含水率将测得的湿密度转换为干密度，或从目标干密度计算对应湿密度，用于压实度计算与现场密度控制。  
  - 适用场景：现场用核子密度仪、光弹性仪或其他仪器测湿密度并需换算为干密度，或根据目标干密度与现场含水率计算目标湿密度以便仪器直接比对。  
  公式或操作步骤：  
  - 干密度计算：ρd = ρ / (1 + w)  
  - 湿密度计算：ρ = ρd × (1 + w)  
  - 其中 w 以质量比表示（小数形式，例如 12% = 0.12）。  
  全部变量与单位：  
  - ρd：干密度（kg/m3 或 g/cm3）  
  - ρ：湿密度（kg/m3 或 g/cm3）  
  - w：含水率（小数或%）  
  完整数值示例：  
  - 例1（湿→干）：测得湿密度ρ = 2.05 t/m3，含水率 w = 12% = 0.12，ρd = 2.05 / (1 + 0.12) = 1.8304 t/m3 = 1.830 g/cm3。  
  - 例2（干→湿）：目标ρd = 1.75 t/m3，现场w = 10% = 0.10，目标湿密度ρ = 1.75 × (1 + 0.10) = 1.925 t/m3。  
  结果解释：  
  - 换算后结果用于与ρd_max比较（计算压实度），或用于仪器设定、现场即时判断是否达到湿密度目标。  
  注意事项与禁用边界：  
  - 含水率w必须为质量含水率（m_wet-m_dry）/m_dry；体积含水率或其它定义不可混淆。  
  - 单位一致性必须保证（kg/m3 或 t/m3 与 g/cm3 之间换算）。  
  - 当土体中空隙、粗骨料比重大或含水率不均匀时，单点换算具有局限性，应增密采样或采用体积法换算（见体积换算项）。  
  关联标准/规程：实施前复核现行版本（现场密度和含水率测定相关标准）。  
  建议页面控件：输入框（湿密度）、输入框（含水率%）、转换方向单选、结果显示（干密度或湿密度）、单位切换。  
  是否适合自动计算：是

- 编号：SUB-04  
  二级分类：压实度与压实质量控制  
  名称：压实方与天然方体积换算（基于干密度守恒的质量法）  
  定义与适用场景：  
  - 定义：依据质量守恒原理，用天然状态下的干密度与压实后干密度之间的比值，将天然方（原状体积）换算为压实方（压实后体积），反之亦然。适用于土方核算、工程量换算与施工配土计算。  
  - 适用场景：从原状测量体积或工程图纸体积推算压实后所需填方量；或由压实方量反推出需外运或开挖的天然方量。  
  公式或操作步骤：  
  - 基本质量守恒：M = Vn × ρd_n = Vc × ρd_c  
  - 换算公式：Vc = Vn × (ρd_n / ρd_c)；反向：Vn = Vc × (ρd_c / ρd_n)  
  全部变量与单位：  
  - Vn：天然方体积（m3）  
  - Vc：压实后体积（压实方，m3）  
  - ρd_n：天然状态干密度（t/m3 或 kg/m3）  
  - ρd_c：压实状态干密度（t/m3 或 kg/m3）  
  完整数值示例：  
  - 已知：Vn = 1000 m3，天然干密度ρd_n = 1.60 t/m3，压实后干密度ρd_c = 1.75 t/m3。  
  - 计算：Vc = 1000 × (1.60 / 1.75) = 914.29 m3。  
  - 解释：将1000 m3天然土按上述密度压实后得到约914.3 m3压实方。  
  结果解释：  
  - 当ρd_c > ρd_n时，Vc < Vn（体积收缩）；当ρd_c < ρd_n时（极少见，或湿度膨胀等），Vc > Vn。该计算基于干质量守恒，不包含含水率引起的质量变化或材料损失。  
  注意事项与禁用边界：  
  - 需以干密度为基础进行换算，若给出的是湿密度，必须先转换为干密度（见SUB-03）。  
  - 不考虑材料损失、扬尘、筛分和剔除杂质、施工过程中加入填料或掺合料的质量变化；大粒径、含机体或浮土时需修正。  
  - 对于含水率变化显著或存在体积膨胀（膨胀土）/收缩的土层，应采用更为复杂的质量—体积模型并进行试配。  
  关联标准/规程：实施前复核现行版本（土方工程计量与验收相关标准）。  
  建议页面控件：输入框（Vn 或 Vc）、输入框（ρd_n, ρd_c）、单位下拉、单选（直接算Vc或算Vn）、结果显示、导出换算表格。  
  是否适合自动计算：是

- 编号：SUB-05  
  二级分类：压实度与压实质量控制  
  名称：试验室配合比/施工配合比与含水率换算（参考性换算）  
  定义与适用场景：  
  - 定义：将实验室击实试验得到的ρd_max与w_opt，结合设计或规范要求的压实度，换算为现场的目标干密度与目标湿密度；用于施工控制与压实机（摊铺机/压路机）现场目标设定。强调：此换算为参考，不可替代现场试配与调整。  
  - 适用场景：施工前制定现场控制目标（干密度/湿密度），进行质量控制、仪表设定与验收依据。  
  公式或操作步骤：  
  - 计算目标干密度：ρd_target = (target_compaction% / 100) × ρd_max  
  - 将目标干密度换算为目标湿密度（用于湿密度仪器）：ρ_target = ρd_target × (1 + w_field)  
  - 若以现场预计含水率为参考，则 w_field 可取现场测得平均含水率或用 w_opt 作为初始参考并通过试配确定最终施工含水率。  
  全部变量与单位：  
  - ρd_target：目标干密度（kg/m3 或 g/cm3）  
  - target_compaction%：目标压实度（%）  
  - ρd_max：试验室最大干密度（kg/m3 或 g/cm3）  
  - ρ_target：目标湿密度（kg/m3 或 g/cm3）  
  - w_field：现场施工含水率（小数或%）  
  完整数值示例：  
  - 已知：ρd_max = 1.85 t/m3，目标压实度 = 95%，现场预计含水率 w_field = 10% = 0.10。  
  - ρd_target = 0.95 × 1.85 = 1.7575 t/m3。  
  - ρ_target = 1.7575 × (1 + 0.10) = 1.93325 t/m3。  
  结果解释：  
  - ρd_target 为按设计压实度应达到的干密度；ρ_target 为在现场含水率条件下需达到的湿密度（便于湿密度仪器直接比对）。  
  注意事项与禁用边界：  
  - 明确：该换算为参考目标，必须通过现场试配（碾压试验段）确定最终施工配合比与施工水分控制策略。  
  - 若现场含水率与w_opt有明显偏离，应通过加水或控水及碾压次数调整直至试配满足目标。  
  - 对含粗颗粒、土壤分层或材料来源变化大的工程，室内ρd_max可能不能代表现场，须局部重做击实试验或试配。  
  关联标准/规程：实施前复核现行版本（配合比与压实质量控制相关标准）。  
  建议页面控件：输入框（ρd_max）、输入框（目标压实度%）、输入框（现场含水率%）、计算按钮、输出（ρd_target, ρ_target）、提醒文本（“必须现场试配”复选框）。  
  是否适合自动计算：是

- 编号：SUB-06  
  二级分类：压实度与压实质量控制  
  名称：现场干密度测定（环刀法）及计算步骤  
  定义与适用场景：  
  - 定义：环刀法（切刀取样法）通过已知环刀体积直接取现场样品，经称量并烘干后计算干密度，是现场常用的快速干密度检测方法之一。  
  - 适用场景：中细土层或不含过大砾石、岩块的填方/路基分层压实质量检验。  
  公式或操作步骤：  
  - 公式：ρd = m_dry / V_ring  
  - 操作步骤：1) 校验环刀体积 V_ring（记录并校准）及环刀重量；2) 用环刀在被检点切取土样并记录取样湿重 m_wet（含环刀或按规程扣除环刀质量）；3) 将样品入烘箱按标准温度和时间烘干至恒重，记录干重 m_dry；4) 计算含水率 w = (m_wet - m_dry) / m_dry；5) 计算干密度 ρd = m_dry / V_ring（注意单位换算）。  
  全部变量与单位：  
  - ρd：干密度（kg/m3 或 g/cm3）  
  - m_wet：样品湿质量（kg 或 g）  
  - m_dry：样品烘干后干质量（kg 或 g）  
  - w：含水率（小数或%）  
  - V_ring：环刀体积（m3 或 cm3）  
  完整数值示例：  
  - 假设环刀体积 V_ring = 100 cm3（0.0001 m3），取样湿重 m_wet = 210 g，烘干后 m_dry = 185 g。  
  - 含水率 w = (210 - 185) / 185 = 25 / 185 = 0.1351 = 13.51%。  
  - 干密度 ρd = 185 g / 100 cm3 = 1.85 g/cm3 = 1850 kg/m3。  
  结果解释：  
  - 计算得出ρd后，与ρd_max计算压实度（见SUB-01）决定是否合格；同时含水率用于判断是否处于良好施工含水范围。  
  注意事项与禁用边界：  
  - 环刀法不适用于含大于环刀截面一半颗粒（如卵石、块石）的土样；遇大粒径、贯通空洞或松散颗粒应采用沙锥法或其他方法。  
  - 环刀体积需定期校验、温度校正和腐蚀检查；烘干温度、时间须按标准执行以免有机物分解或水分未蒸发完全。  
  - 取样时避免压缩或丢土，严格按操作规程取样以保证体积与质量对应准确。  
  关联标准/规程：实施前复核现行版本（环刀法/现场密度测定相关标准）。  
  建议页面控件：输入框（V_ring + 单位）、输入框（m_wet）、输入框（m_dry）、烘干温度/时间输入提示、自动计算按钮（含水率、ρd）、合格判定（与ρd_max和目标压实度连接）。  
  是否适合自动计算：是

### 土石方计算与测量计量

### SUB-01
- 二级分类：土石方计算 — 断面法（单段截面法 / 梯形法）
- 名称：断面法土方计算（梯形近似）
- 定义与适用场景：  
  采用相邻两断面面积的平均值乘以两断面间距计算区段土方量的传统方法，适用于断面布设规则、断面间距较短且地形变化平缓的挖方或填方工程量计算。常用于施工图预算、工程计量与常规地形测量。
- 公式或操作步骤：  
  1. 测量或计算每个断面净挖/净填面积 A_i（m²）。  
  2. 对相邻两断面 i 与 i+1，计算区段体积：  
     V_i = (A_i + A_{i+1}) / 2 × L_i  
     （L_i 为两断面间水平投影距离，m）  
  3. 全线体积 V_total = Σ V_i（对所有区段求和）。  
- 全部变量与单位：  
  - A_i：第 i 个断面净挖/净填面积，单位 m²  
  - L_i：断面 i 与 i+1 之间的水平间距或沿轴距离，单位 m  
  - V_i：第 i 段土方体积，单位 m³  
  - V_total：总土方体积，单位 m³
- 完整数值示例：  
  给定三个连续断面面积 A1=100.0 m²、A2=120.0 m²、A3=110.0 m²，断面间距均为 L=20.0 m。  
  计算：  
  V_1 = (100 + 120)/2 × 20 = 110 × 20 = 2200 m³  
  V_2 = (120 + 110)/2 × 20 = 115 × 20 = 2300 m³  
  V_total = 2200 + 2300 = 4500 m³
- 结果解释：  
  得到的 V_total 为按梯形近似计算的工程原状（或净挖/净填）土方体积。结果为设计或计量依据，但当断面间地形变化剧烈时误差增大，应选用更密断面或更高精度方法（Simpson、三角剖分或数字地面模型）。
- 注意事项与禁用边界：  
  - 要求断面间距足够密（间距过大时误差显著）。  
  - A_i 应为净面积（按设计挖深/回填后剩余面积），并明确挖/填方向。  
  - 若断面间距不等，应分别使用对应 L_i。  
  - 不适用于断面曲率大、地形突变或需高精度计量时（此时建议采用 Simpson 法或基于三维TIN/DEM 的体积计算）。  
  - 断面数据来源（测量/设计）要统一基准与水准系统。  
- 关联标准/规程：实施前复核现行版本（如：工程计量规范、测量规程相关条款）
- 建议页面控件：  
  - 表格输入区域：断面编号、A_i（m²）、坐标或里程、与下断面间距 L_i（m）  
  - 自动计算按钮、结果汇总、导出 CSV/EXCEL、断面图像预览（缩略图）  
  - 警示提示：断面间距过大/存在空值标红  
  - 可选开关：使用 Simpson 校正（当断面数与间距满足条件时）
- 是否适合自动计算：是

### SUB-02
- 二级分类：土石方计算 — 断面法（辛普森法 / 高精度规则）
- 名称：辛普森规则（数值积分法）用于断面体积计算
- 定义与适用场景：  
  当断面等间距布设且需提高体积计算精度（相比梯形法）时，采用辛普森规则对等距断面进行积分。适用于地形变化较为平滑但需较高精度的工程量计算。要求断面数为偶数间隔（即区段数为偶数）。
- 公式或操作步骤：  
  1. 确认等间距：各断面间距 h（m）一致，断面共有 n+1 个（n 为区间数，n 必须为偶数）。  
  2. 应用辛普森公式：  
     V = (h/3) × [A_0 + A_n + 4×ΣA_odd + 2×ΣA_even]  
     其中 A_odd 为奇数序号断面（1,3,...,n-1）面积之和，A_even 为偶数序号断面（2,4,...,n-2）面积之和。  
  3. 若区间数为奇数或间距不等，应分组或退回使用梯形法或等效数值积分处理。
- 全部变量与单位：  
  - h：等间距，m  
  - A_0..A_n：从起点到终点各断面面积，m²  
  - V：计算得体积，m³
- 完整数值示例：  
  设 3 个区间（n=3，注意：此处 n 必须为偶数；为示例使用 n=2），取 n=2（即 3 个断面），h=10 m，A0=80 m²，A1=100 m²，A2=120 m²。  
  V = (10/3) × [80 + 120 + 4×100] = (10/3) × (200 + 400) = (10/3) × 600 = 2000.0 m³
- 结果解释：  
  与梯形法比较，辛普森对同样间距的断面能提供更高的数值精度，尤其在断面面积呈二次连续变化时误差更小。若间距或断面数不满足要求，应改用其他方法或分段应用辛普森。
- 注意事项与禁用边界：  
  - 必须为等间距断面；不等间距需先插值。  
  - 区间数 n 必须为偶数（若不满足，须将线路分段使每段满足条件）。  
  - 对突变地形（如陡坎）仍可能产生误差，必要时结合密断面或三维模型。  
- 关联标准/规程：实施前复核现行版本（如相关工程计量与测量标准）
- 建议页面控件：  
  - 栏目：断面序号、A_i（m²）、间距 h（m）统一输入或单独输入每个区段 h_i（用于等距检测）

  - 可视化：断面面积折线图与 Simpson 运算权重示意

### SUB-03
- 二级分类：土石方计量术语
- 名称：松铺系数
- 英文/缩写：Swell factor / Bulking factor（常缩写 Fs）
- 定义：  
  松铺系数 Fs 通常定义为挖出后的松散体积（松铺体积、堆放体积）与原状体积（原状、原位体积）之比：  
  Fs = V_loose / V_bank  
  其中 V_loose 为挖出并松铺后的体积，V_bank 为原状（in-situ）体积。常用于将设计/合同标注的原状土方量换算为运输或临时堆放所需体积。
- 现场示例：  
  某段原状土方 V_bank = 200 m³，经现场试挖测定松铺系数 Fs = 1.18，则松散体积 V_loose = 200 × 1.18 = 236 m³。用于安排运输车数或堆场占用体积估算。
- 易混淆项：  
  - 压实系数（回填后体积与原状体积比）— 与松铺系数方向相反且数值通常小于 1。  
  - 蓬松率（通常用于土壤物理表征）与松铺系数概念不同。  
  - 单位重量/堆积密度（bulk density）— 反映质量与体积关系，不等同体积比。  
  注意：松铺系数受土类、含水率、颗粒级配、挖掘方式和块石含量影响，需以现场试验或历史资料为准，施工中不得盲目采用通用表值。

### SUB-04
- 二级分类：土石方计算 — 体积换算（原状/松铺/回填转换）
- 名称：土石方体积转换与换算公式（含松铺与压实系数）
- 定义与适用场景：  
  在土石方工程中常需在原状体积（原位）、挖出松铺体积（运输/堆放）与回填压实体积之间互相换算。本模板给出标准转换关系与操作步骤，适用于工料调配、运输安排与回填材料来源计算。
- 公式或操作步骤：  
  定义变量并按需换算：  
  - V_b：原状（bank / in-situ）体积，m³  
  - V_l：松铺（loose / excavated）体积，m³  
  - V_c：回填（compacted）体积，m³  
  - Fs：松铺系数 = V_l / V_b （常 >1）  
  - Kr：回填压实系数（或简称压实系数） = V_c / V_b （常 ≈0.9~1.0，视压实度与土性）  
  换算关系：  
  - V_l = V_b × Fs  
  - V_c = V_b × Kr  
  - 若已知需要回填体积 V_c，需要原状土方来源 V_b_required = V_c / Kr  
  - 若计算运输量（以车斗体积为准），运输次数 N = V_l / 单车净载（m³/车） 并考虑装载系数与损耗  
- 全部变量与单位：  
  - V_b、V_l、V_c：体积，m³  
  - Fs、Kr：无量纲比值  
  - 单车净载：m³/车
- 完整数值示例：  
  已知工程设计需回填压实体积 V_c = 900 m³，现场回填压实系数 Kr = 0.95（即回填后体积占原状的 0.95）。  
  则所需原状土方 V_b_required = 900 / 0.95 = 947.368 m³。  
  若现场松铺系数 Fs = 1.20，则挖出后的松散体积 V_l = V_b_required × 1.20 = 947.368 × 1.20 = 1,136.842 m³。  
  若单车净载 8.5 m³/车，则理论运输车次 ≈ 1,136.842 / 8.5 ≈ 133.74 → 取整按合同/现场规则（通常向上取整并计损耗）。
- 结果解释：  
  通过上述关系可在原状、松铺与回填之间进行体积平衡与运输计划编制。示例显示为满足压实后体积，需额外挖取并考虑松铺造成的体积增加与运输次数。
- 注意事项与禁用边界：  
  - Fs 与 Kr 强烈依赖土性、含水率、挖掘方式、存在石块比例及压实工艺，应以现场取样与试验值或历史可靠数据为准；推荐施工前进行现场试堆或试配以确定系数。  
  - 不要用通用表值盲目替代现场试验；在含水率临界或冻土/溶胀土条件下误差更大。  
  - 运输车次计算应考虑装载损耗、空载比与现场装卸效率。  
- 关联标准/规程：实施前复核现行版本（如工程计量与土石方作业相关规范）
- 建议页面控件：  
  - 输入框：V_b、Fs、Kr、V_c、单车净载  
  - 选单：土类选择（提示推荐 Fs/Kr 区间，仅作参考）  
  - 计算按钮：显示 V_l、V_b_required、运输车次、并提供向上/向下取整选项  
  - 警告/提示：提示需现场试验、含水率影响说明、误差估算（例如 ±x%）  
  - 导出/打印：运量清单与计算依据
- 是否适合自动计算：是

### SUB-05
- 二级分类：土石方测量计量 — 测量高程模板（精密水准与一般水准）
- 名称：测量高程计算模板（高程测设与差值换算操作模板）
- 定义与适用场景：  
  提供从基准点（BM）通过视准高度、后视/前视读数计算各点高程的标准操作模板，适用于施工放样、控制测量、填挖高程检查与竣工验收中的常规水准测量与差高计算。
- 公式或操作步骤：  
  基本流程（附标准高差法）：  
  1. 确定已知基准点 BM_elev（m）。  
  2. 在 BM 或其附近架设仪器，记录后视读数 BS（staff reading on BM，m）；计算仪高：HI = BM_elev + BS。  
  3. 对目标点读前视 FS（staff reading on target，m）；目标点高程 E_point = HI - FS。  
  4. 连续测设时交替后视/前视：每次移动仪器时记录换点的读数并做闭合差校核。  
  5. 闭合检验：回到原始 BM 或闭合点，计算闭合差 Δ = (已知 BM_elev_end - 计算得 BM_elev_end)。对照允许误差（按规范：实施前复核现行版本）进行平差或分配闭合差。  
- 全部变量与单位：  
  - BM_elev：已知基准点高程，m  
  - BS：后视读数（杆尺在基点的读数），m  
  - HI：仪高（Height of Instrument），m  
  - FS：前视读数（杆尺在目标点的读数），m  
  - E_point：目标点高程，m  
  - Δ：闭合差，m
- 完整数值示例：  
  已知 BM_elev = 100.000 m。架仪并在 BM 上读 BS = 1.350 m。  
  则 HI = 100.000 + 1.350 = 101.350 m。  
  测目标点读 FS = 2.842 m，则目标点高程 E_point = 101.350 − 2.842 = 98.508 m。  
  若第二目标点 FS2 = 0.512 m，则 E2 = 101.350 − 0.512 = 100.838 m。
- 结果解释：  
  计算得各测点地面或控制点高程，用于比较设计高程判断挖/填量、指导机械放样或作为竣工高程资料。闭合差反映测量精度与系统误差，应根据规范判断是否接受并进行必要平差。
- 注意事项与禁用边界：  
  - 仪器必须按规范水准校正并做温度/气候影响考虑；长距测量时折光、视差影响上升。  
  - 后视与前视点高度差过大需分段架设仪器以减小读数误差。  
  - 闭合差应在规范允许范围内（实施前复核现行版本）；若超差需检查仪器安装、读数、人员操作并重测或施行平差。  
  - 用于工程放样时，务必与设计高程基准一致（同一水准面、同一单位）。  
- 关联标准/规程：实施前复核现行版本（如水准测量与工程测量规程）
- 建议页面控件：  
  - 输入区：BM_elev、BS、FS（可添加多点批量表格）  
  - 自动计算：HI 自动生成、各点 E_point 输出、单位与小数位选择（建议保留 mm 精度即 0.001 m）  
  - 闭合检验模块：输入终点实测值，自动计算闭合差并与允许误差比较  
  - 测量日志：时间、操作者、仪器编号、气象条件、备注字段  
  - 导出：高程表、平差结果、测量簿样式导出（PDF/CSV）  
- 是否适合自动计算：是

### 路基与地基处理

## SUB-01  
- 二级分类：路基与地基处理  
- 名称：加州承载比（CBR）计算（基于穿入载荷）  
- 定义与适用场景：  
  - 定义：CBR（California Bearing Ratio）是以标准试验条件下土样或原地土在规定穿入量处所承载荷载与标准试验参考荷载之比表示的百分数，用于路基材料强度与路面结构设计参考。  
  - 适用场景：实验室固结或未固结CBR试验、原位CBR或穿入式试验结果换算、路基分层材料强度评价与初步设计。  
- 公式或操作步骤：  
  1. 按试验记录确定在规定穿入量（通常为2.5 mm或5.0 mm）时的试验载荷 P_test（单位：kN或N）。  
  2. 采用对应的标准参考载荷 P_ref（标准值可按所用标准或试验方法确定）。  
  3. 计算： CBR(%) = (P_test / P_ref) × 100%  
- 全部变量与单位：  
  - CBR (%)：加州承载比，百分比  
  - P_test：试验时测得的载荷（kN）或（N） — 在同一单位下计算  
  - P_ref：标准参考载荷（kN）或（N），对应穿入量（如2.5 mm 或 5.0 mm）  
- 完整数值示例：  
  - 设试验在2.5 mm时测得载荷 P_test = 12.00 kN；标准参考载荷 P_ref(2.5mm) = 13.24 kN（示例标准值，实施前复核现行版本）。  
  - CBR = (12.00 / 13.24) × 100% = 90.6%  
- 结果解释：  
  - CBR 高（如 > 50%）表示材料承载力高、适合作为基层或垫层；CBR 低（如 < 5%）表示强度差，需改良或加厚路面结构。  
  - 必须区分未浸水（干/现场自然湿度）与浸水（浸泡）试验值，设计时通常采用浸水（或按规范要求）条件值作为保守参考。  
- 注意事项与禁用边界：  
  - 不同标准和孔径、板径、加载速度、样品固结条件会影响 P_ref 与试验结果，计算前确认所用标准和试验条件。  
  - 对于有机土、快速膨胀土、含砾量高或非均匀土样，CBR 可能不可靠，需辅助试验（切片、剪切、压缩试验等）。  
  - 参考载荷值 P_ref 应以所依标准为准；示例数值仅作计算说明，不得直接替代现场/实验室试配。  
- 关联标准/规程：实施前复核现行版本（如加州CBR试验相关规范或国家/行业试验规程）。  
- 建议页面控件：  
  - 输入框：P_test（数值 + 单位选择 kN/N）  
  - 下拉：穿入量选择（2.5 mm / 5.0 mm / 其它并可自定义 P_ref）  
  - 输入框：P_ref（允许自动填充常见标准值并可手动修改）  
  - 复选：试样条件（未浸泡 / 浸泡）  
  - 输出：CBR (%)、判定等级提示（可配置阈值）  
- 是否适合自动计算：是

## SUB-02  
- 二级分类：路基与地基处理  
- 名称：CBR与路基模量/弹性模量（经验换算）  
- 定义与适用场景：  
  - 定义：将CBR值经经验公式换算为路基弹性模量（或弾性模量、弹性模量的代表值）以便进行路面结构计算或有限元分析的简化估算方法。  
  - 适用场景：在缺乏现场或室内弹性模量试验（回弹模量、三轴动弹试验等）时做初步结构设计、壳体或路堤快速参数化、或用作参数敏感性分析的初值。  
- 公式或操作步骤（经验形式，需现场复核）：  
  - 常见经验形式（示例，可按本地经验修正）：  
    - Mr (MPa) ≈ k1 × CBR(%)  
    - 或 Mr (MPa) ≈ k2 × [CBR(%) ]^k3  
  - 常用参考系数示例（仅作示范，设计前必须通过试验校准）： k1 ≈ 8 ~ 15（常取 10 作为粗略估计）；若使用幂函数，典型 k2≈10，k3≈1。  
- 全部变量与单位：  
  - Mr：路基或土层的弹性模量 / 回弹模量（MPa）  
  - CBR(%)：加州承载比，百分比（%）  
  - k1、k2、k3：经验系数（无量纲；需基于本地区/材料的试验校正）  
- 完整数值示例：  
  - 取经验系数 k1 = 10；测得 CBR = 8%。  
  - 则 Mr ≈ 10 × 8 = 80 MPa。  
- 结果解释：  
  - 得到的 Mr 为经验估算值，可作为路面结构设计的初始输入或敏感性分析基准。  
  - 若后续有回弹模量、三轴试验等结果，应优先采用直接试验值并调整设计。  
- 注意事项与禁用边界：  
  - 该换算为经验关系，受土种（砂、粉土、粘土、砾石）、含水率、密实度、浸泡状态影响较大，严禁在未校核的特殊土（如膨胀土、有机质土、高含砾）直接套用。  
  - 参考配比/换算不得替代试验配合比或现场试验验证。  
- 关联标准/规程：实施前复核现行版本（若有本地区/行业推荐换算系数或表格，应优先使用）。  
- 建议页面控件：  
  - 输入框：CBR(%)（数值）  
  - 下拉/输入：选择或输入经验系数 k1（或 k2、k3）并显示默认建议值与来源备注  
  - 输出：Mr (MPa)，并提示“仅为经验估算，建议试验校核”  
- 是否适合自动计算：是（但需提示不确定性与校核要求）

## SUB-03  
- 二级分类：路基与地基处理  
- 名称：一维固结沉降估算（Terzaghi 一维固结理论）  
- 定义与适用场景：  
  - 定义：采用一维固结理论估算饱和或部分饱和黏性土层在有效应力增加下的主沉降（一级压缩），用于预测随时间的固结沉降量。  
  - 适用场景：软黏土层、厚黏性土层地基改良前后沉降估算、基坑回填或荷载新增引起的长期固结沉降计算。  
- 公式或操作步骤：  
  - 主公式（压缩量）：
    S = (Cc / (1 + e0)) × H × log10( (σ'0 + Δσ) / σ'0 )  
  - 步骤：  
    1. 确定土层厚度 H（m）、初始空隙比 e0、压缩指数 Cc（试验获得）、初始有效应力 σ'0（kPa）与荷载导致的有效应力增加 Δσ（kPa）。  
    2. 代入公式计算沉降 S（m）。  
    3. 若存在多层土，按分层分别计算并累加。  
- 全部变量与单位：  
  - S：固结沉降量（m）  
  - Cc：压缩指数（无量纲，试验获得）  
  - e0：初始空隙比（无量纲）  
  - H：压缩活跃层厚度（m）  
  - σ'0：初始有效垂直应力（kPa）  
  - Δσ：有效应力增量（kPa） — 通常由新增地面荷载或建筑荷载计算得到  
- 完整数值示例：  
  - 设 H = 2.00 m，e0 = 0.80，Cc = 0.25，初始有效应力 σ'0 = 100 kPa，新增有效应力 Δσ = 50 kPa。  
  - S = (0.25 / (1 + 0.80)) × 2.00 × log10((100+50)/100)  
  - = (0.25 / 1.80) × 2.00 × log10(1.5)  
  - = 0.1389 × 2.00 × 0.1761 = 0.0489 m = 48.9 mm  
- 结果解释：  
  - 该值为主固结沉降量（一级压缩），通常为长期主要沉降分量。若计算结果较大，需考虑改良（消减荷载、换填、预压或排水固结措施）。  
- 注意事项与禁用边界：  
  - 适用于粘性土（低渗透性）明显固结过程；对砂、透水性土层或非一维应力状态（斜向荷载、边界效应显著）不适用。  
  - 必须使用试验获得的 Cc 与 e0；若使用经验值，应标注不确定性并配合现场观测。  
  - σ'0 的估算需考虑水位、上覆荷载与沉井深度；若地下水位深度变化显著，应采用有效应力修正。  
  - 未包含第二次压缩（Cα）或结构性沉降，应在需要时另行计算。  
- 关联标准/规程：实施前复核现行版本（固结试验相关规范与土工试验规程）。  
- 建议页面控件：  
  - 输入框：H（m）、e0、Cc、σ'0（kPa）、Δσ（kPa）  
  - 可选：分层计算表格（添加多层按钮）  
  - 计算按钮与结果显示（沉降量 m 和 mm，分层贡献表）  
  - 输出导出（CSV/PDF）与结果不确定性提示（若使用经验参数）  
- 是否适合自动计算：是

## SUB-04  
- 二级分类：路基与地基处理  
- 名称：即时弹性沉降估算（简化弹性层法）  
- 定义与适用场景：  
  - 定义：基于弹性层（或弹性半空间）近似估算加荷后土体的即时（瞬时）弹性沉降，用于估计初期沉降和总沉降的短期分量。  
  - 适用场景：刚性或弹性层薄、荷载施加后短期变形估算、与固结沉降叠加得到总沉降估算的第一步。  
- 公式或操作步骤（简化通用形式）：  
  - 近似估算（等效层法）： Se ≈ q × H_e / E_s  
    - 其中 H_e 为影响厚度（m），E_s 为土体弹性模量（MPa），q 为外加平均工作荷载（kPa）。  
  - 若考虑泊松比 ν，则可使用修正系数： Se ≈ q × H_e / E_s × f(ν) ，常用 f(ν) ≈ (1 - ν^2) 或按经验取 0.7~1.0。  
  - 步骤：确定 q、H_e（通常为与荷载半径或层厚相关的影响深度）、E_s（回弹模量或静三轴/三轴试验结果）、ν，代入计算。  
- 全部变量与单位：  
  - Se：即时弹性沉降（m）  
  - q：作用面平均工作荷载（kPa）  
  - H_e：等效影响厚度（m）——可取与荷载大小和基础尺寸相关的经验值  
  - E_s：土体弹性模量（MPa） — 注意单位换算：1 MPa = 1000 kPa  
  - ν：泊松比（无量纲）  
- 完整数值示例：  
  - 假设 q = 200 kPa（建筑基础或路堤局部），H_e = 1.0 m，E_s = 50 MPa，ν = 0.3。  
  - 先单位统一：E_s = 50 MPa = 50,000 kPa。取 f(ν) ≈ (1 - ν^2) = 1 - 0.09 = 0.91。  
  - Se ≈ q × H_e / E_s × f(ν) = 200 × 1.0 / 50,000 × 0.91 = 0.00364 m = 3.64 mm  
- 结果解释：  
  - 该值为瞬时弹性沉降估算，用于与固结沉降叠加。若 Se 非常大（相对于允许沉降限值），需考虑改变基础形式或加大处理措施。  
- 注意事项与禁用边界：  
  - 该方法为近似估算，适用于弹性响应占主导的短期沉降。对层析复杂、含砂层主导或应力集中明显的情况应采用更精细的弹性解或数值模拟（有限元/有限差分）。  
  - E_s 应优先采用现场/室内试验值（如回弹模量、动三轴），若用经验值应明确不确定性。  
  - 影响厚度 H_e 的选取对结果影响大，常需依据基础尺寸或经验表格确定。  
- 关联标准/规程：实施前复核现行版本（路基设计与地基处理相关规范）。  
- 建议页面控件：  
  - 输入框：q（kPa）、H_e（m）、E_s（MPa）、ν  
  - 下拉：E_s 来源（直接试验/经验估算）并提示默认范围  
  - 输出：Se（m/mm），并提供占总预估沉降的百分比（若已输入固结沉降）  
- 是否适合自动计算：是

## SUB-05  
- 二级分类：路基与地基处理  
- 名称：浅基础极限承载力估算（Terzaghi 形式）并换算为允许承载力  
- 定义与适用场景：  
  - 定义：采用浅基础极限承载力的经典表达式估算地基在破坏前可承受的极限压力，并基于安全系数换算为设计允许承载力（工作荷载）。该表达式为设计提供初步承载力判定。  
  - 适用场景：条形或矩形或独立基础的初步承载力评估、地基改良前后承载力计算、与现场承载力试验（板载）对比校核。  
- 公式或操作步骤（Terzaghi 经典形式，含三项贡献）：  
  - q_ult = c × Nc + q × Nq + 0.5 × γ × B × Nγ  
    - 若需考虑深度修正（Df）、形状修正与浸水影响，应乘以相应修正系数（d, s, i 等），并依据规范/工程手册取值。  
  - 设计允许承载力 q_allow = q_ult / FS  （FS 为总安全系数，常取 2.5~3.0，按规范与工程重要性调整）  
- 全部变量与单位：  
  - q_ult：极限承载力（kPa）  
  - q_allow：设计允许承载力（kPa）  
  - c：土的粘聚力（kPa）  
  - γ：土的饱和或有效单位重（kN/m^3 或 kPa/m）  
  - B：基础宽度（m）  
  - q：基础底部上覆土产生的有效应力（kPa），通常 q = γ × Df（Df 为基础埋深）  
  - Nc、Nq、Nγ：承载力因子（与土体摩擦角 φ 有关，按标准表或公式计算）  
  - FS：安全系数（无量纲）  
- 完整数值示例（粘性土简化示例 φ ≈ 0）：  
  - 设粘聚力 c = 25 kPa，φ = 0 时常用 Nc ≈ 5.14，Nq ≈ 1，Nγ ≈ 0（示例值，实施前复核），基础埋深 Df = 1.0 m，土重 γ = 18 kN/m3，B = 1.5 m，取 FS = 3.0。  
  - 计算 q = γ × Df = 18 × 1.0 = 18 kPa。  
  - q_ult = c × Nc + q × Nq + 0.5 × γ × B × Nγ = 25×5.14 + 18×1 + 0.5×18×1.5×0 = 128.5 + 18 = 146.5 kPa。  
  - q_allow = 146.5 / 3.0 = 48.8 kPa。  
- 结果解释：  
  - q_ult 为理论极限承载力（破坏前极限）；q_allow 为可持续使用的设计承载力，应作为基础设计的允许接触压力。  
  - 对于摩擦性土（φ>0），须按规范计算 Nc、Nq、Nγ 或采用表格，并考虑深度、形状、基底摩擦、地下水等修正。  
- 注意事项与禁用边界：  
  - 经典公式为简化解析解，假设均匀、半无限土体和理想化破坏面；对层状地基、倾斜地基、分层砾石或强烈非线性应力应使用数值方法或现场载荷试验校核。  
  - 承载力因子（Nc、Nq、Nγ）应依据当前工程手册或规范计算/查表（不同来源值可能不同）；示例中的数值仅为示范，不可直接用于设计。  
  - 若地下水位在基础底部或以上，应按有效应力原则调整 γ 和 q，并添加渗透与浮力修正。  
  - 对软岩、风化层、人工回填、桩基础或深基础情形不得使用该浅基础简化公式。  
- 关联标准/规程：实施前复核现行版本（地基承载力与基础设计相关规范与手册）。  
- 建议页面控件：  
  - 输入框：c（kPa）、γ（kN/m3）、B（m）、Df（m）、φ（°）  
  - 按钮/脚本：自动计算 Nc、Nq、Nγ（采用规范公式或允许用户手动输入表值）  
  - 下拉：安全系数 FS（建议值可选）  
  - 选项：是否考虑地下水位修正、形状/深度/倾角修正项（可勾选并输入修正系数）  
  - 输出：q_ult（kPa）、q_allow（kPa）、各项贡献分解（c×Nc、q×Nq、γ项）  
- 是否适合自动计算：是（需用户确认承载力因子计算方法并提示规范引用）

### 边坡稳定性与防护

## SUB-01
- 二级分类：边坡坡率计算
- 名称：边坡坡率 / 坡度、坡比与坡角换算
- 定义与适用场景：用于描述边坡几何形状的基本量，适用于场地勘测、设计表达、土方计算、边坡稳定初步判定及施工控制。包括：坡比（垂直：水平）、坡度(%) 及坡角(°) 三类常用表达互换。
- 公式或操作步骤：
  1. 坡比（竖：横） = Δh : L_h，其中 Δh 为高度差（m），L_h 为水平投影长度（m）。常写为 1 : n 或 m : 1。
  2. 坡度百分比（%） = (Δh / L_h) × 100%。
  3. 坡角（α，度） = arctan(Δh / L_h)（注意计算器需切换到度）。
  4. 互换：若已知坡角 α，
     - 坂比 = 1 : (cot α) 或 (tan α) : 1 视表达习惯；
     - 坡度% = tan α × 100%。
- 全部变量与单位：
  - Δh：高差，单位 m
  - L_h：水平投影长度，单位 m
  - α：坡角，单位 °（度）
  - 坡度 (%)：百分数 %
- 完整数值示例：
  - Δh = 10 m，L_h = 20 m
  - 坡比 = 10 : 20 = 1 : 2
  - 坡度% = (10/20) × 100% = 50%
  - 坡角 α = arctan(10/20) = arctan(0.5) ≈ 26.565°
- 结果解释：
  - 1:2 表示竖向每降 1 单位，水平延伸 2 单位；50% 为常用施工/标注表达；26.6° 为角度表达，便于与摩擦角等角度量比较。
- 注意事项与禁用边界：
  - 若边坡有明显曲面（非直坡面），坡比/坡角应基于局部段落或按等高线平均；不得用单一坡比描述复杂多段坡。
  - 对于非常陡（如超过 60°）或接近垂直的坡体应采用角度或坡面形式描述，避免用百分比易引起误解。
  - 在标注时注明基准（竖向为高差还是深度）及水平投影口径（设计投影/实际投影）。
- 关联标准/规程：实施前复核现行版本（关于边坡表示的国家/行业规范）
- 建议页面控件：
  - 输入：Δh（数值 + 单位选择 m）、L_h（数值 + 单位选择 m）
  - 切换：输入模式选择（垂直/水平、坡角或坡比）
  - 输出：坡比、坡度(%)、坡角(°)（可复制/导出）
  - 按钮：计算、重置、示意图显示（自动绘制斜坡示意）
- 是否适合自动计算：是

## SUB-02
- 二级分类：边坡稳定性计算
- 名称：无限坡安全系数（简化无限坡模型，含孔隙水压）
- 定义与适用场景：用于坡面受重力驱动、范围大于滑动面深度且滑面近似平行坡面的土体（无限坡近似）。适用于风化层浅、坡长显著大于潜在滑深的初步稳定性分析与参数敏感性检核。对饱和或部分饱和情况可引入沿坡线孔隙水压力比例 m。
- 公式或操作步骤：
  - 基本形式（含粘聚力与沿坡孔压）：
    Fs = [ c' + (γ · z · cos^2α - u) · tan φ' ] / (γ · z · sinα · cosα)
  - 孔压按沿坡比例 m 计算：
    u = m · γ_w · z · cos^2α
  - 合并：
    Fs = { c' + [γ·z·cos^2α - m·γ_w·z·cos^2α]·tanφ' } / (γ·z·sinα·cosα)
  - 计算步骤：
    1. 确定 α（坡角）、z（潜在滑面深度）、土参数 c'、φ'、γ、孔隙水比 m（0~1）和 γ_w。
    2. 计算 cosα、sinα、cos^2α、sinα·cosα。
    3. 计算 u 与分子、分母，求 Fs。
- 全部变量与单位：
  - Fs：安全系数（无量纲）
  - c'：有效粘聚力（kPa）
  - φ'：有效内摩擦角（°，计算需取 tan φ'）
  - γ：土的湿重或有效重（kN/m³）
  - z：潜在滑动深度（m）
  - α：坡角（°）
  - u：孔隙水压力（kPa）
  - m：水位比例（无量纲，0 表干土，1 表全饱和沿深）
  - γ_w：水的重度（kN/m³，常取 9.81 kN/m³）
- 完整数值示例：
  - 设 c' = 10 kPa，φ' = 30°，γ = 18 kN/m³，z = 2.0 m，α = 26.565°（即1:2坡），m = 0.5，γ_w = 9.81 kN/m³
  - cosα = 0.894427，sinα = 0.447214，cos^2α = 0.8，sinα·cosα = 0.4
  - u = 0.5 · 9.81 · 2 · 0.8 = 7.848 kPa
  - 分子 = 10 + (18·2·0.8 - 7.848)·tan30° = 10 + (28.8 - 7.848)·0.57735 = 22.095 kN/m²
  - 分母 = 18·2·0.4 = 14.4 kN/m²
  - Fs = 22.095 / 14.4 ≈ 1.53
- 结果解释：
  - Fs ≈ 1.53 表示在给定参数下坡体满足常见的短期/中期稳定性要求（具体阈值按设计规范或工程情形确定）。
- 注意事项与禁用边界：
  - 该模型基于无限坡假设（滑动面平行坡面、坡长远大于滑深）；对有限坡、拱效应、异质土层、深滑面或复杂地下水渗流场不适用，应采用极限平衡法（Bishop、Morgenstern-Price 等）或数值模拟。
  - m 的取值应基于现场地下水位或渗流分析；盲目取 m=1 会高估孔压影响。
  - c'、φ' 应为有效应力参数（排除总应力计算误用）。
- 关联标准/规程：实施前复核现行版本（无限坡与边坡稳定相关的国家/行业规范）
- 建议页面控件：
  - 输入：c'（kPa）、φ'（°）、γ（kN/m³）、z（m）、α（°或坡比选择器）、m（0~1）、γ_w（kN/m³，默认9.81）
  - 输出：Fs（值与解释）、分子、分母、孔压 u、图形示意（坡面与潜滑面）
  - 功能：参数敏感分析（滑动深度或 m 的变化曲线）、保存/导出结果
- 是否适合自动计算：是（但推荐人工校核并结合更精确方法）

## SUB-03
- 二级分类：挡土墙土压力估算（Rankine 理论）
- 名称：Rankine 主动/被动土压力系数及深度分布（含粘聚力修正）
- 定义与适用场景：Rankine 理论适用于简化条件下（无壁面摩擦或壁面摩擦可忽略、墙面自由面真实近似，回填为均质土体）的主动（Ka）与被动（Kp）土压力系数计算及侧向压力分布估算。常用于竖直墙、水平回填或简化初步设计。
- 公式或操作步骤：
  - Ka = tan^2(45° - φ / 2) = (1 - sinφ) / (1 + sinφ)
  - Kp = tan^2(45° + φ / 2) = (1 + sinφ) / (1 - sinφ)
  - 无粘聚力时，深度 z 处的侧向有效应力：
    σ_h(z) = K · σ_v(z) = K · γ · z
  - 含有效粘聚力 c' 时（Rankine 修正）：
    σ_h(z) = K · γ · z - 2 · c' · √K  （主动位移方向时）
  - 计算步骤：输入 φ、γ、c'（若有）、K 的选择（Ka 或 Kp）、深度 z，代入计算。
- 全部变量与单位：
  - Ka、Kp：土压力系数（无量纲）
  - φ：内摩擦角（°）
  - γ：土重度（kN/m³）
  - c'：有效粘聚力（kPa）
  - z：深度（m）
  - σ_h：侧向总应力或有效应力（kPa，取决于是否包含孔压）
- 完整数值示例：
  - φ = 30°，γ = 18 kN/m³，z = 3 m，c' = 5 kPa（示例含粘聚修正）
  - sin30° = 0.5 → Ka = (1 - 0.5)/(1 + 0.5) = 0.3333
  - σ_h（不含 c） = Ka · γ · z = 0.3333 · 18 · 3 = 18 kPa
  - 粘聚修正项 = 2 · c' · √Ka = 2 · 5 · 0.57735 = 5.7735 kPa
  - σ_h（含 c 修正）= 18 - 5.7735 = 12.2265 kPa
- 结果解释：
  - σ_h 表示在该深度因主动土压力产生的侧向应力；若 σ_h ≤ 0 表示理论上粘聚力足以抵抗主动张力（实际应理解为未产生侧向拉应力）。
- 注意事项与禁用边界：
  - Rankine 假定无壁面摩擦（δ=0）、回填面可能为水平、土体均匀且墙不引起地表受力约束；对存在墙面摩擦、倾斜回填或非均质层时误差较大，应选用 Coulomb 或极限平衡法。
  - 粘聚力修正仅为理论修正，实际粘聚对分布和集中效应需谨慎；在干湿循环或长期条件下粘聚力可能衰减。
- 关联标准/规程：实施前复核现行版本（关于挡土墙设计与土压力计算的国家/行业规范）
- 建议页面控件：
  - 输入：φ（°）、γ（kN/m³）、c'（kPa，可为空）、深度 z（m）
  - 选择：Ka 或 Kp、是否含粘聚修正
  - 输出：K 值、σ_h（含/不含 c 修正）、深度分布曲线、可导出表格
- 是否适合自动计算：是

## SUB-04
- 二级分类：挡土墙土压力估算（Coulomb 方法）
- 名称：Coulomb 主动土压力计算（含壁面摩擦与回填坡度）——计算步骤模板
- 定义与适用场景：Coulomb 方法用于计算考虑墙面摩擦（δ）、回填面坡度（i）、墙面倾角（β）等几何与摩擦因素的主动/被动土压力系数。适用于工程中墙—土相互作用较明显且需考虑摩擦影响的情况，为比 Rankine 更广泛的解析方法。
- 公式或操作步骤（步骤化模板）：
  1. 输入：土体内摩擦角 φ、墙面摩擦角 δ、回填坡度 i（以水平为基准，正向上坡）、墙面倾角 β（与竖直的偏角，垂直墙 β=0）、γ、c（若考虑粘聚力则后处理）。
  2. 选择求主动（Ka）或被动（Kp）。
  3. 使用 Coulomb 解析公式（参考公式较复杂，推荐按以下步骤数值化实现）：
     - 以滑块法建立土体潜在破坏面，求使主动力最大的失稳角 θ（或等价方法）。
     - 具体可用解析表达式或在软件/数值程序中按 Coulomb 能量/力矩平衡求解 Ka（实施前复核现行公式版本）。
  4. 若墙面为垂直且回填水平且 δ = 0，则 Coulomb 退化为 Rankine（可直接用 Rankine）。
  5. 计算深度分布：σ_h(z) = Ka · γ · z（如含粘聚 c，则 σ_h(z) = Ka · γ · z - 2c · √Ka）。
- 全部变量与单位：
  - Ka/Kp：主动/被动系数（无量纲）
  - φ：内摩擦角（°）
  - δ：墙土界面摩擦角（°）
  - i：回填坡度（与水平角度，°）
  - β：墙面倾角（与竖直的偏角，°）
  - γ：土重度（kN/m³）
  - c：粘聚力（kPa）
  - z：深度（m）
- 完整数值示例（退化情形举例）：
  - 设竖直墙（β = 0）、水平回填（i = 0）、壁摩 δ = 0，φ = 30°，γ = 18 kN/m³，z = 3 m
  - 退化至 Rankine，Ka = 0.3333（见 SUB-03）
  - σ_h = 0.3333 · 18 · 3 = 18 kPa
- 结果解释：
  - Coulomb 可得更接近实际的 Ka，特别是当 δ ≠ 0 和回填有坡度时。结果为侧向土压力系数与随深度变化的侧向应力分布。
- 注意事项与禁用边界：
  - Coulomb 方法基于刚性块体和刚性失稳面的假定，对软弱层、非均质土体或复杂动力/时间依赖问题有局限。
  - 解析公式繁复，易错；建议用已验证的计算程序或按标准公式并复核边界条件。
  - 在采用 δ 时注意取值不得超过 φ，常用取 δ = (0.5~0.8)φ，但应基于现场测试或经验值并在规范允许范围内取值。
- 关联标准/规程：实施前复核现行版本（关于挡土墙设计中 Coulomb 及土压力计算的规范）
- 建议页面控件：
  - 输入：φ、δ、i、β（都为角度，°）、γ（kN/m³）、c（kPa）、深度 z（m）
  - 选项：解析公式/数值求解（当解析式不可用时建议数值优化求最大/最小）
  - 输出：Ka/Kp、σ_h(z) 分布、作用线位置、计算过程日志（便于复核）
  - 高级：参数敏感分析、与 Rankine 比较、导出报告
- 是否适合自动计算：是（推荐基于验证过的数值实现并人工复核）

## SUB-05
- 二级分类：挡土墙稳定性与内力计算
- 名称：主动土压力合力、作用点与抗倾矩计算（带/不带粘聚修正）
- 定义与适用场景：用于将侧向土压力分布转化为合力作用于挡土墙上，计算合力大小、作用点位置以进行受力、抗倾矩与基底稳定性设计。适用于单跨直墙（单位长度）及初步截面配筋与基础设计。
- 公式或操作步骤：
  - 对于以 σ_h(z) = Ka · γ · z（无粘聚） 为三角分布：
    - 合力 P = 0.5 · Ka · γ · H^2  （kN/m）
    - 合力作用点距基底（底部） = H / 3（向上）
  - 含粘聚力 c' 修正时（Rankine 型压强表达 σ_h(z) = Ka·γ·z - 2·c'·√Ka）：
    - P = 0.5 · Ka · γ · H^2 - 2 · c' · √Ka · H
    - 合力作用点 z_bar（距基底） = [ (Ka·γ·H^3 / 3) - (c'·√Ka · H^2) ] / P
  - 抗倾矩（关于基底前缘或其他参考点）按合力与其作用臂计算： M = P · e（kN·m/m）
  - 计算步骤：
    1. 确定 Ka（或采用 Rankine/Coulomb 计算）、γ、c'、墙高 H。
    2. 使用上述公式计算 P、z_bar（若含 c'）。
    3. 将 P 与墙自重、结构荷载一起进行力矩平衡与地基承载力检核。
- 全部变量与单位：
  - P：侧向土压力合力，单位 kN/m（每米墙长）
  - Ka：主动土压力系数（无量纲）
  - γ：土重度，kN/m³
  - H：墙高或垂直土压力高度，m
  - c'：有效粘聚力，kPa
  - z_bar：合力作用点距基底高度，m
  - M：力矩，kN·m/m
- 完整数值示例：
  - 取 H = 4.0 m，γ = 18 kN/m³，φ = 30° → Ka = 0.3333，c' = 0 或 c' = 5 kPa 两种情况
  - 无粘聚（c' = 0）：
    - P = 0.5 · 0.3333 · 18 · 4^2 = 48.0 kN/m
    - 作用点 = H / 3 = 4 / 3 ≈ 1.333 m（从基底向上）
  - 含粘聚（c' = 5 kPa）：
    - P = 0.5 · 0.3333 · 18 · 16 - 2 · 5 · √0.3333 · 4
        = 48.0 - 23.094 ≈ 24.906 kN/m
    - 分子 = Ka·γ·H^3 /3 - c'·√Ka·H^2 = 128 - 46.188 = 81.812
    - z_bar = 81.812 / 24.906 ≈ 3.285 m（距基底）
- 结果解释：
  - P 为墙上水平合力，供抗倾、滑移及基底承载力校核使用；z_bar 显示合力作用高度（用于力矩计算）。当 P ≤ 0 表示粘聚抵消了主动推力（实务上表示无主动拉力，但仍需检查其他工况）。
- 注意事项与禁用边界：
  - 上述公式基于线性分布（Rankine 或等效 Ka）与均匀土层；对分层土体、深层被动、地下水变化或墙体柔性引起的非线性分布需采用分段积分或数值方法。
  - 当计算出 z_bar 超出物理范围或 P 接近零时应人工复核模型与参数。
  - 合力与作用点仅是静力模型的一部分，设计时必须合并重力、活载、地震力及地基反力参与整体验算。
- 关联标准/规程：实施前复核现行版本（挡土墙合力与稳定性相关规范）
- 建议页面控件：
  - 输入：Ka、γ、H、c'（可选）
  - 输出：P（kN/m）、z_bar（m）、力矩示意（关于基底前缘/重心）
  - 功能：分层土体分段计算、合力图形显示、参数敏感（H、c'、Ka 变化）
- 是否适合自动计算：是 (需与结构/地基复核联动)

### 排水与防渗

### SUB-01
- 二级分类：排水与防渗
- 名称：渗透系数（恒定水头法）
- 定义与适用场景：  
  渗透系数（系数符号常用 k，单位 m/s）表示土体在稳态单向水力梯度下的渗透能力。恒定水头法适用于中等至高渗透性的无粘性或颗粒状土样在室内渗透试验中，样品保持恒定上、下游水头差并测量稳态流量。
- 公式或操作步骤：  
  1. 准备饱和的圆柱形环刀土样，测定长度 L 和横截面积 A。  
  2. 在试验装置上建立恒定水头 h（上、下游水位差），待流量达到稳态后记录时间间隔内累计排水量 Q（通常单位为 m^3/s）。  
  3. 计算渗透系数：  
     k = Q / (A · i) ，其中水力坡度 i = h / L  
- 全部变量与单位：  
  - k：渗透系数，单位 m/s  
  - Q：稳态流量，单位 m^3/s（注意为流量/时间）  
  - A：试样横截面积，单位 m^2  
  - i：水力坡度（无单位），i = h/L  
  - h：水头差，单位 m  
  - L：试样长度，单位 m
- 完整数值示例：  
  - 试样直径 D = 0.05 m → A = πD^2/4 = 0.0019635 m^2  
  - L = 0.10 m；设稳态测得 Q = 1.96×10^-6 m^3/s；水头差 h = 0.05 m → i = 0.05/0.10 = 0.5  
  - k = Q / (A·i) = 1.96e-6 / (0.0019635·0.5) ≈ 0.0020 m/s
- 结果解释：  
  - k 的大小反映土体渗透能力：例如 2×10^-3 m/s 属较高渗透能力（粗砂/碎石）；较小值（<10^-6 m/s）表示粘性土或防渗层。试验结果用于渗流量计算、设计排水和地下水控制。
- 注意事项与禁用边界：  
  - 适用于稳态、单相水流、水平或近水平流动且满足 Darcy 定律的情况；当渗流速度过大、发生非达西流动或存在空气分离、双相流时不适用。  
  - 样品必须充分饱和并消除微气泡；试样端部封边要可靠以避免旁流。  
  - 对于低透性土（k 很小），恒定水头法难以达到稳态，应采用变水头法或更长试验时间。  
  - 受温度、孔隙结构、样本扰动影响较大，必要时做温度校正或重复试验。  
- 关联标准/规程：实施前复核现行版本（例如：有关土工试验的国家/行业技术标准、土工实验室规程等）  
- 建议页面控件：  
  - 输入框：D（或直接输入 A）、L、h、Q（单位切换）  
  - 自动计算按钮、结果显示区、单位说明与检验提示（是否稳态、饱和提示）  
  - 帮助提示：如何测量 Q、A 计算器、稳态判定准则  
- 是否适合自动计算：是

### SUB-02
- 二级分类：排水与防渗
- 名称：渗透系数（变水头法 / 降水头法）
- 定义与适用场景：  
  变水头法用于测定低至中等渗透性的土样渗透系数，适用于较低 k 值条件下的室内试验。通过记录一定时间内上游水头从 h1 降至 h2 的变化，计算 k。
- 公式或操作步骤：  
  1. 试样横截面积 A，长度 L；设置连通的立管截面积 a（量水管），初始水头 h1，计时开始至水头降至 h2，耗时 t。  
  2. 计算（两种常用写法）：  
     - 自然对数形式：k = (a · L) / (A · t) · ln(h1 / h2)  
     - 常用对数（10）形式：k = 2.303 · (a · L) / (A · t) · log10(h1 / h2)  
- 全部变量与单位：  
  - k：渗透系数，单位 m/s  
  - a：立管截面积，单位 m^2  
  - A：试样横截面积，单位 m^2  
  - L：试样长度，单位 m  
  - h1：初始水头（相对于试样底部），单位 m  
  - h2：终止水头，单位 m  
  - t：时间间隔，单位 s（注意保持单位一致）  
- 完整数值示例：  
  - 试样直径 D = 0.05 m → A = 0.0019635 m^2；L = 0.10 m；立管直径 d = 0.01 m → a = π(0.01)^2/4 = 7.854×10^-5 m^2  
  - h1 = 0.30 m；h2 = 0.10 m；t = 1800 s  
  - k = (a·L)/(A·t)·ln(h1/h2) = (7.854e-5·0.10)/(0.0019635·1800)·ln(3)  
    = (7.854e-6)/(3.5343)·1.0986 ≈ (2.223e-6)·1.0986 ≈ 2.44×10^-6 m/s
- 结果解释：  
  - 该 k 值表明土样渗透性较低（典型于细砂或粉土）。结果应与恒定水头法、现场孔隙流速观测比对，若差异大应检查试样饱和、密实度、端部封边及立管截面积误差。  
- 注意事项与禁用边界：  
  - 要保证试样饱和以及水头降幅适中（h1/h2 不宜过接近 1 也不宜过大，以保证测量精度）。  
  - 对极高透水性土样，变水头法测定时间过短，稳定性差；对极低透水性土样需长时间试验并注意蒸发误差。  
  - 与恒定水头法一样，要求单相稳态、达西条件成立。  
- 关联标准/规程：实施前复核现行版本（参考土工试验标准与室内渗透试验方法）  
- 建议页面控件：  
  - 输入框：a、A（或样品直径）、L、h1、h2、t（单位切换）  
  - 自动选择 ln 或 log10 公式、结果不确定度估计、稳态与饱和性检查清单  
- 是否适合自动计算：是

### SUB-03
- 二级分类：排水与防渗
- 名称：排水沟流量计算（明渠——曼宁公式）
- 定义与适用场景：  
  曼宁公式用于近似计算均匀稳态开敞明渠（自然沟渠、人工排水沟、路肩排水沟等）中的平均流量。适用于粘土衬砌、土质沟、砾石或混凝土衬砌等多种断面，需满足渐变缓和、流态接近稳定条件。
- 公式或操作步骤：  
  1. 计算断面面积 A（m^2）与湿周 P（m），水力半径 R = A / P（m）。  
  2. 取适当曼宁糙率系数 n（无量纲），测定沟底坡 S（比降，无量纲）。  
  3. 应用曼宁公式：Q = (1/n) · A · R^(2/3) · S^(1/2)  
- 全部变量与单位：  
  - Q：流量，单位 m^3/s  
  - n：曼宁糙率系数（无单位）  
  - A：流通断面面积，单位 m^2  
  - R：水力半径，单位 m（R = A / P）  
  - P：湿周，单位 m（接触水面的周长）  
  - S：床面坡度/比降（无单位，例如 0.01 表示 1%）  
- 完整数值示例（矩形断面）：  
  - 断面宽 b = 1.00 m；水深 y = 0.40 m → A = b·y = 0.40 m^2；P = b + 2y = 1.00 + 0.80 = 1.80 m；R = 0.40 / 1.80 = 0.2222 m  
  - 取 n = 0.025（土底、草沟或普通密实土），坡度 S = 0.01（1%）  
  - Q = (1/0.025) · 0.40 · (0.2222)^(2/3) · (0.01)^(1/2) ≈ 40 · 0.40 · 0.367 · 0.1 ≈ 0.587 m^3/s
- 结果解释：  
  - 计算得到的 Q 为在给定水深与坡度下的理论正常流量。用于排水沟尺寸校核、检验设计流量是否满足排水目标并判断是否需增加断面或提升坡度。设计时需考虑淤积、植被阻力、暴雨峰值及安全余量（自由舱限、高程余量）。  
- 注意事项与禁用边界：  
  - 曼宁公式为经验公式，适用于湍流条件及缓变稳定流；对局部急变流、溢流、沉积不均或含大量固体输移的流体准确性下降。  
  - n 值受材料、衬砌、植被和年龄影响，应根据现场条件选取或通过实测校正。  
  - 当流态接近临界或超临界时（Froude 数接近或超过 1），仅用曼宁公式不够，应做能量与流态分析。  
  - 对非均匀断面（复合断面、桥下收缩等）需分段或采用数值模拟方法。  
- 关联标准/规程：实施前复核现行版本（参考水利工程明渠设计规范、道路排水相关标准）  
- 建议页面控件：  
  - 断面选择器（矩形/三角/梯形/用户自定义）并自动计算 A、P、R；输入 b、y、坡度 S、糙率 n；单位切换；输出 Q 与警示（超临界、淤积风险）  
  - 图形预览（断面与水位）、推荐 n 值下拉、自由舱限计算器  
- 是否适合自动计算：是

### SUB-04
- 二级分类：排水与防渗（术语）
- 名称：水力半径
- 英文/缩写：Hydraulic radius（R）
- 定义：  
  水力半径 R 定义为流通断面面积 A 与湿周 P 的比值，R = A / P。它是衡量明渠或管道内流体受壁面摩阻影响程度的几何参数，常用于曼宁公式、能量与速度计算中。
- 现场示例：  
  - 矩形明渠（宽 b = 1.0 m，深 y = 0.4 m）：A = 0.4 m^2；P = 1.8 m；R = 0.4 / 1.8 = 0.222 m。  
  - 圆管充满时：R = 管径 / 4；当部分淹没时需按实际湿周与面积计算。
- 易混淆项：  
  - 与“水力直径（hydraulic diameter）”的差异：水力直径通常用于管道或通风/输送中定义为 Dh = 4A/P，与水力半径仅是比例关系 Dh = 4R。  
  - 不等同于流体的等效直径或水深：R 与水深 y 在窄深比断面中并不相等，具体需通过 A 与 P 计算。  
  - 不同断面形状在相同水深下 R 不同，直接影响流速与流量计算，因此不可用简单经验代替精确计算。

### 材料配比与含水率调整

## SUB-01
- 二级分类：材料配比与含水率调整  
- 名称：施工现场加水量计算（基于目标干密度）  
- 定义与适用场景：  
  用于将试验室确定的目标含水率或施工配合比，换算为施工现场每立方米土体需要额外加入的水量。适用于土工路基压实、夯实或稳定土拌合施工前的加水量计算。强调：参考值不得替代试拌，现场必须先确认初始含水率与干密度。  
- 公式或操作步骤：  
  1. 确定目标干密度 ρ_d（kg/m³）及目标含水率 w_t（小数表示，如12%→0.12），以及现场初始含水率 w_i（小数表示）。  
  2. 计算每立方米干土质量：M_dry = ρ_d（kg/m³）。  
  3. 计算每立方米需额外加水量（质量基）：W_add = M_dry × (w_t - w_i)（kg/m³）。  
  4. 若需要体积（升）：V_add(L/m³) ≈ W_add (kg)（假定水密度≈1 kg/L）。  
- 全部变量与单位：  
  - ρ_d — 目标干密度，单位 kg/m³  
  - w_t — 目标含水率，单位（无量纲，小数）或 %（换算为小数）  
  - w_i — 现场初始含水率，单位（无量纲，小数）或 %  
  - M_dry — 干土质量，单位 kg/m³（等于 ρ_d）  
  - W_add — 每立方米需加水质量，单位 kg/m³（等同于 L/m³）  
- 完整数值示例：  
  假设目标干密度 ρ_d = 1800 kg/m³，目标含水率 w_t = 12%（0.12），现场初始含水率 w_i = 8%（0.08）。  
  M_dry = 1800 kg/m³  
  W_add = 1800 × (0.12 − 0.08) = 1800 × 0.04 = 72 kg/m³ ≈ 72 L/m³  
- 结果解释：  
  结果表示每立方米干土需额外加入72 kg（≈72 L）水才能把含水率从8%提高到12%并达到目标干密度前提下的水量需求。若计算值为负数，表示现场含水率高于目标，需排水或风干处理。  
- 注意事项与禁用边界：  
  - 所有含水率以干质量基(w = m_water/m_dry)表示并应以小数输入；若使用%形式需先除以100。  
  - 公式假定土体按目标干密度均匀并且不考虑材料吸水/释放、骨料吸水率、化学用水消耗（例如水泥吸水/水化耗水），见 SUB-04 修正项。  
  - 对于含盐土、膨胀土、含机理水变化大的材料，现场预试验与观察必需。  
  - 不适用于需要控制总水胶比的水泥稳定土拌合设计（应结合水泥用量与水胶比共同计算）。  
  - 参考值不得替代试拌；施工前应做现场小试并调整。  
- 关联标准/规程：实施前复核现行版本（如《路基土压实试验规程》《土工试验规程》等）  
- 建议页面控件：  
  - 数字输入：目标干密度（kg/m³）、目标含水率（%）、现场含水率（%）  
  - 单位选择提示（% 或 小数）  
  - 输出显示：需加水量（kg/m³ 和 L/m³）、正/负提示（需加水/需排水）  
  - “包含吸水修正”复选框（勾选后调用 SUB-04 修正）  
- 是否适合自动计算：是

## SUB-02
- 二级分类：材料配比与含水率调整  
- 名称：由试验室配合比换算为施工配合比（按干质量基）  
- 定义与适用场景：  
  将实验室配合比（通常以干土质量为基准给出：水%w_lab、胶凝材料% c%（如水泥占干土质量的百分数））换算为施工现场每立方米需投料质量（kg/m³）和需额外加水量的计算方法。适用于水泥土、石灰土或粉煤灰稳定土从实验室试验结果向施工配方转换的初步计算。强调：实验室配合比为试验参考，施工必须先试拌。  
- 公式或操作步骤：  
  1. 输入：目标干密度 ρ_d（kg/m³）、试验室配合比：水 w_lab（小数）、胶凝剂 c_pct（占干土质量的%或小数）、现场初始含水率 w_i（小数）。  
  2. 计算每立方米干土质量：M_dry = ρ_d（kg/m³）。  
  3. 计算按干质量的各材料质量：  
     - 胶凝剂质量（kg/m³）：M_c = c_pct × M_dry  
     - 试验室总用水质量（理论、kg/m³）：W_total_lab = w_lab × M_dry  
  4. 计算现场需额外加水（不考虑吸/放水材料的情况下）：W_add = M_dry × (w_lab - w_i)（kg/m³）  
  5. 若现场需按体积供料或按袋计算，继续用材料堆积密度或单袋质量换算（见 SUB-03）。  
- 全部变量与单位：  
  - ρ_d — 目标干密度，单位 kg/m³  
  - w_lab — 实验室配合比含水率（干质量基），单位（小数）  
  - c_pct — 胶凝剂用量（占干土质量），单位（小数或%）  
  - w_i — 现场初始含水率，单位（小数）  
  - M_dry — 干土质量，单位 kg/m³（=ρ_d）  
  - M_c — 胶凝剂质量，单位 kg/m³  
  - W_total_lab — 试验室配合所需总水质量，单位 kg/m³  
  - W_add — 需额外加入的水，单位 kg/m³  
- 完整数值示例：  
  设 ρ_d = 1900 kg/m³；试验室配合比：c_pct = 6%（0.06），w_lab = 12%（0.12）；现场初始含水率 w_i = 7%（0.07）。  
  M_dry = 1900 kg/m³  
  M_c = 0.06 × 1900 = 114 kg/m³（即水泥114 kg/立方米干土）  
  W_total_lab = 0.12 × 1900 = 228 kg/m³（总用水）  
  W_add = 1900 × (0.12 − 0.07) = 1900 × 0.05 = 95 kg/m³（需加水95 L/立方米）  
- 结果解释：  
  - 每立方米干土需水泥114 kg；试验室推荐总用水228 kg，其中现场已有水量按 w_i 对应为 M_dry×w_i = 133 kg，故需补充95 kg水以满足试验室配合比。  
  - 施工中可据此进行投料计量与加水控制，但须结合材料含水（砂、碎石）、胶凝剂吸水与水化耗水（见 SUB-04）修正，并通过现场试拌确认。  
- 注意事项与禁用边界：  
  - c_pct、w_lab 均按干土质量基给出；若实验室配合比为湿质量基或其它基准，必须先统一换算。  
  - 不考虑胶凝材料包装含水、骨料自由水或吸水特性，实际投料需修正。  
  - 对于要求控制水胶比（w/c 或 w/(cement+flyash)）的设计，必须同时满足强度与耐久性要求，简单按百分比转换可能不足。  
  - 参考配合不得替代现场试拌验证强度、工作性与压实性。  
- 关联标准/规程：实施前复核现行版本（如《水泥稳定土施工技术规范》《路基工程施工规程》等）  
- 建议页面控件：  
  - 数字输入：目标干密度（kg/m³）、试验含水率（%）、胶凝剂百分比（%）、现场含水率（%）  
  - 输出：每立方米胶凝剂质量（kg/m³）、理论总用水（kg/m³）、需补加水（kg/m³）  
  - 可选项：按袋规格（kg/袋）自动换算袋数；“考虑材料含水/吸水”复选项（调用 SUB-04）  
- 是否适合自动计算：是

## SUB-03
- 二级分类：材料配比与含水率调整  
- 名称：水泥用量从百分比向袋数/体积的换算（施工投料计算）  
- 定义与适用场景：  
  将设计或试验中以“占干土质量百分比”给出的水泥用量，换算为施工现场实际投料单位（kg/m³、袋数/m³ 或 体积 m³/m³），以便称量与配料。适用于水泥稳定土、砂砾土掺水泥等场景。强调：实际投料前应校核水泥含水率与堆积密度，进行试拌。  
- 公式或操作步骤：  
  1. 输入：目标干密度 ρ_d（kg/m³）；水泥百分比 c_pct（小数）；水泥袋重 Bag_w（kg/袋，常用50 kg/袋）；（可选）水泥堆积密度 ρ_c_bulk（kg/m³）用于体积换算。  
  2. 计算每立方米干土需水泥质量：M_c = c_pct × ρ_d（kg/m³）。  
  3. 换算成袋数：N_bags = M_c / Bag_w（袋/m³），取整与剩余管理由现场决定。  
  4. 若需体积（m³ 水泥 / m³ 土）：V_c = M_c / ρ_c_bulk（m³/m³）。  
- 全部变量与单位：  
  - ρ_d — 目标干密度，单位 kg/m³  
  - c_pct — 水泥百分比（占干土质量），单位（小数或%）  
  - M_c — 水泥质量，单位 kg/m³  
  - Bag_w — 水泥每袋质量，单位 kg/袋  
  - N_bags — 每立方米所需水泥袋数，单位 袋/m³  
  - ρ_c_bulk — 水泥堆积密度（或体积密度），单位 kg/m³（用于体积换算）  
  - V_c — 水泥体积（m³/m³）  
- 完整数值示例：  
  设 ρ_d = 1900 kg/m³，c_pct = 6%（0.06），Bag_w = 50 kg/袋，ρ_c_bulk = 1500 kg/m³（示例堆积密度）。  
  M_c = 0.06 × 1900 = 114 kg/m³  
  N_bags = 114 / 50 = 2.28 袋 → 现场投料可设为 2 袋 + 14 kg（或向上取整并记录余量）  
  V_c = 114 / 1500 = 0.076 m³/m³  
- 结果解释：  
  - 每立方米干土需水泥114 kg（≈2.28袋）；施工时通常按袋计量并需考虑散装称量误差，应确定配料效率与余量管理。  
  - 体积换算便于散装料仓储与运输安排。  
- 注意事项与禁用边界：  
  - 水泥袋重、堆积密度及实际含水率会影响最终投料质量（潮湿水泥可能含水）；散装计量误差需控制。  
  - 对于高精度工程（抗压强度敏感），切勿仅按理论换算直接施工，必须做现场试拌与强度检验。  
  - 当水泥用量超出经济或强度需要范围（过高或过低）应重审配比设计；过高会引起裂缝、成本浪费，过低影响强度与耐久性。  
- 关联标准/规程：实施前复核现行版本（如《水泥质量及使用规范》《水泥稳定土施工规范》等）  
- 建议页面控件：  
  - 数字输入：目标干密度（kg/m³）、水泥百分比（%）、单袋质量（kg/袋）、水泥堆积密度（kg/m³，可选）  
  - 输出：水泥质量（kg/m³）、袋数（袋/m³）、体积（m³/m³）及建议取整策略下的袋数与剩余质量提示  
- 是否适合自动计算：是

## SUB-04
- 二级分类：材料配比与含水率调整  
- 名称：含水率修正与材料吸/放水效应（吸水量/水化耗水校正）  
- 定义与适用场景：  
  在将试验室配合比转为施工配比并计算现场加水量时，必须修正因胶凝材料吸水（表面吸附）、水化耗水、骨料/粉料吸水或释放的水量。本条目提供通用修正公式与操作步骤，适用于水泥、粉煤灰、石灰、砂、碎石等常见材料的水量影响估算。强调：各项参数须通过材料试验获取；试算为参考，不能替代现场试拌与强度验证。  
- 公式或操作步骤：  
  1. 基础需加水量（见 SUB-01/SUB-02）：W_add_basic = M_dry × (w_t - w_i)（kg/m³）。  
  2. 计算各材料对水量的影响（以质量基计，正值表示释放水到体系，负值表示吸收/消耗水）：对第 i 种材料：ΔW_i = M_i × α_i，其中：  
     - M_i 为该材料投加质量（kg/m³），如水泥、粉煤灰、骨料等；  
     - α_i 为该材料的“单位质量水量影响系数”（kg_water absorbed(+)/released(-) per kg_material）；注：吸水为负值（从混合体系吸水），释放为正值。  
  3. 若考虑水泥水化耗水（理论或经验值）：可设 α_c_hydration ≈ -k（kg水/kg水泥），常用经验值约 -0.25（即每1 kg水泥完全水化消耗约0.25 kg水），但该值随配合比与水化程度不同，应以试验为准并在初期施工中保守估计。  
  4. 计算净修正量：ΔW_total = Σ_i ΔW_i（kg/m³）。  
  5. 修正后的需加水量：W_add_corrected = W_add_basic − ΔW_total（kg/m³）。（注意符号约定）  
  6. 若 W_add_corrected < 0，则表示现场现有自由水足以满足并可能出现过湿，应采用排水/风干或减少外加水。  
- 全部变量与单位：  
  - M_dry — 干土质量，kg/m³  
  - w_t — 目标含水率（小数）  
  - w_i — 现场初始含水率（小数）  
  - W_add_basic — 基础需加水量（kg/m³）  
  - M_i — 第 i 种材料投加质量（kg/m³）  
  - α_i — 第 i 种材料单位质量水量影响系数（kg_water/kg_material，吸水为负，释放为正）  
  - ΔW_i — 第 i 种材料对水量的影响（kg/m³）  
  - ΔW_total — 总修正水量（kg/m³）  
  - W_add_corrected — 修正后的需加水量（kg/m³）  
- 完整数值示例：  
  场景：按 SUB-02 计算，M_dry = 1900 kg/m³，w_t = 0.12，w_i = 0.07 → W_add_basic = 95 kg/m³。投加材料：水泥 M_c = 114 kg/m³，粉煤灰 M_f = 30 kg/m³，砂（潮湿）M_s = 使用土体中固有已计入 w_i，不单列。取经验系数：α_c_hydration = -0.25 kg/kg（水泥水化耗水，示例值）；粉煤灰 α_f = -0.05 kg/kg（轻微吸水）；若骨料带余水 μ_agg = +0.01（释放），这里忽略。  
  ΔW_c = 114 × (−0.25) = −28.5 kg/m³（水泥消耗）  
  ΔW_f = 30 × (−0.05) = −1.5 kg/m³（粉煤灰吸水）  
  ΔW_total = −28.5 − 1.5 = −30 kg/m³  
  W_add_corrected = 95 − (−30) = 125 kg/m³ ≈ 125 L/m³  
  解释：考虑水泥等材料吸/耗水后，需额外加入水量增加到125 L/m³以满足目标含水率与试验室配合。  
- 结果解释：  
  - 修正量可显著影响现场加水决策：常见情形是胶凝材料消耗/吸收水导致需加水量增加；相反如果使用含水率高的骨料可能减少外加水。  
  - 水泥水化耗水并非瞬时完全发生，谨慎采用并优先以试拌结果为准；初期施工可采用保守（较高）加水量并通过分批观察沉降/强度变化调整。  
- 注意事项与禁用边界：  
  - α_i 参数应由材料吸水试验（如吸水率、含水率、自由水测定）和水化研究确定；使用经验值时需注明并在施工初期通过小试验证。  
  - 水泥水化耗水的理论值（0.25 kg/kg）基于完全水化条件，实际现场并不完全立即发生；直接用该值可能高估即时耗水，建议作为保守估计且需结合现场观测。  
  - 对于含有有机物、膨胀矿物或盐分的土体，水迁移行为复杂，单一线性系数可能失真，此类情形需进阶试验与咨询。  
  - 禁止在未试验材料吸水特性且工程关键性强（路基承载、抗冻）时仅凭经验系数直接施工。  
- 关联标准/规程：实施前复核现行版本（如相关土工材料试验方法与施工规范）  
- 建议页面控件：  
  - 数字输入：各材料质量（kg/m³）、各材料α系数（kg/kg）、基础需加水量（自动带入或手动输入）  
  - 输出：各材料ΔW_i、ΔW_total、修正后需加水量（kg/m³ 与 L/m³）、警示（若<0）  
  - “使用经验系数/使用试验系数”切换按钮及材料吸水试验上传功能（附件）  
- 是否适合自动计算：是

### 专业术语

### TERM-01
- 二级分类：术语 — 路基/路床
- 名称（中文）：路基
- 英文/缩写：Subgrade
- 定义：路基是指公路、铁路等路线工程中，直接承受路面、路床以及车辆或列车荷载并将荷载传递到下部土体的人工处理或原状土体部分，包括路堤、路槽及路基面以上和以下一定深度内的土体与结构。
- 现场示例：高速公路行车道下方经过整平、压实的土体层与必要的排水层构成的承载部分。
- 易混淆项：
  - 路床（roadbed）：常被误作路基的同义词，但路床通常指路基顶面及其上设置的基层和路面承载的整体单元；路基更广泛包括路堤、路槽及其周边土体处理。
  - 基床/基层：基层是路面结构里的材料层，不等同于路基。

### TERM-02
- 二级分类：术语 — 路基/路床
- 名称（中文）：路床
- 英文/缩写：Roadbed
- 定义：路床一般指路基顶面（即路基面）及其上直接承载基层、底基层和面层的部分，通常强调路面结构下的承载层和与之直接接触的路基面整修形状与质量。
- 现场示例：已整平并达到设计高程与压实度的路基顶面，供铺设底基层的工作面。
- 易混淆项：
  - 与路基的关系：路床侧重路基顶面与上部结构的接触和支承功能，路基范围更广。
  - 与基层：基层是路床之上的结构层，不是土体本身。

---

### TERM-03
- 二级分类：术语 — 路堤/路槽
- 名称（中文）：路堤
- 英文/缩写：Embankment
- 定义：路堤是为达到设计路线高程而用土石等材料填筑形成的高出原地面的土工结构。路堤按材料可分为工程填土、挖方回填或人工堆筑材料。
- 现场示例：在低洼地段把土方运来分层压实，逐步填筑到设计高程形成的道路高出地面部分。
- 易混淆项：
  - 路堤与填土：路堤是结构类型，填土是施工动作；高堤与一般填土在稳定性、压实规范上有更严格要求。
  - 路堤与路基：路堤是路基的一种构成形式（填方路段），与挖方路段的路基不同。

---

### TERM-04
- 二级分类：术语 — 路基/边坡
- 名称（中文）：路槽
- 英文/缩写：Cut (Road Cutting)
- 定义：路槽是为达到设计路线高程而将地面土体挖除形成的下凹部分，其边坡及底面构成路基的一部分。路槽边坡需按稳定性与排水要求处理。
- 现场示例：山区公路需削坡形成的降低地表高程的断面，挖出的土可用于路堤回填。
- 易混淆项：
  - 路槽与路堤：路槽是挖方段（路面低于原地面），路堤是填方段（路面高于原地面）。
  - 路槽坡面与边坡防护：挖方后的边坡不是自然稳定体，需按工程要求处理。

### TERM-05
- 二级分类：术语 — 含水率/压实
- 名称（中文）：最佳含水率
- 英文/缩写：Optimum Moisture Content (OMC)
- 定义：在标准或改良实验压实试验（如标准击实/改良击实）中，使土样达到最大干密度时对应的含水率称为最佳含水率。是指导施工压实时调节土料含水率以获得最大干密度的重要参数。
- 现场示例：黏土通过击实试验得到最佳含水率为18%，施工中通过加水或控水将现场含水率调整到接近该值再分层压实。
- 易混淆项：
  - 最佳含水率与现场最适含水率：实验室OMC是试验条件下的参考值，施工现场应结合压实能量、含水率换算（试验室配合比与施工配合比）、材料变化及温湿条件进行试配确认，不能直接替代现场配合比。
  - 与自然含水率：自然含水率是现场原状土的含水率，不等同于OMC。

---

### TERM-06
- 二级分类：术语 — 压实度/质量控制
- 名称（中文）：压实度（或压实系数）
- 英文/缩写：Degree of Compaction / Compaction Degree
- 定义：压实度通常为现场实测干密度（或湿密度）与规定参考干密度（如实验室标准击实最大干密度或设计要求的干密度）之比，表示土体被压实达到设计密实程度的比值，常以百分比表示。
- 现场示例：设计规定路基须达到≥95%标准击实最大干密度，现场抽样经测定干密度为1.88 g/cm³，若标准击实最大干密度为1.98 g/cm³，则压实度=1.88/1.98=94.9%（未达标）。
- 易混淆项：
  - 压实度与相对密度：相对密度（Dr）用于无粘性颗粒土（砂类）描述颗粒紧密度，不等同于以最大干密度为基准的压实度。
  - 使用哪个参考密度：需区分是以标准击实还是改良击实的最大干密度作为参考，或以设计指定的参考密度；不同依据会导致压实度计算差异。

### TERM-07
- 二级分类：术语 — 压实/试验
- 名称（中文）：最大干密度
- 英文/缩写：Maximum Dry Density (MDD)
- 定义：在标准（或改良）击实试验条件下，通过改变含水率得到的最大干密度值，代表在该击实能量下土料所能达到的最大干密实状态的干密度。
- 现场示例：砂土经改良击实试验的最大干密度为2.05 g/cm³，对应最佳含水率为10%。
- 易混淆项：
  - 与自然干密度：自然干密度是现场未压实或原状土的干密度，通常低于MDD。
  - 与湿密度：湿密度包含水分质量，不可直接用于与MDD比较，压实度计算需用干密度或进行换算。

### TERM-08
- 二级分类：术语 — 力学性能/承载力
- 名称（中文）：加州承载比
- 英文/缩写：California Bearing Ratio (CBR)
- 定义：CBR是评价土料或路基、基层承载能力的一种经验指数，通过在标准条件下用贯入试验测得试样在特定沉入量（通常为2.54 mm或5.08 mm）时的贯入阻力与标准砾石贯入阻力之比，表示为百分比。
- 现场示例：路基回填材料经实验室CBR试验得CBR=18%，用于判断是否满足路基设计对承载力的要求或需做改良处理。
- 易混淆项：
  - CBR与强度参数：CBR是经验性的承载指标，不等同于土的抗剪强度（如φ、c）或弹性模量，但可用于路面结构设计经验换算。
  - 实验条件敏感性：CBR受含水率、密实度、颗粒级配和试验养护条件影响，现场原位CBR与实验室标准样本CBR可能不同，需按规范或设计要求区分。

### TERM-09
- 二级分类：术语 — 含水率/质量控制
- 名称（中文）：含水率
- 英文/缩写：Moisture Content (w)
- 定义：含水率是指土中水的质量与土中固体颗粒质量之比，通常以百分比表示，计算公式为 w = (Mw / Ms) × 100%，其中Mw为水质量，Ms为固体颗粒质量。
- 现场示例：取样检测后得到湿重及干燥后的干重，计算出现场含水率为12.4%，用于判断是否需要加水或降水以达到压实施工要求。
- 易混淆项：
  - 含水率与饱和度：饱和度是孔隙中水充满程度的比例，依赖孔隙比；含水率是质量比，两者概念不同但相互关联。
  - 湿密度/干密度：含水率不能直接等同于湿密度或干密度，但可用于互相换算时的参数。

### TERM-10
- 二级分类：术语 — 填土/工程填方
- 名称（中文）：工程填土（回填土）
- 英文/缩写：Engineered Fill / Fill Material
- 定义：工程填土指按设计要求选择、处理、摊铺并分层压实以满足强度、变形和排水等性能要求的土体材料。包含天然土、改良土或进口材料，需满足规定的粒径组成、含水率和密实度标准。
- 现场示例：桥台回填使用经筛分和掺加粉煤灰改良后的土料，分层≤30 cm湿法压实至≥95%标准击实最大干密度。
- 易混淆项：
  - 工程填土与弃土：工程填土强调经控制并满足规范要求，弃土是施工中临时堆放的土，未经处理与控制。
  - 现场土与设计配合比：试验室配合比仅作参考，必须通过现场试配（含水率换算）确认工程填土的施工配合比与压实措施。
