### <a id="item-1"></a>1. 坐标正算
- **二级分类**：坐标与方位角计算
- **定义和适用场景**：已知起点坐标、平距和方位角，计算终点坐标。
- **公式/步骤**：
  ```
  X_B = X_A + D * cos(α)
Y_B = Y_A + D * sin(α)
  ```
- **全部变量单位**：X_A, Y_A, X_B, Y_B: m; D: m; α: rad或°
- **完整数值示例**：起点(100, 100), D=50m, α=45°。X_B = 100 + 50*cos(45°) = 135.355m, Y_B = 100 + 50*sin(45°) = 135.355m
- **结果解释**：终点坐标为(135.355, 135.355)。
- **注意事项与禁用边界**：注意坐标系的X、Y方向（测量坐标系X为北向）。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：数值输入框(X,Y,D,α)
- **自动计算适用性**：高

### <a id="item-2"></a>2. 坐标反算
- **二级分类**：坐标与方位角计算
- **定义和适用场景**：已知两点坐标，计算两点间的平距和坐标方位角。
- **公式/步骤**：
  ```
  D = sqrt((X_B - X_A)^2 + (Y_B - Y_A)^2)
α = arctan((Y_B - Y_A) / (X_B - X_A))
  ```
- **全部变量单位**：X_A, Y_A, X_B, Y_B: m; D: m; α: rad或°
- **完整数值示例**：起点(100,100), 终点(135.355, 135.355)。D = sqrt(35.355^2 + 35.355^2) = 50m, α = arctan(1) = 45°
- **结果解释**：距离50m，方位角45°。
- **注意事项与禁用边界**：需根据象限调整arctan计算出的方位角。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：数值输入框(两点坐标)
- **自动计算适用性**：高

### <a id="item-3"></a>3. 方位角推算
- **二级分类**：坐标与方位角计算
- **定义和适用场景**：已知前一边方位角和转折角，推算下一边方位角。
- **公式/步骤**：
  ```
  α_n = α_{n-1} + β ± 180° (左角取+, 右角取-)
  ```
- **全部变量单位**：α, β: ° ' "
- **完整数值示例**：前边方位角120°, 左转角100°。α_n = 120° + 100° - 180° = 40°
- **结果解释**：下一边方位角为40°。
- **注意事项与禁用边界**：结果若大于360°需减360°，小于0°需加360°。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：角度输入框(度分秒)
- **自动计算适用性**：高

### <a id="item-4"></a>4. 两点间空间距离计算
- **二级分类**：坐标与方位角计算
- **定义和适用场景**：已知两点三维坐标，计算空间直线距离。
- **公式/步骤**：
  ```
  S = sqrt((X_B - X_A)^2 + (Y_B - Y_A)^2 + (Z_B - Z_A)^2)
  ```
- **全部变量单位**：X, Y, Z, S: m
- **完整数值示例**：点A(0,0,0), 点B(3,4,12)。S = sqrt(3^2 + 4^2 + 12^2) = 13m
- **结果解释**：空间距离为13m。
- **注意事项与禁用边界**：地球曲率影响在短距离内可忽略。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：数值输入框(三维坐标)
- **自动计算适用性**：高

### <a id="item-5"></a>5. 坐标转换(四参数)
- **二级分类**：坐标与方位角计算
- **定义和适用场景**：同一基准下不同平面直角坐标系之间的转换。
- **公式/步骤**：
  ```
  X = ΔX + (1+m)(x*cosθ - y*sinθ)
Y = ΔY + (1+m)(x*sinθ + y*cosθ)
  ```
- **全部变量单位**：X,Y,x,y,ΔX,ΔY: m; m: 无量纲; θ: rad
- **完整数值示例**：平移(10,10), 旋转0°, 缩放0。点(5,5)转换后为(15,15)。
- **结果解释**：转换后坐标为(15,15)。
- **注意事项与禁用边界**：需至少2个公共点求取参数。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：参数配置表单
- **自动计算适用性**：中

### <a id="item-7"></a>7. 水准高程计算
- **二级分类**：高程与水准测量
- **定义和适用场景**：已知后视高程和前后视读数，计算前视高程。
- **公式/步骤**：
  ```
  H_B = H_A + a - b
  ```
- **全部变量单位**：H_A, H_B, a, b: m
- **完整数值示例**：H_A=100m, 后视a=1.5m, 前视b=1.2m。H_B = 100 + 1.5 - 1.2 = 100.3m
- **结果解释**：前视点高程为100.3m。
- **注意事项与禁用边界**：仪器视线高程应控制在标尺范围内。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《国家三、四等水准测量规范》GB/T 12898-2009
- **建议页面控件**：数值输入框
- **自动计算适用性**：高

### <a id="item-8"></a>8. 水准路线闭合差计算
- **二级分类**：高程与水准测量
- **定义和适用场景**：计算闭合或附合水准路线的高程闭合差。
- **公式/步骤**：
  ```
  f_h = Σh_测 - Σh_理
  ```
- **全部变量单位**：f_h, h: mm
- **完整数值示例**：实测高差之和+15mm, 理论高差之和0mm。f_h = +15mm
- **结果解释**：闭合差为+15mm。
- **注意事项与禁用边界**：必须与容许闭合差比较，超限则重测。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《国家三、四等水准测量规范》GB/T 12898-2009
- **建议页面控件**：表格输入(测段高差)
- **自动计算适用性**：高

### <a id="item-9"></a>9. 水准闭合差平差(按距离)
- **二级分类**：高程与水准测量
- **定义和适用场景**：将闭合差按测段距离成正比分配。
- **公式/步骤**：
  ```
  v_i = -f_h * (L_i / ΣL)
  ```
- **全部变量单位**：v_i, f_h: mm; L_i: km
- **完整数值示例**：闭合差+10mm, 总长10km, 某段长2km。v = -10 * (2/10) = -2mm
- **结果解释**：该测段改正数为-2mm。
- **注意事项与禁用边界**：改正数之和必须等于闭合差反号。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：数据表格
- **自动计算适用性**：高

### <a id="item-10"></a>10. 水准闭合差平差(按测站数)

- **结果解释**：该测段改正数为-3mm。
- **注意事项与禁用边界**：适用于山区或各站距离相近的情况。 系统仅计算不自动判定。实施前复核现行版本。

### <a id="item-11"></a>11. 三角高程测量
- **二级分类**：高程与水准测量
- **定义和适用场景**：通过测量垂直角和距离计算两点高差。
- **公式/步骤**：
  ```
  h = D * tan(α) + i - v + f
  ```
- **全部变量单位**：h, D, i, v, f: m; α: rad或°
- **完整数值示例**：D=100m, α=5°, i=1.5m, v=1.6m, f忽略。h = 100*tan(5°) + 1.5 - 1.6 = 8.649m
- **结果解释**：高差为8.649m。
- **注意事项与禁用边界**：长距离需考虑地球曲率和大气折光差(f)。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：多参数输入框
- **自动计算适用性**：高

### <a id="item-12"></a>12. 跨河水准测量计算
- **二级分类**：高程与水准测量
- **定义和适用场景**：用于跨越宽阔水域的高程传递。
- **公式/步骤**：
  ```
  h = (h_正 + h_反) / 2
  ```
- **全部变量单位**：h: m
- **完整数值示例**：正测高差1.234m，反测高差1.236m。h = 1.235m
- **结果解释**：跨河高差为1.235m。
- **注意事项与禁用边界**：必须采用双向同步或交替观测消除折光影响。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《国家三、四等水准测量规范》GB/T 12898-2009
- **建议页面控件**：正反观测值输入
- **自动计算适用性**：高

### <a id="item-14"></a>14. 导线坐标增量闭合差
- **二级分类**：导线与控制网
- **定义和适用场景**：计算导线在X和Y方向的闭合差。
- **公式/步骤**：
  ```
  f_x = ΣΔx, f_y = ΣΔy
  ```
- **全部变量单位**：f_x, f_y, Δx, Δy: m
- **完整数值示例**：闭合导线ΣΔx = 0.05m, ΣΔy = -0.04m。
- **结果解释**：X闭合差0.05m，Y闭合差-0.04m。
- **注意事项与禁用边界**：坐标增量闭合差用于计算全长闭合差。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：增量列表
- **自动计算适用性**：高

### <a id="item-15"></a>15. 导线全长相对闭合差
- **二级分类**：导线与控制网
- **定义和适用场景**：评估导线测量整体精度。
- **公式/步骤**：
  ```
  K = 1 / (ΣD / sqrt(f_x^2 + f_y^2))
  ```
- **全部变量单位**：K: 无量纲分数; D, f_x, f_y: m
- **完整数值示例**：全长1000m, f_x=0.03m, f_y=0.04m。f=0.05m, K = 1 / (1000/0.05) = 1/20000
- **结果解释**：相对闭合差为1/20000。
- **注意事项与禁用边界**：应满足相应等级导线的精度要求。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：全长与闭合差输入
- **自动计算适用性**：高

### <a id="item-16"></a>16. 坐标增量平差
- **二级分类**：导线与控制网
- **定义和适用场景**：将坐标闭合差按边长比例分配。
- **公式/步骤**：
  ```
  v_x = -f_x * (D_i / ΣD)
v_y = -f_y * (D_i / ΣD)
  ```
- **全部变量单位**：v, f: m; D: m
- **完整数值示例**：f_x=0.1m, 总长100m, 段长10m。v_x = -0.1 * (10/100) = -0.01m
- **结果解释**：该段X坐标改正数为-0.01m。
- **注意事项与禁用边界**：平差后增量之和必须为0（闭合导线）。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：数据表格
- **自动计算适用性**：高

### <a id="item-17"></a>17. 交会定点(前方交会)
- **二级分类**：导线与控制网
- **定义和适用场景**：已知两点坐标及观测角度，计算未知点坐标。
- **公式/步骤**：
  ```
  X_P = (X_A*cotβ + X_B*cotα + Y_B - Y_A) / (cotα + cotβ)
  ```
- **全部变量单位**：X, Y: m; α, β: rad或°
- **完整数值示例**：A(0,0), B(100,0), α=45°, β=45°。X_P = 50m, Y_P = 50m
- **结果解释**：交会点坐标为(50, 50)。
- **注意事项与禁用边界**：交会角宜在30°至150°之间。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：坐标与角度输入
- **自动计算适用性**：高

### <a id="item-18"></a>18. 圆曲线切线长计算
- **二级分类**：曲线计算
- **定义和适用场景**：计算圆曲线交点到起终点的切线长度。
- **公式/步骤**：
  ```
  T = R * tan(α / 2)
  ```
- **全部变量单位**：T, R: m; α: rad或°
- **完整数值示例**：R=1000m, 转向角α=60°。T = 1000 * tan(30°) = 577.35m
- **结果解释**：切线长为577.35m。
- **注意事项与禁用边界**：适用于单一圆曲线。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《公路路线设计规范》JTG D20-2017

- **完整数值示例**：X中误差2mm，Y中误差3mm。M = sqrt(4 + 9) = 3.6mm
- **结果解释**：测站平面中误差为3.6mm。
- **注意事项与禁用边界**：设站精度需高于放样点精度要求。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《工程测量规范》GB 50026-2020
- **建议页面控件**：坐标中误差
- **自动计算适用性**：高

### <a id="item-41"></a>41. 基坑土方开挖量(棱台法)
- **二级分类**：构造物工程量计算
- **定义和适用场景**：计算带放坡的独立基坑开挖体积。
- **公式/步骤**：
  ```
  V = H/6 * (A_1 + 4*A_0 + A_2)
  ```
- **全部变量单位**：V: m³; H: m; A_1, A_2, A_0(中截面): m²
- **完整数值示例**：底面积10m², 顶面积20m², 中面积14.5m², 深3m。V = 3/6 * (10 + 58 + 20) = 44m³
- **结果解释**：开挖土方量为44m³。
- **注意事项与禁用边界**：适用于底面和顶面均为矩形的放坡基坑。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《房屋建筑与装饰工程工程量计算规范》GB 50854-2013
- **建议页面控件**：长宽与放坡系数
- **自动计算适用性**：高

### <a id="item-42"></a>42. 管沟土方量计算
- **二级分类**：构造物工程量计算
- **定义和适用场景**：计算带放坡的管沟开挖体积。
- **公式/步骤**：
  ```
  V = (B + m*H) * H * L
  ```
- **全部变量单位**：V: m³; B, H, L: m; m: 放坡系数
- **完整数值示例**：底宽1m, 深2m, 放坡0.5, 长100m。V = (1 + 0.5*2) * 2 * 100 = 400m³
- **结果解释**：管沟土方量为400m³。
- **注意事项与禁用边界**：工作面宽度需加在底宽B中计算。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《房屋建筑与装饰工程工程量计算规范》GB 50854-2013
- **建议页面控件**：沟槽参数输入
- **自动计算适用性**：高

### <a id="item-43"></a>43. 钻孔灌注桩混凝土充盈系数
- **二级分类**：构造物工程量计算
- **定义和适用场景**：实际灌注混凝土量与理论体积的比值。
- **公式/步骤**：
  ```
  K = V_实 / ( π * R^2 * L )
  ```
- **全部变量单位**：K: 无量纲; V_实: m³; R, L: m
- **完整数值示例**：桩径1m, 桩长20m(理论15.7m³), 实际灌注18m³。K = 18 / 15.7 = 1.146
- **结果解释**：充盈系数为1.15。
- **注意事项与禁用边界**：一般要求充盈系数>1.0，过大说明可能扩孔或塌孔。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《建筑地基基础工程施工质量验收标准》GB 50202-2018
- **建议页面控件**：实际方量与桩尺寸
- **自动计算适用性**：高

### <a id="item-44"></a>44. 桥墩实体体积计算
- **二级分类**：构造物工程量计算
- **定义和适用场景**：计算圆柱形或矩形桥墩的混凝土体积。
- **公式/步骤**：
  ```
  V = A * H - V_扣减
  ```
- **全部变量单位**：V, V_扣减: m³; A: m²; H: m
- **完整数值示例**：截面积10m², 高度15m, 扣减预埋管0.5m³。V = 10*15 - 0.5 = 149.5m³
- **结果解释**：桥墩混凝土量为149.5m³。
- **注意事项与禁用边界**：必须扣除体积大于0.3m³的孔洞。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《公路工程预算定额》JTG/T 3832-2018
- **建议页面控件**：截面与高度参数
- **自动计算适用性**：高

### <a id="item-45"></a>45. 隧道超挖量计算
- **二级分类**：构造物工程量计算
- **定义和适用场景**：实际开挖体积超出设计轮廓体积的部分。
- **公式/步骤**：
  ```
  V_超 = Σ(A_实 - A_设) * L_i
  ```
- **全部变量单位**：V_超: m³; A_实, A_设: m²; L_i: m
- **完整数值示例**：设计面积50m², 实际面积52m², 进尺3m。V_超 = (52 - 50) * 3 = 6m³
- **结果解释**：超挖体积为6m³。
- **注意事项与禁用边界**：超挖部分通常需用同标号混凝土回填。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《公路隧道施工技术规范》JTG/T 3660-2020
- **建议页面控件**：断面面积比对表
- **自动计算适用性**：高

### <a id="item-46"></a>46. 钢筋工程量(理论重量)
- **二级分类**：构造物工程量计算
- **定义和适用场景**：根据钢筋直径和长度计算重量。
- **公式/步骤**：
  ```
  W = 0.00617 * d^2 * L
  ```
- **全部变量单位**：W: kg; d: mm; L: m
- **完整数值示例**：直径20mm，长度10m。W = 0.00617 * 400 * 10 = 24.68kg
- **结果解释**：钢筋重量为24.68kg。
- **注意事项与禁用边界**：0.00617为密度推导系数，适用于常规建筑钢筋。 系统仅计算不自动判定。实施前复核现行版本。
- **关联标准/规程**：《混凝土结构工程施工规范》GB 50666-2011
- **建议页面控件**：直径与长度输入
- **自动计算适用性**：高
