### M-001. 混凝土施工配合比换算
- **编号**：M-001
- **二级分类**：混凝土
- **名称**：混凝土施工配合比换算
- **定义与适用场景**：根据现场砂石含水率，将试验室配合比换算为施工现场实际使用的配合比。注意：参考配比不得替代试配！
- **公式或操作步骤**：施工配合比计算公式：
水 = 试验室用水量 - 砂用量×砂含水率 - 石用量×石含水率
砂 = 试验室砂用量 × (1 + 砂含水率)
石 = 试验室石用量 × (1 + 石含水率)
水泥 = 试验室水泥用量
- **全部变量与单位**：试验室用水量 (kg/m³)
试验室砂用量 (kg/m³)
试验室石用量 (kg/m³)
试验室水泥用量 (kg/m³)
砂含水率 (a, %)
石含水率 (b, %)
- **完整数值示例**：试验室配比：水泥300kg，水180kg，砂700kg，石1200kg。测得砂含水率4%，石含水率1%。
施工砂 = 700×(1+0.04) = 728kg
施工石 = 1200×(1+0.01) = 1212kg
施工水 = 180 - 700×0.04 - 1200×0.01 = 180 - 28 - 12 = 140kg
- **结果解释**：得出实际施工时每立方米混凝土各材料的准确称量值。
- **注意事项与禁用边界**：必须强调试验室配合比与施工配合比的含水率换算，参考配比绝对不能替代试配。雨天施工应增加含水率检测频率。
- **关联标准/规程**：《普通混凝土配合比设计规程》(JGJ 55)（实施前复核现行版本）
- **建议页面控件**：数字输入框（带步长微调）、自动计算只读框
- **是否适合自动计算**：是

### M-002. 混凝土立方体抗压强度计算
- **编号**：M-002
- **二级分类**：混凝土
- **名称**：混凝土立方体抗压强度计算
- **定义与适用场景**：用于评定混凝土的抗压强度等级，适用于标准养护28d的立方体试件。
- **公式或操作步骤**：f_cu = F / A
- **全部变量与单位**：f_cu：混凝土立方体抗压强度 (MPa)
F：破坏荷载 (N)
A：受压面积 (mm²)
- **完整数值示例**：150mm×150mm×150mm试件，破坏荷载为675000N。A = 22500mm²。f_cu = 675000 / 22500 = 30.0 MPa。
- **结果解释**：该试块抗压强度为30.0MPa，若一组三个试块均值为30MPa，满足C30混凝土强度要求。
- **注意事项与禁用边界**：非标准尺寸试件（如100mm或200mm）需乘以尺寸换算系数（0.95或1.05）。
- **关联标准/规程**：《混凝土物理力学性能试验方法标准》(GB/T 50081)（实施前复核现行版本）
- **建议页面控件**：数据表格输入框、自动计算结果框
- **是否适合自动计算**：是

### M-003. 混凝土抗折强度计算
- **编号**：M-003
- **二级分类**：混凝土
- **名称**：混凝土抗折强度计算
- **定义与适用场景**：用于道路、机场道面等有抗折要求的混凝土强度评定。
- **公式或操作步骤**：f_f = (F × l) / (b × h²)
- **全部变量与单位**：f_f：抗折强度 (MPa)
F：破坏荷载 (N)
l：支座间跨度 (mm)
b：试件截面宽度 (mm)
h：试件截面高度 (mm)
- **完整数值示例**：标准试件150×150×600mm，跨度l=450mm，破坏荷载F=35000N。f_f = (35000 × 450) / (150 × 150²) = 15750000 / 3375000 = 4.67 MPa。
- **结果解释**：该试块抗折强度为4.67MPa。
- **注意事项与禁用边界**：若断裂面在三分点之外，该试件结果作废。
- **关联标准/规程**：《普通混凝土力学性能试验方法标准》(GB/T 50081)（实施前复核现行版本）
- **建议页面控件**：输入框（跨度、截面、荷载）、结果展示框
- **是否适合自动计算**：是

### M-004. 回弹法检测混凝土抗压强度换算
- **编号**：M-004
- **二级分类**：混凝土
- **名称**：回弹法检测混凝土抗压强度换算
- **定义与适用场景**：现场非破损检测实体混凝土强度的常用方法，适用于C10-C60混凝土。
- **公式或操作步骤**：1. 计算测区平均回弹值 Rm
2. 计算碳化深度平均值 dm
3. 查测强曲线表得出换算强度 f_cu,c
- **全部变量与单位**：Rm：测区平均回弹值（剔除3个最大和3个最小值）
dm：平均碳化深度 (mm)
f_cu,c：测区混凝土强度换算值 (MPa)
- **完整数值示例**：某测区16个回弹值剔除极值后平均为35.2，碳化深度为1.5mm。查表得换算强度约为 32.5 MPa。
- **结果解释**：代表该测区混凝土的推定强度为32.5MPa。
- **注意事项与禁用边界**：需区分泵送与非泵送、测角修正、浇筑面修正。表层受损或有饰面层的不能直接测。
- **关联标准/规程**：《回弹法检测混凝土抗压强度技术规程》(JGJ/T 23)（实施前复核现行版本）
- **建议页面控件**：16宫格回弹值输入、碳化深度输入、查表匹配组件
- **是否适合自动计算**：是（需内置测强曲线数据库）

### M-005. 混凝土坍落度试验
- **编号**：M-005
- **二级分类**：混凝土
- **名称**：混凝土坍落度试验
- **定义与适用场景**：测定塑性混凝土拌合物的流动性，适用于骨料最大粒径不大于40mm、坍落度不小于10mm的混凝土。
- **公式或操作步骤**：1. 将坍落度筒放在湿润钢板上。
2. 分三层装入拌合物，每层插捣25次。
3. 抹平后垂直平稳提起坍落度筒。
4. 测量筒高与坍落后试体最高点的高度差。
- **全部变量与单位**：坍落度 (mm)
要求坍落度范围 (mm)
- **完整数值示例**：设计坍落度180±20mm。实测坍落前筒高300mm，坍落后试体高115mm。坍落度 = 300 - 115 = 185mm。
- **结果解释**：185mm在160-200mm范围内，合格。
- **注意事项与禁用边界**：提筒过程应在5-10s内完成，从开始装料到提筒完成不应超过150s。
- **关联标准/规程**：《普通混凝土拌合物性能试验方法标准》(GB/T 50080)（实施前复核现行版本）
- **建议页面控件**：数值输入框、合格状态指示灯
- **是否适合自动计算**：是（自动判定是否在允许偏差内）

### M-006. 水胶比

### M-008. 砂浆立方体抗压强度计算
- **编号**：M-008
- **二级分类**：砂浆
- **名称**：砂浆立方体抗压强度计算
- **定义与适用场景**：用于评定砌筑砂浆或抹灰砂浆的抗压强度，标准试件为70.7×70.7×70.7mm立方体。
- **公式或操作步骤**：f_m = (K × F) / A
- **全部变量与单位**：f_m：砂浆立方体抗压强度 (MPa)
F：破坏荷载 (N)
A：受压面积 (mm²)，即5000mm²
K：换算系数（通常取1.35）
- **完整数值示例**：破坏荷载F=30000N。f_m = (1.35 × 30000) / 5000 = 8.1 MPa。
- **结果解释**：该试件抗压强度为8.1MPa。
- **注意事项与禁用边界**：注意底模材料（无底模或有底模）会影响水分流失，需严格按标准制样。
- **关联标准/规程**：《建筑砂浆基本性能试验方法标准》(JGJ/T 70)（实施前复核现行版本）
- **建议页面控件**：输入框、自动计算框

### M-009. 砂浆保水率计算
- **编号**：M-009
- **二级分类**：砂浆
- **名称**：砂浆保水率计算
- **定义与适用场景**：评估砂浆在运输和施工过程中保持水分的能力，防止水分过快被底材吸收。
- **公式或操作步骤**：W = [1 - (m4 - m3) / (m2 - m1) × α] × 100%
- **全部变量与单位**：W：保水率 (%)
m1：滤纸质量 (g)
m2：吸水后滤纸质量 (g)
m3：砂浆质量 (g)
m4：砂浆与滤纸总质量 (g)
α：砂浆含水率 (%)
- **完整数值示例**：m1=10g, m2=15g, m3=200g, m4=200g(简化), α=15%。代入公式计算得保水率92%。
- **结果解释**：保水率92%，满足规范要求的≥88%。
- **注意事项与禁用边界**：试验时间需严格控制，滤纸规格需符合标准。
- **关联标准/规程**：《建筑砂浆基本性能试验方法标准》(JGJ/T 70)（实施前复核现行版本）
- **建议页面控件**：多变量表单、计算结果框
- **是否适合自动计算**：是

### M-010. 砌筑砂浆施工配合比
- **编号**：M-010
- **二级分类**：砂浆
- **名称**：砌筑砂浆施工配合比
- **定义与适用场景**：指导现场砂浆搅拌，根据现场砂的含水率调整用水量。强调：参考配比不得替代试配！
- **公式或操作步骤**：施工用水量 = 试验室用水量 - 砂用量 × 砂含水率
实际干砂量不变，湿砂称量 = 砂用量 × (1 + 砂含水率)
- **全部变量与单位**：试验室用水量 (kg/m³)
试验室砂用量 (kg/m³)
砂含水率 (%)
- **完整数值示例**：试验室配比：水泥250kg，水280kg，砂1450kg。砂含水率3%。
湿砂称量 = 1450 × 1.03 = 1493.5kg
施工用水量 = 280 - 1450 × 0.03 = 236.5kg
- **结果解释**：指导现场搅拌机加水量。
- **注意事项与禁用边界**：含水率变化大时需随时调整，严禁随意加水。
- **关联标准/规程**：《砌筑砂浆配合比设计规程》(JGJ/T 98)（实施前复核现行版本）
- **建议页面控件**：动态输入表单
- **是否适合自动计算**：是

### M-012. 钢筋屈服强度计算
- **编号**：M-012
- **二级分类**：钢材
- **名称**：钢筋屈服强度计算
- **定义与适用场景**：测定钢筋受拉屈服时的应力，是结构设计的重要指标。
- **公式或操作步骤**：R_eL = F_eL / S_0
- **全部变量与单位**：R_eL：下屈服强度 (MPa)

- **注意事项与禁用边界**：公称截面积按理论值计算，不使用实测截面积。
- **关联标准/规程**：《金属材料 拉伸试验 第1部分：室温试验方法》(GB/T 228.1)（实施前复核现行版本）

### M-015. 钢筋重量偏差计算
- **编号**：M-015
- **二级分类**：钢材
- **名称**：钢筋重量偏差计算
- **定义与适用场景**：检验进场钢筋是否存在“瘦身”现象（负偏差超标）。
- **公式或操作步骤**：D = (W_d - W_0) / W_0 × 100%
- **全部变量与单位**：D：重量偏差 (%)
W_d：实际每米重量 (kg/m)
W_0：理论每米重量 (kg/m)
- **完整数值示例**：直径12mm钢筋理论重量0.888kg/m。取5根长度500mm称重总计2.10kg，实际每米=2.10/(5×0.5)=0.84kg/m。D = (0.84 - 0.888) / 0.888 × 100% = -5.4%。
- **结果解释**：偏差为-5.4%，满足规范允许的-5%内吗？不满足，超标（规范允许-5%以内）。
- **注意事项与禁用边界**：试样需端部平齐，长度测量精确至1mm，重量精确至1g。
- **关联标准/规程**：《钢筋混凝土用钢 第2部分：热轧带肋钢筋》(GB/T 1499.2)（实施前复核现行版本）
- **建议页面控件**：根数、长度、总重输入，偏差自动计算
- **是否适合自动计算**：是

### M-016. 钢材理论重量计算（圆钢/带肋钢筋）
- **编号**：M-016
- **二级分类**：钢材
- **名称**：钢材理论重量计算（圆钢/带肋钢筋）

### M-038. 混凝土抗渗性能试验
- **编号**：M-038
- **二级分类**：混凝土
- **名称**：混凝土抗渗性能试验
- **定义与适用场景**：检验混凝土抵抗水压渗透的能力。
- **公式或操作步骤**：P = 10H - 1
- **全部变量与单位**：P：抗渗等级 (如P6, P8)
H：6个试件中3个未出现渗水时的最大水压 (MPa)
- **完整数值示例**：加压至0.9MPa时，有3个试件表面渗水，停止试验。此时H=0.8MPa。P = 10 × 0.8 - 1 = 7。抗渗等级为P6（按偶数分级）。
- **结果解释**：该混凝土抗渗等级满足P6要求。
- **注意事项与禁用边界**：试件成型后需带模养护24h，表面需用钢丝刷刷毛处理以防边缘渗漏。

## 实施前标准复核清单与参考来源
本分卷整理的公式、标准与术语依据现行国家及行业规范，但在实际工程应用中，**必须**实施以下复核：
1. **规范时效性复核**：登录“国家标准全文公开系统”(openstd.samr.gov.cn)或“交通运输部/住房城乡建设部”官网，核对所列标准（如GB/T 50081, JGJ 55, JTG E20等）是否已被最新年份的版本替代。
2. **配比验证原则**：本清单中列举的配合比示例仅为说明计算逻辑（如含水率换算）。**严禁将参考配比直接用于工程**，所有材料配合比（混凝土、砂浆、沥青混合料）必须由有资质的试验室通过现场原材试配后出具正式报告。
3. **地方标准优先级**：部分地区（如高寒、沿海高盐地区）可能有更严格的地方标准，当国标与地标冲突时，应按设计文件和更严格的标准执行。
