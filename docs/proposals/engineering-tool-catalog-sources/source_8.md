# 中国道路与铁路施工承包管理系统 - 工具知识候选清单

> 本分卷覆盖专业域：工程计量、清单结算、变更索赔、合同支付、税费资金、质量安全环保常用术语及建筑公路铁路综合专业术语。

## 01. 土方开挖体积计算（平均断面法）
- **二级分类**: 工程计量
- **定义与适用场景**: 适用于道路、铁路等线形工程中，相邻两横断面之间的土方开挖或填筑体积计算。
- **公式或操作步骤**: V = (A1 + A2) / 2 * L
- **全部变量与单位**: V: 土方体积 (m³); A1: 起点横断面面积 (m²); A2: 终点横断面面积 (m²); L: 两断面间距 (m)
- **完整数值示例**: A1=10 m², A2=15 m², L=20 m. V = (10+15)/2 * 20 = 250 m³
- **结果解释**: 计算得出的250m³为两断面之间的理论开挖土方量。
- **注意事项与禁用边界**: 当相邻两断面面积相差较大（如A1/A2 > 2）时，该公式误差较大，应改用棱台体积公式。禁用边界：地形剧烈起伏段。
- **关联标准/规程**: 《公路工程建设项目造价文件编制导则》（JTG 3810-2017） (实施前复核现行版本)
- **建议页面控件**: A1、A2、L数值输入框，V只读结果框
- **是否适合自动计算**: 是

## 02. 钢筋工程量计算
- **二级分类**: 工程计量
- **定义与适用场景**: 适用于计算混凝土结构中钢筋的理论重量，作为计量支付的依据。
- **公式或操作步骤**: W = L * (d^2 * 0.00617)
- **全部变量与单位**: W: 钢筋重量 (kg); L: 钢筋总长度 (m); d: 钢筋公称直径 (mm)
- **完整数值示例**: L=100 m, d=12 mm. W = 100 * (12^2 * 0.00617) = 100 * 0.888 = 88.8 kg
- **结果解释**: 计算得出100米长、直径12mm的钢筋理论重量为88.8kg。
- **注意事项与禁用边界**: 不包含施工损耗，搭接长度需按合同规定决定是否计入。禁用边界：异形钢材。
- **关联标准/规程**: 《建设工程工程量清单计价规范》（GB 50500-2013） (实施前复核现行版本)
- **建议页面控件**: L、d输入框，下拉选择常见直径，W只读结果框
- **是否适合自动计算**: 是

## 03. 沥青混凝土面层面积计量
- **二级分类**: 工程计量
- **定义与适用场景**: 用于计算道路工程中沥青路面的铺筑面积。
- **公式或操作步骤**: A = W_avg * L
- **全部变量与单位**: A: 铺筑面积 (m²); W_avg: 平均铺筑宽度 (m); L: 铺筑长度 (m)
- **完整数值示例**: W_avg=7.5 m, L=1000 m. A = 7.5 * 1000 = 7500 m²
- **结果解释**: 该路段的沥青面层铺筑面积为7500平方米。
- **注意事项与禁用边界**: 需扣除检查井等突出物面积（若单孔面积大于合同规定阈值）。
- **关联标准/规程**: 《公路工程标准施工招标文件》（交公路发[2018]86号） (实施前复核现行版本)
- **建议页面控件**: 长度、宽度输入框，扣除面积输入框，总面积结果
- **是否适合自动计算**: 是

## 04. 混凝土体积计量
- **二级分类**: 工程计量
- **定义与适用场景**: 用于计算桥梁、涵洞等结构物的实体混凝土体积。
- **公式或操作步骤**: V = L * W * H - V_deduct
- **全部变量与单位**: V: 混凝土净体积 (m³); L, W, H: 构件长宽高 (m); V_deduct: 扣除体积 (m³)
- **完整数值示例**: L=10, W=2, H=1, V_deduct=0.5. V = 10*2*1 - 0.5 = 19.5 m³
- **结果解释**: 结构物实际计量混凝土体积为19.5立方米。
- **注意事项与禁用边界**: 钢筋、预埋件所占体积通常不扣除，具体以技术规范为准。
- **关联标准/规程**: 《公路桥涵施工技术规范》（JTG/T 3650-2020） (实施前复核现行版本)
- **建议页面控件**: 长宽高输入框，扣除项动态添加，净体积结果
- **是否适合自动计算**: 是

## 05. 钻孔灌注桩成孔长度计量
- **二级分类**: 工程计量
- **定义与适用场景**: 计算钻孔灌注桩的有效钻孔长度。
- **公式或操作步骤**: L = E_top - E_bottom
- **全部变量与单位**: L: 成孔长度 (m); E_top: 原地面或护筒顶高程 (m); E_bottom: 孔底高程 (m)
- **完整数值示例**: E_top=100.50, E_bottom=70.20. L = 100.50 - 70.20 = 30.30 m
- **结果解释**: 该桩的成孔计量长度为30.30米。
- **注意事项与禁用边界**: 计量高程起算点需严格按合同界定（原地面或护筒顶）。
- **关联标准/规程**: 《公路工程标准施工招标文件》 (实施前复核现行版本)
- **建议页面控件**: 顶底高程输入框，长度自动计算
- **是否适合自动计算**: 是

## 06. 单价合同期中结算金额计算
- **二级分类**: 清单结算
- **定义与适用场景**: 用于每月或每期按实际完成合格工程量计算应付工程款。
- **公式或操作步骤**: P = Σ(Q_i * U_i)
- **全部变量与单位**: P: 本期结算款 (元); Q_i: 第i项清单实际完成并验收合格的工程量; U_i: 第i项清单合同单价 (元)
- **完整数值示例**: 完成土方1000m³(单价20元)，混凝土100m³(单价500元)。P = 1000*20 + 100*500 = 70000元
- **结果解释**: 本期应结算清单金额为70000元。
- **注意事项与禁用边界**: 未验收合格的工程量不得计入；总价合同不适用此纯单价累加。
- **关联标准/规程**: 《建设工程工程量清单计价规范》（GB 50500-2013） (实施前复核现行版本)
- **建议页面控件**: 清单项选择，本期完成量输入，单价自动带出，合价计算
- **是否适合自动计算**: 是

## 07. 工程量偏差导致单价调整
- **二级分类**: 清单结算
- **定义与适用场景**: 当实际工程量超过合同约定幅度（如15%）时，调整超出部分的综合单价。
- **公式或操作步骤**: 当 Q_actual > Q_plan * 1.15 时，S = Q_plan * 1.15 * U + (Q_actual - Q_plan * 1.15) * U_new
- **全部变量与单位**: S: 结算总价; Q_actual: 实际量; Q_plan: 计划量; U: 原单价; U_new: 调低后的新单价
- **完整数值示例**: 计划100，实际130，原单价100，新单价90。S = 115*100 + (130-115)*90 = 11500 + 1350 = 12850
- **结果解释**: 超过15%的部分按新单价90结算，总金额12850。
- **注意事项与禁用边界**: 需合同明确约定调价条款，否则按原单价。
- **关联标准/规程**: 《建设工程工程量清单计价规范》 (实施前复核现行版本)
- **建议页面控件**: 计划量、实际量对比警示，新单价输入框
- **是否适合自动计算**: 是

## 08. 暂估价材料结算调整
- **二级分类**: 清单结算
- **定义与适用场景**: 发包人提供暂估价的材料，在实际采购后调整合同价款。
- **公式或操作步骤**: ΔP = (P_actual - P_temp) * Q * (1 + 规费率 + 税率)
- **全部变量与单位**: ΔP: 调整金额; P_actual: 实际确认单价; P_temp: 暂估单价; Q: 数量
- **完整数值示例**: 暂估100，实际120，数量1000，综合费率9%。ΔP = (120-100)*1000*1.09 = 21800
- **结果解释**: 因材料价格上涨，需调增结算款21800元。
- **注意事项与禁用边界**: 实际单价需经发包人签证确认。
- **关联标准/规程**: 《建设工程施工合同（示范文本）》（GF-2017-0201） (实施前复核现行版本)
- **建议页面控件**: 暂估价、实际价输入，差额计算，费率配置
- **是否适合自动计算**: 是

## 09. 计日工结算
- **二级分类**: 清单结算
- **定义与适用场景**: 用于处理合同外的零星工作按日计费。
- **公式或操作步骤**: E = Σ(T_worker * U_worker) + Σ(T_machine * U_machine) + 材料费
- **全部变量与单位**: E: 计日工总额; T: 工日/台班数量; U: 计日工单价
- **完整数值示例**: 人工5工日，单价200；机械2台班，单价1000。E = 5*200 + 2*1000 = 3000
- **结果解释**: 零星工作计日工结算为3000元。
- **注意事项与禁用边界**: 必须有现场签证单支持，禁用边界：合同内已包含的工作。
- **关联标准/规程**: 《建设工程造价咨询规范》（GB/T 51095-2015） (实施前复核现行版本)
- **建议页面控件**: 人工/机械类型下拉，数量输入，自动计算总额
- **是否适合自动计算**: 是

## 10. 总价措施项目费调整
- **二级分类**: 清单结算
- **定义与适用场景**: 因设计变更导致实体工程量增减，相应调整总价措施费。
- **公式或操作步骤**: M_new = M_old * (1 + ΔQ / Q_total)
- **全部变量与单位**: M: 措施费; ΔQ: 工程量变化引起的直接费变化; Q_total: 原合同直接费
- **完整数值示例**: 原措施费10万，直接费增加10%。M_new = 10 * (1 + 0.1) = 11万
- **结果解释**: 措施费随工程量增加调增至11万元。
- **注意事项与禁用边界**: 仅适用于与工程量相关的措施项目（如脚手架），安全文明施工费另有规定。
- **关联标准/规程**: 《建设工程工程量清单计价规范》 (实施前复核现行版本)
- **建议页面控件**: 调整系数输入，措施费联动计算
- **是否适合自动计算**: 是

## 11. 工期索赔计算（网络分析法）
- **二级分类**: 变更索赔
- **定义与适用场景**: 非承包商原因导致延误时，计算可索赔的工期天数。
- **公式或操作步骤**: ΔT = T_actual - T_plan （需延误发生在关键线路上）
- **全部变量与单位**: ΔT: 索赔工期(天); T_actual: 延误后总工期; T_plan: 原计划总工期
- **完整数值示例**: 原计划100天，关键线路上非承包商原因停工10天。ΔT = 110 - 100 = 10天
- **结果解释**: 承包商可合理索赔10天工期。
- **注意事项与禁用边界**: 非关键线路上的延误若未超过总时差，则不能索赔工期。
- **关联标准/规程**: 《建设工程施工合同（示范文本）》 (实施前复核现行版本)
- **建议页面控件**: 延误事件录入，关键线路判定勾选，天数计算
- **是否适合自动计算**: 否（需结合进度计划软件）

## 12. 人员窝工费索赔
- **二级分类**: 变更索赔
- **定义与适用场景**: 发包人原因导致停工，承包商索赔人员闲置费用。
- **公式或操作步骤**: C_labor = N * T * U_idle
- **全部变量与单位**: C_labor: 窝工费(元); N: 窝工人数; T: 窝工天数; U_idle: 窝工单价(元/天)
- **完整数值示例**: 20人停工5天，窝工单价100元/天。C = 20 * 5 * 100 = 10000元
- **结果解释**: 可索赔人员窝工费10000元。
- **注意事项与禁用边界**: 窝工单价通常低于正常工作日工资，且不计利润。
- **关联标准/规程**: 《建设工程工程量清单计价规范》 (实施前复核现行版本)
- **建议页面控件**: 人数、天数、单价输入框，结果自动计算
- **是否适合自动计算**: 是

## 13. 机械闲置费索赔
- **二级分类**: 变更索赔
- **定义与适用场景**: 发包人原因导致机械停滞，索赔机械闲置费。
- **公式或操作步骤**: C_mach = Σ(T_idle * U_depreciation)
- **全部变量与单位**: C_mach: 机械闲置费; T_idle: 闲置台班数; U_depreciation: 机械折旧费/租赁费单价
- **完整数值示例**: 挖掘机闲置3台班，折旧费500元/台班。C = 3 * 500 = 1500元
- **结果解释**: 可索赔机械闲置费1500元。
- **注意事项与禁用边界**: 自有机械按折旧费算，租赁机械按租赁费算，不含燃料动力费及操作人员工资。
- **关联标准/规程**: 《施工机械台班费用编制规则》 (实施前复核现行版本)
- **建议页面控件**: 机械类型、权属(自有/租赁)选择，台班数输入
- **是否适合自动计算**: 是

## 14. 总部管理费索赔（伊柯尔公式 Eichleay Formula）
- **二级分类**: 变更索赔
- **定义与适用场景**: 因发包人原因导致工程延期，承包商索赔增加的总部管理费。
- **公式或操作步骤**: C_hq = (该工程合同额/公司同期总合同额) * 同期总部管理费 / 合同工期 * 延期天数
- **全部变量与单位**: 各项金额单位为元，时间单位为天。
- **完整数值示例**: 分摊比例10%，同期总管理费100万，合同工期100天，延期10天。C_hq = (100万*10%)/100 * 10 = 10000元
- **结果解释**: 可索赔总部管理费10000元。
- **注意事项与禁用边界**: 需证明延期导致了管理费用的实际增加，国内应用需合同特别约定。
- **关联标准/规程**: 国际工程惯例（FIDIC） (实施前复核现行版本)
- **建议页面控件**: 公司财务数据输入，分摊比例自动计算
- **是否适合自动计算**: 是

## 15. 新增工程单价确定
- **二级分类**: 变更索赔
- **定义与适用场景**: 发生合同外新增变更工程时，确定其结算单价。
- **公式或操作步骤**: 有类似项目则参照；无类似项目则按: U_new = 直接成本 * (1 + 管理费率) * (1 + 利润率)
- **全部变量与单位**: U_new: 新单价; 各费率为百分比。
- **完整数值示例**: 直接成本100，管理费5%，利润7%。U_new = 100 * 1.05 * 1.07 = 112.35
- **结果解释**: 新增工程单价组价为112.35元。
- **注意事项与禁用边界**: 费率需采用合同约定或招投标时的下浮率。
- **关联标准/规程**: 《建设工程工程量清单计价规范》 (实施前复核现行版本)
- **建议页面控件**: 成本明细录入，费率配置，单价生成
- **是否适合自动计算**: 是

## 16. 预付款扣回计算
- **二级分类**: 合同支付
- **定义与适用场景**: 工程进度达到一定比例后，分期扣回发包人已支付的工程预付款。
- **公式或操作步骤**: R = A * (C - P_s) / (P_e - P_s)
- **全部变量与单位**: R: 本期扣回额; A: 预付款总额; C: 本期完成累计金额; P_s: 起扣点; P_e: 满扣点
- **完整数值示例**: A=100万, P_s=300万, P_e=800万, 上期累计300万, 本期累计400万。R = 100 * (400-300)/(800-300) = 20万
- **结果解释**: 本期应扣回预付款20万元。
- **注意事项与禁用边界**: 扣回完毕后不再计算；合同如有等额扣回条款则不适用此公式。
- **关联标准/规程**: 《建设工程施工合同（示范文本）》 (实施前复核现行版本)
- **建议页面控件**: 起扣点满扣点设置，本期扣回额自动计算
- **是否适合自动计算**: 是

## 17. 质量保证金扣留
- **二级分类**: 合同支付
- **定义与适用场景**: 从进度款中按比例扣留，用于质保期内的缺陷修复。
- **公式或操作步骤**: D = P_current * r
- **全部变量与单位**: D: 本期扣留质保金; P_current: 本期结算款; r: 扣留比例(通常3%)
- **完整数值示例**: 本期结算100万，扣留比例3%。D = 100 * 3% = 3万
- **结果解释**: 本期扣留质量保证金3万元。
- **注意事项与禁用边界**: 累计扣留总额不得超过工程价款结算总额的3%（根据现行规定）。
- **关联标准/规程**: 《建设工程质量保证金管理办法》（建质[2017]138号） (实施前复核现行版本)
- **建议页面控件**: 扣留比例设置，累计扣留限额校验
- **是否适合自动计算**: 是

## 18. 物价波动调价（价格指数法）
- **二级分类**: 合同支付
- **定义与适用场景**: 因材料价格大幅波动，按价格指数调整工程款。
- **公式或操作步骤**: ΔP = P0 * [A + B1(Ft1/F01) + B2(Ft2/F02) + ... - 1]
- **全部变量与单位**: ΔP: 调增减额; P0: 约定基数; A: 不调值权重; B: 各因子权重; Ft: 现行指数; F0: 基期指数
- **完整数值示例**: P0=100万, A=0.3, 钢材权重0.7, 基期100, 现期110。ΔP = 100 * [0.3 + 0.7*(110/100) - 1] = 100 * [1.07 - 1] = 7万
- **结果解释**: 因钢材涨价，应调增工程款7万元。
- **注意事项与禁用边界**: 各项权重之和必须等于1 (A+ΣB=1)。
- **关联标准/规程**: 《建设工程施工合同（示范文本）》 (实施前复核现行版本)
- **建议页面控件**: 权重分配表，基期/现期指数录入，自动计算
- **是否适合自动计算**: 是

## 19. 实际应支付款计算
- **二级分类**: 合同支付

- **公式或操作步骤**: P_net = P_settle - R_advance - D_retention - 其他扣款
- **全部变量与单位**: P_net: 实际应支付金额; P_settle: 本期结算款; R_advance: 扣预付款; D_retention: 扣质保金

## 37. 钢筋强度标准值
- **二级分类**: 材料标准
- **定义与适用场景**: HRB400等热轧带肋钢筋在结构计算和材料进场检验时的屈服强度下限。
- **公式或操作步骤**: 无
- **全部变量与单位**: 屈服强度标准值 f_yk (MPa)
- **完整数值示例**: HRB400钢筋的 f_yk = 400 MPa，抗拉强度标准值 f_tk = 540 MPa。
- **结果解释**: 进场拉伸试验测得屈服强度必须 ≥ 400MPa 方为合格。
- **注意事项与禁用边界**: 不同牌号（如HRB500）标准值不同；抗震结构对强屈比有额外要求。
- **关联标准/规程**: 《钢筋混凝土用钢 第2部分：热轧带肋钢筋》（GB/T 1499.2-2018） (实施前复核现行版本)
- **建议页面控件**: 牌号下拉选择，自动带出标准值用于试验数据对比
- **是否适合自动计算**: 是

## 38. 混凝土抗压强度评定
- **二级分类**: 材料标准
- **定义与适用场景**: 根据同批次试块的抗压强度数据，评定该批混凝土是否合格。
- **公式或操作步骤**: 统计方法：m_fcu - λ1 * S_fcu ≥ 0.9 * f_cu,k 且 f_cu,min ≥ λ2 * f_cu,k
- **全部变量与单位**: m_fcu: 均值(MPa); S_fcu: 标准差(MPa); f_cu,k: 标准值(MPa); λ1,λ2: 评定系数
- **完整数值示例**: C30混凝土，15组试块，均值35MPa，标准差2MPa，λ1=1.70, λ2=0.9。35 - 1.7*2 = 31.6 ≥ 0.9*30=27，最小值32 ≥ 0.9*30=27。评定合格。
- **结果解释**: 该批次C30混凝土强度评定为合格。
- **注意事项与禁用边界**: 组数小于10组时必须采用非统计方法评定。
- **关联标准/规程**: 《混凝土强度检验评定标准》（GB/T 50107-2010） (实施前复核现行版本)
- **建议页面控件**: 试块数据批量导入，自动判断统计/非统计法并出具结论
- **是否适合自动计算**: 是

## 39. 不可抗力导致的费用分担
- **二级分类**: 变更索赔
- **定义与适用场景**: 台风、地震等不可抗力发生后，发承包双方费用的分担原则。
- **公式或操作步骤**: 工程本身损害、发包人人员伤亡及财产损失由发包人承担；承包人人员伤亡、机械损坏由承包人承担；停工期间必须留守人员费用由发包人承担。
- **全部变量与单位**: 无
- **完整数值示例**: 台风导致已完工墙体倒塌（损失10万，发包人承担），承包商塔吊折断（损失50万，承包人承担）。
- **结果解释**: 各自承担相应风险，公平合理。
- **注意事项与禁用边界**: 不可抗力发生后必须在合同规定时间（如14天）内发出通知，否则丧失索赔权。
- **关联标准/规程**: 《建设工程施工合同（示范文本）》 (实施前复核现行版本)
- **建议页面控件**: 损失清单分类勾选，自动归属责任方
- **是否适合自动计算**: 否

## 40. 缺陷责任期
- **二级分类**: 综合术语
- **定义与适用场景**: 【术语】中文名称：缺陷责任期；英文：Defect Liability Period。定义：承包人对已交工验收的工程承担缺陷修复责任的期限，通常为12或24个月。
- **公式或操作步骤**: 无
- **全部变量与单位**: 无
- **完整数值示例**: 现场示例：某公路2023年1月1日交工验收，缺陷责任期2年，至2025年1月1日届满，届满后返还质保金。
- **结果解释**: 易混淆项：保修期（保修期是法定要求，通常比缺陷责任期长，如地基基础为设计使用年限）。
- **注意事项与禁用边界**: 缺陷责任期从工程通过交工验收之日起计算。
- **关联标准/规程**: 《建设工程质量保证金管理办法》 (实施前复核现行版本)
- **建议页面控件**: 日期计算器，到期预警
- **是否适合自动计算**: 是（日期计算）
