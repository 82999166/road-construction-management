## 1. 面积与体积计算

本节涵盖了土方开挖、混凝土浇筑及墙体砌筑等常见的面积与体积计算方法。

### 1.1 矩形基础土方开挖体积
**编号**: STR-VOL-001
**二级分类**: 面积体积
**名称**: 矩形基础土方开挖体积计算
**定义与适用场景**: 用于计算矩形独立基础或条形基础的土方开挖量，适用于放坡开挖场景。
**公式或操作步骤**: $V = (a + 2c + kH) \times (b + 2c + kH) \times H + \frac{1}{3} k^2 H^3$
**全部变量与单位**: 
| 变量 | 说明 | 单位 |
| --- | --- | --- |
| $V$ | 开挖体积 | $m^3$ |
| $a, b$ | 基础底面长宽 | $m$ |
| $c$ | 工作面宽度 | $m$ |
| $k$ | 放坡系数 | 无量纲 |
| $H$ | 开挖深度 | $m$ |

**完整数值示例**: 基础底面长 $2m$，宽 $1.5m$，工作面宽 $0.3m$，放坡系数 $0.5$，开挖深度 $2m$。
$V = (2 + 2\times0.3 + 0.5\times2) \times (1.5 + 2\times0.3 + 0.5\times2) \times 2 + \frac{1}{3} \times 0.5^2 \times 2^3 = 3.6 \times 3.1 \times 2 + 0.67 = 22.32 + 0.67 = 22.99 m^3$
**结果解释**: 预计需要开挖 $22.99$ 立方米土方。
**注意事项与禁用边界**: 仅适用于均质土层，复杂地质或支护开挖不适用。边坡及深基坑等高风险结构，系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。
**关联标准/规程**: 《房屋建筑与装饰工程工程量计算规范》GB 50854-2013 (实施前复核现行版本) [1]
**建议页面控件**: 输入框(长, 宽, 深度, 工作面, 放坡系数)，输出框(体积)
**是否适合自动计算**: 是

### 1.2 圆形检查井开挖体积
**编号**: STR-VOL-002
**二级分类**: 面积体积
**名称**: 圆形检查井开挖体积计算
**定义与适用场景**: 用于市政管网工程中圆形检查井的土方开挖量计算。
**公式或操作步骤**: $V = \frac{\pi}{3} H (R^2 + R r + r^2)$
**全部变量与单位**: 
| 变量 | 说明 | 单位 |
| --- | --- | --- |
| $V$ | 开挖体积 | $m^3$ |
| $H$ | 开挖深度 | $m$ |
| $r$ | 井底开挖半径 (含工作面) | $m$ |
| $R$ | 井口开挖半径 ($R = r + kH$) | $m$ |
| $k$ | 放坡系数 | 无量纲 |

**完整数值示例**: 井底半径 $1m$，开挖深度 $3m$，放坡系数 $0.33$。$R = 1 + 0.33\times3 = 1.99m$。
$V = \frac{3.14}{3} \times 3 \times (1.99^2 + 1.99\times1 + 1^2) = 3.14 \times (3.96 + 1.99 + 1) = 21.82 m^3$
**结果解释**: 圆形检查井需开挖 $21.82$ 立方米土方。
**注意事项与禁用边界**: 注意放坡起点的深度要求。深基坑等高风险结构，系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。
**关联标准/规程**: 《市政工程工程量计算规范》GB 50857-2013 (实施前复核现行版本) [1]
**建议页面控件**: 输入框(井底半径, 深度, 放坡系数)，输出框(体积)
**是否适合自动计算**: 是

### 1.3 柱混凝土体积计算
**编号**: STR-VOL-003
**二级分类**: 面积体积
**名称**: 矩形柱混凝土体积计算
**定义与适用场景**: 房屋建筑中钢筋混凝土矩形柱的浇筑体积计算。
**公式或操作步骤**: $V = a \times b \times H$
**全部变量与单位**: 
| 变量 | 说明 | 单位 |
| --- | --- | --- |
| $V$ | 混凝土体积 | $m^3$ |
| $a, b$ | 柱截面长宽 | $m$ |
| $H$ | 柱高 (层高减板厚或梁高) | $m$ |

**完整数值示例**: 柱截面 $0.5m \times 0.5m$，层高 $3m$，板厚 $0.15m$。$H = 3 - 0.15 = 2.85m$。
$V = 0.5 \times 0.5 \times 2.85 = 0.7125 m^3$
**结果解释**: 单根柱需浇筑 $0.7125$ 立方米混凝土。
**注意事项与禁用边界**: 需准确扣减相交构件(梁、板)的体积。高风险结构，系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。
**关联标准/规程**: 《混凝土结构工程施工质量验收规范》GB 50204-2015 (实施前复核现行版本) [1]
**建议页面控件**: 输入框(截面长, 截面宽, 层高, 扣减高度)，输出框(体积)
**是否适合自动计算**: 是

### 1.4 墙体面积计算
**编号**: STR-VOL-004
**二级分类**: 面积体积
**名称**: 墙体净面积计算
**定义与适用场景**: 计算砌体墙或混凝土墙的实际面积，用于抹灰、涂料或砌筑工程量。
**公式或操作步骤**: $S = L \times H - \sum (w_i \times h_i)$
**全部变量与单位**: 
| 变量 | 说明 | 单位 |
| --- | --- | --- |
| $S$ | 净面积 | $m^2$ |
| $L$ | 墙体长度 | $m$ |
| $H$ | 墙体高度 | $m$ |
| $w_i, h_i$ | 门窗洞口的宽和高 | $m$ |

**完整数值示例**: 墙长 $5m$，高 $3m$，有一个 $1m \times 2m$ 的门洞和一个 $1.5m \times 1.5m$ 的窗洞。
$S = 5 \times 3 - (1 \times 2 + 1.5 \times 1.5) = 15 - (2 + 2.25) = 10.75 m^2$
**结果解释**: 墙体实际净面积为 $10.75$ 平方米。
**注意事项与禁用边界**: 洞口侧壁面积是否展开计入需根据具体计价规则确定。高风险结构，系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。
**关联标准/规程**: 《房屋建筑与装饰工程工程量计算规范》GB 50854-2013 (实施前复核现行版本) [1]
**建议页面控件**: 输入框(墙长, 墙高)，动态列表(洞口宽, 洞口高)，输出框(净面积)
**是否适合自动计算**: 是

### 1.5 楼梯混凝土体积
**编号**: STR-VOL-005
**二级分类**: 面积体积
**名称**: 楼梯段混凝土体积估算
**定义与适用场景**: 快速估算板式楼梯梯段的混凝土体积。
**公式或操作步骤**: $V = L \times B \times \cos\theta \times d + \frac{1}{2} \times n \times a \times h \times B$ (近似简化)
**全部变量与单位**: 
| 变量 | 说明 | 单位 |
| --- | --- | --- |
| $V$ | 体积 | $m^3$ |
| $L$ | 梯段水平投影长度 | $m$ |
| $B$ | 梯段宽度 | $m$ |
| $\theta$ | 楼梯倾角 | $^\circ$ |
| $d$ | 梯板厚度 | $m$ |
| $n$ | 踏步数量 | 个 |
| $a$ | 踏步宽 | $m$ |
| $h$ | 踏步高 | $m$ |

**完整数值示例**: 水平投影长 $3m$，宽 $1.2m$，板厚 $0.12m$，倾角 $30^\circ$，踏步数 $10$，宽 $0.3m$，高 $0.15m$。
梯板体积 = $3 / \cos30^\circ \times 1.2 \times 0.12 = 3.46 \times 1.2 \times 0.12 = 0.498 m^3$
踏步体积 = $0.5 \times 10 \times 0.3 \times 0.15 \times 1.2 = 0.27 m^3$
$V = 0.498 + 0.27 = 0.768 m^3$
**结果解释**: 楼梯段混凝土体积约为 $0.768$ 立方米。
**注意事项与禁用边界**: 仅为估算，实际结算需精确建模或按投影面积计算。高风险结构，系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。
**关联标准/规程**: 《混凝土结构工程施工规范》GB 50666-2011 (实施前复核现行版本) [1]
**建议页面控件**: 输入框(水平长, 宽度, 板厚, 踏步宽, 踏步高, 踏步数)，输出框(体积)
**是否适合自动计算**: 是

**名称**: 后浇带
**英文/缩写**: Post-pouring band
**定义**: 为防止现浇钢筋混凝土结构由于温度、收缩不均可能产生的有害裂缝，按设计要求留设的暂不浇筑的混凝土带。
**现场示例**: 顶板浇筑时，中间留了一条800mm宽的缝未浇筑，需等主体结构完工或60天后再用微膨胀混凝土封闭。
**易混淆项**: 施工缝 (后浇带是设计要求的防裂措施，缝宽较大且有时间要求；施工缝是施工停顿形成的交界面)。

### 8.8 见证取样
**编号**: STR-TRM-008
**二级分类**: 术语
**名称**: 见证取样
**英文/缩写**: Witness sampling
**定义**: 在监理单位或建设单位见证人员的监督下，由施工单位取样人员现场取样，并送至具备相应资质的检测机构进行检测的活动。
**现场示例**: 钢筋进场后，监理工程师旁站看着材料员截取钢筋试件，并一起装箱贴封条送去实验室。
**易混淆项**: 平行检验 (监理自己独立进行的抽样检测，不是看着施工单位做)。

### 8.9 满堂脚手架
**编号**: STR-TRM-009
**二级分类**: 术语
**名称**: 满堂脚手架
**英文/缩写**: Full scaffold
**定义**: 在纵、横方向，由不少于三排立杆并与水平杆、水平剪刀撑、竖向剪刀撑、扣件等构成的脚手架，主要用于支撑或操作平台。
**现场示例**: 为了安装剧院8米高的吊顶，大厅内部搭设了密密麻麻如同森林一般的满堂脚手架。
**易混淆项**: 双排脚手架 (仅有内外两排立杆，主要用于外墙施工)。

### 8.10 盲沟
**编号**: STR-TRM-010
**二级分类**: 术语
**名称**: 盲沟
**英文/缩写**: Blind ditch / French drain
**定义**: 在地下埋设的透水管或填充碎石等透水材料的沟槽，用于汇集和排放地下水，表面被覆土掩盖。
**现场示例**: 挡土墙背后挖了一条沟，填满碎石并包上土工布，用来排走地下水防止墙体受水压破坏。
**易混淆项**: 明沟 (敞开在地表，肉眼可见的排水沟)。
