# 工程工具知识全量候选清单—总目录与实施确认方案

## 汇编摘要
本次汇编涵盖八个审校分卷，共计355项工程工具知识条目。这些条目按功能形态分为自动计算器、查表/材料标准、步骤模板和术语词典四类。为确保系统安全与工程质量，对所有条目进行了风险分级：绿色代表可直接实现，黄色表示需要项目实测参数，红色则涉及结构安全、爆破、临电等高风险领域，系统仅做记录与辅助计算，不得由系统无条件自动判定，必须由设计、试验或专业人员复核。建议分四期逐步实施，优先实现低风险和高频基础计算，逐步过渡到复杂专业功能。特别声明：配比换算功能不得替代试验室试配结果。

## 拟议系统菜单树
- 建筑结构与市政工程
- 材料标准与试验
- 土工路基与地基处理
- 公路桥涵与隧道
- 铁路工程专业
- 工程测量与算量
- 机械运输与成本
- 计量结算与术语
