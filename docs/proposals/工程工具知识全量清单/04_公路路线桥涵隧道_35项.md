# 公路工程工具知识候选清单

## 路线工程

### 1. 路线 - 平曲线加宽计算
- **编号**: HW-RT-001
- **二级分类**: 路线
- **名称**: 平曲线内侧加宽值计算
- **定义与适用场景**: 计算公路在平曲线路段，为适应车辆转弯时后轮轨迹偏向内侧的需要，在曲线内侧增加的路面宽度。适用于各级公路的圆曲线路段。
- **公式或操作步骤**: $e = \frac{L^2}{2R}$ （单车道加宽值），总加宽值 $E = N \times e + \Delta$
- **全部变量与单位**: $e$: 单车道加宽值(m)；$L$: 车辆轴距加前悬长度(m)；$R$: 平曲线半径(m)；$N$: 车道数；$\Delta$: 车辆行驶摆动加宽(m)
- **完整数值示例**: $L=10$m, $R=200$m, $N=2$, $\Delta=0.2$m。单车道 $e = 10^2 / (2 \times 200) = 0.25$m。总加宽 $E = 2 \times 0.25 + 0.2 = 0.7$m。
- **结果解释**: 曲线段内侧需增加0.7m的宽度以保证行车安全。
- **注意事项与禁用边界**: 当加宽值小于0.25m时，可不设加宽。禁用边界：特大型车辆行驶路段需按实际轨迹计算。系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。
- **关联标准/规程**: 《公路工程技术标准》(JTG B01) - 实施前复核现行版本
- **建议页面控件**: 半径输入框、车辆类型下拉框、车道数输入框、计算按钮、结果显示标签。
- **是否适合自动计算**: 是

### 2. 路线 - 缓和曲线长度计算
- **编号**: HW-RT-002
- **二级分类**: 路线
- **名称**: 缓和曲线最小长度计算
- **定义与适用场景**: 为保证离心加速度变化率在舒适范围内，计算缓和曲线所需的最小长度。适用于直线与圆曲线之间的过渡段。
- **公式或操作步骤**: $L_s = \frac{0.036 V^3}{R \cdot \alpha}$
- **全部变量与单位**: $L_s$: 缓和曲线长度(m)；$V$: 设计速度(km/h)；$R$: 圆曲线半径(m)；$\alpha$: 离心加速度变化率(m/s³)
- **完整数值示例**: $V=80$km/h, $R=400$m, $\alpha=0.6$m/s³。$L_s = (0.036 \times 80^3) / (400 \times 0.6) = 76.8$m。
- **结果解释**: 设计缓和曲线长度至少为76.8m，通常取整为80m。
- **注意事项与禁用边界**: 需同时满足超高渐变率的要求，取各项计算的最大值。系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。
- **关联标准/规程**: 《公路路线设计规范》(JTG D20) - 实施前复核现行版本
- **建议页面控件**: 设计速度输入、曲线半径输入、舒适度系数选择、结果输出。
- **是否适合自动计算**: 是

### 3. 路线 - 竖曲线高程计算
- **编号**: HW-RT-003
- **二级分类**: 路线
- **名称**: 竖曲线任一点高程计算
- **定义与适用场景**: 计算纵断面上竖曲线上任意一点的设计高程，用于路基填挖方施工放样。
- **公式或操作步骤**: $y = \frac{x^2}{2R}$，高程 $H = H_{BVC} \pm i_1 \cdot x \pm y$
- **全部变量与单位**: $y$: 竖曲线上的竖直偏移距(m)；$x$: 计算点距竖曲线起点的水平距离(m)；$R$: 竖曲线半径(m)；$H_{BVC}$: 竖曲线起点高程(m)；$i_1$: 第一坡段坡度(%)
- **完整数值示例**: 凸形竖曲线，起点高程100.0m，坡度$i_1=+3\%$，半径$R=5000$m，计算距起点$x=50$m处高程。$y = 50^2 / (2 \times 5000) = 0.25$m。$H = 100.0 + 0.03 \times 50 - 0.25 = 101.25$m。
- **结果解释**: 距起点50m处的设计高程为101.25m。
- **注意事项与禁用边界**: 凸形竖曲线 $y$ 取负号，凹形竖曲线 $y$ 取正号。
- **关联标准/规程**: 《公路路线设计规范》(JTG D20) - 实施前复核现行版本
- **建议页面控件**: 桩号输入、起点高程与坡度输入、半径输入、结果表格。
- **是否适合自动计算**: 是

## 路基工程

### 4. 路基 - 压实度计算
- **编号**: HW-SG-001
- **二级分类**: 路基
- **名称**: 现场压实度(灌砂法)计算
- **定义与适用场景**: 评价路基填土压实质量，适用于细粒土、砂类土和砾类土。
- **公式或操作步骤**: 压实度 $K = \frac{\rho_d}{\rho_{dmax}} \times 100\%$，其中 $\rho_d = \frac{\rho}{1 + 0.01w}$
- **全部变量与单位**: $K$: 压实度(%)；$\rho_d$: 现场干密度(g/cm³)；$\rho_{dmax}$: 室内标准击实最大干密度(g/cm³)；$\rho$: 现场湿密度(g/cm³)；$w$: 含水率(%)
- **完整数值示例**: 现场测得湿密度 $\rho=2.15$g/cm³，含水率 $w=12.5\%$，标准最大干密度 $\rho_{dmax}=1.98$g/cm³。$\rho_d = 2.15 / (1 + 0.125) = 1.911$g/cm³。$K = (1.911 / 1.98) \times 100\% = 96.5\%$。
- **结果解释**: 现场压实度为96.5%，若标准要求为96%，则合格。
- **注意事项与禁用边界**: 含水率测试必须准确，超粒径土需进行干密度校正。
- **关联标准/规程**: 《公路路基施工技术规范》(JTG/T 3610) - 实施前复核现行版本
- **建议页面控件**: 湿密度、含水率、最大干密度输入框，压实度合格判定指示灯。
- **是否适合自动计算**: 是

### 5. 路基 - 土方调配体积换算
- **编号**: HW-SG-002
- **二级分类**: 路基
- **名称**: 土石方体积换算系数计算
- **定义与适用场景**: 在土方调配和计价中，将天然密实体积换算为压实体积或松方体积。
- **公式或操作步骤**: 压实体积 $V_c = V_n \times K_c$
- **全部变量与单位**: $V_c$: 压实体积(m³)；$V_n$: 天然密实体积(m³)；$K_c$: 压实换算系数(无量纲)
- **完整数值示例**: 普通土开挖天然密实体积 $V_n=1000$m³，查表得压实换算系数 $K_c=0.92$（随土质变）。压实体积 $V_c = 1000 \times 0.92 = 920$m³。
- **结果解释**: 1000m³的天然土开挖后，可填筑920m³的压实路基。
- **注意事项与禁用边界**: 不同土石类别的换算系数差异极大，需根据地勘报告及试验确定。系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。
- **关联标准/规程**: 《公路工程预算定额》(JTG/T 3832) - 实施前复核现行版本
- **建议页面控件**: 土质类型下拉菜单，体积输入框，换算结果输出。
- **是否适合自动计算**: 是

### 6. 路基 - CBR值计算
- **编号**: HW-SG-003
- **二级分类**: 路基
- **名称**: 加州承载比(CBR)计算
- **定义与适用场景**: 评价路基土和路面材料的承载能力。
- **公式或操作步骤**: $CBR = \frac{p}{p_s} \times 100\%$
- **全部变量与单位**: $CBR$: 加州承载比(%)；$p$: 贯入量为2.5mm或5.0mm时的单位压力(MPa)；$p_s$: 标准碎石在相同贯入量时的标准压力(2.5mm时为7.0MPa，5.0mm时为10.5MPa)
- **完整数值示例**: 贯入量2.5mm时测得压力 $p=0.56$MPa。$CBR = (0.56 / 7.0) \times 100\% = 8.0\%$。
- **结果解释**: 该土样的CBR值为8.0%，满足一般路床填料要求。
- **注意事项与禁用边界**: 需同时计算2.5mm和5.0mm的CBR值，通常取2.5mm的值，若5.0mm值大于2.5mm值，需重做试验。
- **关联标准/规程**: 《公路土工试验规程》(JTG 3430) - 实施前复核现行版本
- **建议页面控件**: 测力环读数输入，贯入量选择，自动查表并计算结果。
- **是否适合自动计算**: 是

## 基层工程

### 7. 基层 - 水泥稳定碎石配合比换算
- **编号**: HW-BS-001
- **二级分类**: 基层
- **名称**: 水稳碎石施工配合比换算
- **定义与适用场景**: 将试验室得出的干料配合比换算为拌和站实际生产使用的湿料配合比。
- **公式或操作步骤**: 湿集料用量 $M_{wi} = M_{di} \times (1 + w_i)$，水泥实际用量 $M_c = M_{dc}$，实际加水量 $M_w = M_{total\_water} - \sum (M_{di} \times w_i)$
- **全部变量与单位**: $M_{wi}$: 各档湿集料用量(kg)；$M_{di}$: 各档干集料用量(kg)；$w_i$: 各档集料天然含水率(%)；$M_{total\_water}$: 最佳含水量对应的总水量(kg)；$M_{dc}$: 水泥干用量(kg)；$M_w$: 实际加水量(kg)；$M_c$: 水泥实际用量(kg)
- **完整数值示例**: 1方混合料干质量2300kg，水泥5%（115kg），集料2185kg。其中10-20mm碎石占40%（874kg），含水率1%。湿碎石用量 $= 874 \times (1+0.01) = 882.74$kg。
- **结果解释**: 拌和站需下料882.74kg的湿碎石以保证干料比例。
- **注意事项与禁用边界**: 系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。材料参考配比不得替代试验室试配。雨天含水率变化快，需每班检测含水率并调整。
- **关联标准/规程**: 《公路路面基层施工技术细则》(JTG/T F20) - 实施前复核现行版本
- **建议页面控件**: 干配比输入表格，各料仓含水率输入框，下发生产配比按钮。
- **是否适合自动计算**: 是

### 8. 基层 - 无侧限抗压强度代表值
- **编号**: HW-BS-002
- **二级分类**: 基层
- **名称**: 7d无侧限抗压强度代表值计算
- **定义与适用场景**: 评价半刚性基层材料的强度是否达标。
- **公式或操作步骤**: $R_d = \bar{R} - Z_a \cdot S$
- **全部变量与单位**: $R_d$: 强度代表值(MPa)；$\bar{R}$: 试件抗压强度平均值(MPa)；$Z_a$: 保证率系数(如95%保证率时$Z_a=1.645$)；$S$: 标准差(MPa)
- **完整数值示例**: 9个试件，平均强度 $\bar{R}=4.5$MPa，标准差 $S=0.4$MPa，保证率95%($Z_a=1.645$)。$R_d = 4.5 - 1.645 \times 0.4 = 3.84$MPa。
- **结果解释**: 强度代表值为3.84MPa，若设计要求大于3.5MPa，则合格。
- **注意事项与禁用边界**: 变异系数Cv过大时(如大于15%)，需分析原因或增加试件数量。
- **关联标准/规程**: 《公路工程无机结合料稳定材料试验规程》(JTG E51) - 实施前复核现行版本
- **建议页面控件**: 单个试件强度批量输入，保证率选择，统计结果输出。
- **是否适合自动计算**: 是

### 9. 基层 - 压实厚度与松铺厚度
- **编号**: HW-BS-003
- **二级分类**: 基层
- **名称**: 松铺厚度计算
- **定义与适用场景**: 摊铺机摊铺基层材料时，计算所需的松铺厚度以达到设计压实厚度。
- **公式或操作步骤**: $H_s = H_c \times K$

- **完整数值示例**: 设计水稳基层压实厚度 $H_c=20$cm，试验段确定松铺系数 $K=1.25$。$H_s = 20 \times 1.25 = 25$cm。
- **结果解释**: 摊铺机应设定摊铺厚度为25cm。
- **注意事项与禁用边界**: 松铺系数必须通过现场试验段确定，不同机械、材料变化时需重新标定。
- **关联标准/规程**: 《公路路面基层施工技术细则》(JTG/T F20) - 实施前复核现行版本
- **建议页面控件**: 设计厚度输入，松铺系数滑动条，计算结果。
- **是否适合自动计算**: 是

### 10. 沥青混合料 - 沥青用量(油石比)换算
- **编号**: HW-AM-001
- **二级分类**: 沥青混合料
- **名称**: 沥青含量与油石比换算
- **定义与适用场景**: 沥青混合料配合比设计与生产中，两种沥青用量表示方法的换算。
- **公式或操作步骤**: 沥青含量 $P_b = \frac{P_a}{100 + P_a} \times 100\%$，油石比 $P_a = \frac{P_b}{100 - P_b} \times 100\%$
- **全部变量与单位**: $P_b$: 沥青含量(沥青占混合料总质量的百分比，%)；$P_a$: 油石比(沥青占矿料总质量的百分比，%)
- **完整数值示例**: 已知油石比 $P_a=5.0\%$。沥青含量 $P_b = 5.0 / (100 + 5.0) \times 100\% = 4.76\%$。
- **结果解释**: 油石比5.0%对应混合料中的沥青含量为4.76%。
- **注意事项与禁用边界**: 拌和站设定常使用油石比，设计报告常使用沥青含量，极易混淆导致严重质量事故。
- **关联标准/规程**: 《公路沥青路面施工技术规范》(JTG F40) - 实施前复核现行版本
- **建议页面控件**: 模式选择(油石比转沥青含量/沥青含量转油石比)，数值输入，换算结果。
- **是否适合自动计算**: 是

### 11. 沥青混合料 - 马歇尔稳定度
- **编号**: HW-AM-002

- **定义与适用场景**: 评价沥青混合料的抗车辙能力。

### 12. 沥青混合料 - 理论最大相对密度
- **编号**: HW-AM-003
- **二级分类**: 沥青混合料
- **名称**: 沥青混合料空隙率计算
- **定义与适用场景**: 评价压实沥青混合料的密实程度，控制路面渗水和耐久性。
- **公式或操作步骤**: $VV = \left(1 - \frac{\gamma_f}{\gamma_t}\right) \times 100\%$
- **全部变量与单位**: $VV$: 空隙率(%)；$\gamma_f$: 试件毛体积相对密度(无量纲)；$\gamma_t$: 混合料最大理论相对密度(无量纲)
- **完整数值示例**: 毛体积相对密度 $\gamma_f=2.385$，理论最大相对密度 $\gamma_t=2.490$。$VV = (1 - 2.385 / 2.490) \times 100\% = 4.2\%$。
- **结果解释**: 混合料空隙率为4.2%，满足规范3%-5%的要求。
- **注意事项与禁用边界**: 开级配混合料(OGFC)不适用此常规毛体积测定法（需用体积法）。
- **关联标准/规程**: 《公路工程沥青及沥青混合料试验规程》(JTG E20) - 实施前复核现行版本
- **建议页面控件**: 毛体积密度输入，理论最大密度输入，空隙率指示器。
- **是否适合自动计算**: 是

### 13. 水泥混凝土路面 - 弯拉强度计算
- **编号**: HW-CC-001
- **二级分类**: 水泥混凝土路面
- **名称**: 混凝土抗弯拉强度计算
- **定义与适用场景**: 水泥混凝土路面设计的控制指标，评价混凝土板的抗折断能力。
- **公式或操作步骤**: $f_c = \frac{P L}{b h^2}$
- **全部变量与单位**: $f_c$: 抗弯拉强度(MPa)；$P$: 破坏荷载(N)；$L$: 支座间距(mm)；$b$: 试件宽度(mm)；$h$: 试件高度(mm)
- **完整数值示例**: 标准试件150×150×550mm，支座间距 $L=450$mm。破坏荷载 $P=35000$N。$f_c = (35000 \times 450) / (150 \times 150^2) = 4.67$MPa。
- **结果解释**: 试件弯拉强度为4.67MPa。
- **注意事项与禁用边界**: 试件断裂面必须在三分点以内，否则该试件结果作废。
- **关联标准/规程**: 《公路工程水泥及水泥混凝土试验规程》(JTG 3420) - 实施前复核现行版本
- **建议页面控件**: 破坏荷载输入，试件尺寸选择，结果输出。
- **是否适合自动计算**: 是

### 14. 水泥混凝土路面 - 施工配合比调整
- **编号**: HW-CC-002
- **二级分类**: 水泥混凝土路面

- **完整数值示例**: 桩号K1+000填方断面面积 $A_1=50$m²，K1+020填方断面面积 $A_2=70$m²，间距 $L=20$m。$V = (50 + 70) / 2 \times 20 = 1200$m³。
- **结果解释**: 该20m路段的填方体积为1200立方米。
- **注意事项与禁用边界**: 当两断面面积相差超过一倍时，建议采用棱台体积公式计算更精确。
- **关联标准/规程**: 《公路工程标准施工招标文件》计量规则 - 实施前复核现行版本
- **建议页面控件**: 桩号及面积数据表格导入，间距自动计算，体积累计求和。
- **是否适合自动计算**: 是

## 实施前标准复核清单
在将上述公式与知识编入承包管理系统前，必须进行以下标准有效性与适用性复核：
1. **标准版本现行性复核**：公路工程规范更新较快（如JTG系列规范），系统上线前必须通过“交通运输部官网”或“全国标准信息公共服务平台”核对所有引用的规范编号是否为最新现行版本。
2. **强制性条文合规性**：确认公式中涉及的安全系数、预警阈值（如隧道沉降5mm/d）是否符合现行强制性工程建设规范（GB 55000系列）的要求。
3. **合同计价规则优先度**：计量模板中的扣减规则（如沥青面积扣减0.1m²阈值）为通用规则，实际系统必须支持根据具体项目的《公路工程标准施工招标文件》及合同专用条款进行参数自定义配置。
4. **配合比换算免责声明**：系统提供的施工配合比含水率换算工具，必须在界面醒目位置提示“本工具仅作计算辅助，实际生产配比必须由试验室签字确认，参考配比不得替代试配”。
