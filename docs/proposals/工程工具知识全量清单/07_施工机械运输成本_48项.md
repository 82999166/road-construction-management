### MACH-001 挖掘机土方开挖产能

**二级分类**：施工机械

**定义和适用场景**：计算单台挖掘机在特定土壤条件下的台班产量。适用于土方开挖工程进度计划。

**公式/步骤**：`Q = 8 * 3600 * q * K_c * K_t / t_c`

**全部变量单位**：Q: 台班产量(m³/台班); q: 斗容量(m³); K_c: 充盈系数(无量纲); K_t: 时间利用系数(无量纲); t_c: 循环时间(s)

**完整数值示例**：q=1.2, K_c=0.9, K_t=0.8, t_c=20。Q = 8 * 3600 * 1.2 * 0.9 * 0.8 / 20 = 1244.16

**结果解释**：单台挖掘机每台班可开挖1244.16立方米土方。

**注意事项与禁用边界**：需根据土壤级别调整充盈系数。挖掘机作业半径内严禁站人，系统仅计算不自动判定安全距离。

**关联标准/规程**：《建筑施工土石方工程安全技术规范》（实施前复核现行版本）

**建议页面控件**：数值输入框(q, K_c, K_t, t_c)

**自动计算适用性**：适用自动计算

### MACH-002 推土机推土生产率

**二级分类**：施工机械

**定义和适用场景**：计算推土机的台班生产率。适用于场地平整和短距离推土。

**公式/步骤**：`P = 8 * 60 * V * K_h * K_t / t_c`

**全部变量单位**：P: 台班产量(m³/台班); V: 铲刀容量(m³); K_h: 坡度系数(无量纲); K_t: 时间利用系数(无量纲); t_c: 循环时间(min)

**结果解释**：单台推土机每台班可推土489.6立方米。

**注意事项与禁用边界**：推土距离超过经济运距时效率骤降。严禁在大于规范限值的坡度上横向推土，系统仅计算不自动判定。

### MACH-005 汽车起重机支腿受力

**定义和适用场景**：计算汽车吊起重作业时支腿对地面的最大压力。适用于地基承载力复核。

**公式/步骤**：`F_max = (G + Q) / 2 + (M_o / L)`

**全部变量单位**：F_max: 最大支腿反力(kN); G: 起重机自重(kN); Q: 起重量(kN); M_o: 倾覆力矩(kN·m); L: 支腿跨距(m)

**结果解释**：最大支腿反力为215kN。

**注意事项与禁用边界**：地基承载力必须大于最大支腿反力。严禁在松软地面无垫板作业，系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。

**注意事项与禁用边界**：摊铺速度应保持恒定。严禁时快时慢导致平整度下降，系统仅计算不自动判定。

### MACH-047 履带起重机接地比压

**二级分类**：施工机械

**定义和适用场景**：计算履带吊作业时对地面的压强。适用于地基承载力复核。

**公式/步骤**：`P = (G + Q) / (2 * L * B)`

**全部变量单位**：P: 接地比压(kPa); G: 起重机自重(kN); Q: 起重量(kN); L: 履带接地长度(m); B: 履带宽度(m)

**完整数值示例**：G=500, Q=100, L=4, B=0.8。P = (500 + 100) / (2 * 4 * 0.8) = 600 / 6.4 = 93.75

**结果解释**：接地比压为93.75kPa。

**注意事项与禁用边界**：地基承载力必须大于接地比压。严禁在松软地面无垫板作业，系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。

**关联标准/规程**：《起重机械安全规程》（实施前复核现行版本）

**建议页面控件**：数值输入框(G, Q, L, B)

**自动计算适用性**：适用自动计算

### MACH-048 泥浆外运车次测算

**二级分类**：运输与车次

**定义和适用场景**：计算钻孔灌注桩施工泥浆外运总车次。

**公式/步骤**：`N_m = V_pile * K_e / V_tank`

**全部变量单位**：N_m: 车次; V_pile: 桩体积(m³); K_e: 扩孔及充盈系数; V_tank: 泥浆罐车容量(m³)

**完整数值示例**：V_pile=50, K_e=1.2, V_tank=10。N_m = 50 * 1.2 / 10 = 6

**结果解释**：需外运6车泥浆。

**注意事项与禁用边界**：泥浆必须外运至指定地点。严禁随意倾倒，系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。

**关联标准/规程**：《建筑桩基技术规范》（实施前复核现行版本）

**建议页面控件**：数值输入框(V_pile, K_e, V_tank)

**自动计算适用性**：适用自动计算
