### RW-01-01 路基填方土石方量计算
- **二级分类**：铁路路基
- **定义与适用场景**：计算两相邻横断面之间的填方或挖方体积，适用于铁路路基施工前的土石方量估算与计量。
- **公式或操作步骤**：V = (A1 + A2) / 2 × L
- **全部变量与单位**：V: 土石方体积 (m³); A1: 断面1面积 (m²); A2: 断面2面积 (m²); L: 两断面间距 (m)
- **完整数值示例**：A1 = 50 m², A2 = 70 m², L = 20 m. V = (50 + 70) / 2 × 20 = 1200 m³
- **结果解释**：两断面间的土石方体积为 1200 m³。
- **注意事项及禁用边界**：当相邻断面面积差大于50%时，建议采用棱台体积公式计算。严禁用于地形起伏剧烈的地段。系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。
- **关联标准/规程**：《铁路工程工程量计算规范》 (实施前复核现行版本)
- **建议页面控件**：数值输入框(A1, A2, L)，自动计算结果显示框
- **是否适合自动计算**：是

### RW-01-02 压实系数 (K) 计算
- **二级分类**：铁路路基
- **定义与适用场景**：评价路基填料压实程度的指标，适用于细粒土及粉砂、细砂等填料的压实质量控制。
- **公式或操作步骤**：K = ρd / ρdmax
- **全部变量与单位**：K: 压实系数 (无量纲); ρd: 填料的实际干密度 (g/cm³); ρdmax: 填料的最大干密度 (g/cm³)
- **完整数值示例**：实际干密度 ρd = 1.85 g/cm³, 最大干密度 ρdmax = 1.95 g/cm³. K = 1.85 / 1.95 ≈ 0.949
- **结果解释**：压实系数为 0.949，即94.9%。
- **注意事项及禁用边界**：最大干密度需通过标准击实试验确定。判定标准按设计/现行规范录入参数，系统仅计算不判定。
- **关联标准/规程**：《铁路路基工程施工质量验收标准》 (实施前复核现行版本)
- **建议页面控件**：数值输入框(ρd, ρdmax)，自动计算结果显示框
- **是否适合自动计算**：是

### RW-01-03 地基系数 (K30) 换算
- **二级分类**：铁路路基
- **定义与适用场景**：反映路基受力变形特性的指标，适用于粗粒土和碎石类土路基压实质量检测。
- **公式或操作步骤**：K30 = P / S
- **全部变量与单位**：K30: 地基系数 (MPa/m); P: 荷载强度 (MPa); S: 对应荷载下的沉降量 (m)
- **完整数值示例**：P = 0.125 MPa, 沉降量 S = 0.00125 m (1.25 mm). K30 = 0.125 / 0.00125 = 100 MPa/m
- **结果解释**：地基系数为 100 MPa/m。
- **注意事项及禁用边界**：测试板直径应为300mm。判定标准按设计/现行规范录入参数，系统仅计算不判定。

### RW-01-04 动态变形模量 (Evd) 记录
- **二级分类**：铁路路基
- **定义与适用场景**：用于快速评价路基填料在动荷载作用下的变形模量，适用于各类路基填筑质量控制。
- **公式或操作步骤**：Evd = 1.5 × r × (F / s)
- **全部变量与单位**：Evd: 动态变形模量 (MPa); r: 承载板半径 (mm); F: 最大动荷载 (MN); s: 承载板最大沉降幅值 (mm)
- **完整数值示例**：r = 150 mm, F = 0.00707 MN, s = 0.35 mm. Evd = 1.5 × 150 × (0.00707 / 0.35) = 45.45 MPa
- **结果解释**：动态变形模量为 45.45 MPa。
- **注意事项及禁用边界**：测试前应平整场地，确保承载板与地面紧密接触。判定标准按设计/现行规范录入参数，系统仅计算不判定。
- **关联标准/规程**：《铁路路基动态变形模量(Evd)测试规程》 (实施前复核现行版本)

### RW-01-05 静态变形模量 (Ev2) 计算
- **二级分类**：铁路路基
- **定义与适用场景**：通过两次加载试验计算的路基变形模量，用于评估路基承载力和压实质量。
- **公式或操作步骤**：Ev2 = 1.5 × r × (Δp / Δs)
- **全部变量与单位**：Ev2: 静态变形模量 (MPa); r: 承载板半径 (mm); Δp: 第二次加载压力差 (MPa); Δs: 对应的沉降差 (mm)
- **完整数值示例**：r = 150 mm, Δp = 0.2 MPa, Δs = 0.5 mm. Ev2 = 1.5 × 150 × (0.2 / 0.5) = 90 MPa
- **结果解释**：静态变形模量为 90 MPa。
- **注意事项及禁用边界**：测试耗时较长，通常与Evd配合使用。判定标准按设计/现行规范录入参数，系统仅计算不判定。

### RW-01-06 路基沉降观测数据整理
- **二级分类**：铁路路基
- **定义与适用场景**：对路基沉降观测数据进行汇总，计算累积沉降量和沉降速率，用于沉降评估。
- **公式或操作步骤**：ΔS = S_n - S_0, V = (S_n - S_{n-1}) / Δt
- **全部变量与单位**：ΔS: 累积沉降量 (mm); S_n: 本次高程 (mm); S_0: 初始高程 (mm); V: 沉降速率 (mm/d); S_{n-1}: 上次高程 (mm); Δt: 两次观测时间间隔 (d)
- **完整数值示例**：S_0 = 1000 mm, S_1 = 998 mm, S_2 = 995 mm, Δt = 5天。ΔS = 995 - 1000 = -5 mm。V = (995 - 998) / 5 = -0.6 mm/d
- **结果解释**：累积沉降量为 5 mm，当前沉降速率为 0.6 mm/d。
- **注意事项及禁用边界**：沉降预警阈值按设计/现行规范录入参数，系统仅计算不判定。严禁虚构观测数据。
- **关联标准/规程**：《铁路工程沉降变形观测与评估技术规程》 (实施前复核现行版本)
- **建议页面控件**：表格输入(日期, 观测标高)，折线图展示
- **是否适合自动计算**：是

### RW-02-01 道砟用量计算
- **二级分类**：有砟轨道
- **定义与适用场景**：计算新建或维修有砟轨道所需的道砟体积，适用于备料和工程量核算。
- **公式或操作步骤**：V = A × L × (1 + k)
- **全部变量与单位**：V: 道砟总体积 (m³); A: 道床标准断面面积 (m²); L: 线路长度 (m); k: 损耗及沉陷系数 (一般取0.05-0.1)
- **完整数值示例**：A = 3.2 m², L = 1000 m, k = 0.08. V = 3.2 × 1000 × (1 + 0.08) = 3456 m³
- **结果解释**：1公里线路需道砟 3456 m³。
- **注意事项及禁用边界**：不同等级铁路的断面面积不同，损耗系数按设计规定取值。系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。

### RW-02-02 轨枕数量计算
- **二级分类**：有砟轨道
- **定义与适用场景**：根据轨道铺设标准，计算一定长度线路所需的轨枕根数。
- **公式或操作步骤**：N = L × n / 1000
- **全部变量与单位**：N: 轨枕总根数 (根); L: 线路长度 (m); n: 每公里铺设轨枕根数 (根/km)

- **结果解释**：2.5公里线路需轨枕 4168 根。
- **注意事项及禁用边界**：结果应向上取整。曲线地段按外股长度计算。
- **关联标准/规程**：《铁路轨道工程施工质量验收标准》 (实施前复核现行版本)

### RW-03-05 轨道几何内部平顺性极差计算
- **二级分类**：无砟轨道
- **定义与适用场景**：评估无砟轨道在一定弦长范围内的几何尺寸最大波动量。
- **公式或操作步骤**：R = Max(V_i) - Min(V_i)
- **全部变量与单位**：R: 极差 (mm); V_i: 弦长范围内各测点的几何偏差值 (mm)
