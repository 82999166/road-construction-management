### M-001 混凝土施工配合比换算

| 审计维度 | 内容详情 |
| :--- | :--- |
| **唯一编号** | M-001 |
| **标题** | 混凝土施工配合比换算 |
| **公式或操作步骤** | 施工配合比计算公式：
水 = 试验室用水量 - 砂用量×砂含水率 - 石用量×石含水率
砂 = 试验室砂用量 × (1 + 砂含水率)
石 = 试验室石用量 × (1 + 石含水率)
水泥 = 试验室水泥用量 |
| **输入变量名称与单位** | 试验室用水量 (kg/m³)
试验室砂用量 (kg/m³)
试验室石用量 (kg/m³)
试验室水泥用量 (kg/m³)
砂含水率 (a, %)
石含水率 (b, %) |
| **示例输入** | 试验室配比：水泥300kg，水180kg，砂700kg，石1200kg。测得砂含水率4%，石含水率1%。
施工砂 = 700×(1+0.04) = 728kg
施工石 = 1200×(1+0.01) = 1212kg
施工水 = 180 - 700×0.04 - 1200×0.01 = 180 - 28 - 12 = 140kg |
| **预期输出** | 得出实际施工时每立方米混凝土各材料的准确称量值。 |
| **适用场景** | 根据现场砂石含水率，将试验室配合比换算为施工现场实际使用的配合比。注意：参考配比不得替代试配！ |
| **风险/专业复核边界** | 必须强调试验室配合比与施工配合比的含水率换算，参考配比绝对不能替代试配。雨天施工应增加含水率检测频率。系统仅计算/记录，不自动判定，需按设计和现行规范由专业人员复核。参考配比不得替代试验室试配。 |
| **浏览器确定性计算** | 是 |

| **公式或操作步骤** | f_cu = F / A |

| **风险/专业复核边界** | 非标准尺寸试件（如100mm或200mm）需乘以尺寸换算系数（0.95或1.05）。 |
