# 自有服务器部署盘点记录

> 记录时间：2026-08-22。该记录仅包含非敏感环境边界，不记录服务器地址、账号、密码、令牌或业务密钥。

## 当前宝塔服务器概览

目标服务器运行 CentOS 7.2 x86_64，宝塔 Linux 面板版本为 7.9.3，面板显示有 2 个 CPU 核心、约 3.6 GB 内存和约 118 GB 根分区容量；当前内存已使用约 2.5 GB、磁盘已使用约 33 GB。服务器已运行多个现有站点和多个数据库，因此悦信云智管不能复用任何既有网站根目录、数据库或默认站点配置。

## 已确认的隔离原则

| 边界 | 部署原则 |
| --- | --- |
| 站点 | 使用新的预发布子域名，独立 Nginx 站点，不修改 `yx.maomaoyx.com` 当前解析与托管站点。 |
| 目录 | 使用独立应用目录，例如 `/www/wwwroot/yx-staging`，不得进入或复用已有站点目录。 |
| 运行时 | 使用独立 Node.js 项目、独立 PM2 名称和未占用本机端口。 |
| 数据库 | 创建独立 MySQL 数据库与最小权限账号；不使用既有 11 个数据库。 |
| 文件 | 附件使用独立的 S3 兼容对象存储桶及访问凭据，不以服务器目录替代对象存储。 |
| 切换 | 先在预发布域名完成端到端验收、备份恢复和回滚演练，再决定是否切换正式域名。 |

## 已发现的前置风险

当前系统使用的托管 OAuth、数据库、对象存储与内部服务密钥不能直接复制到自有服务器。自建版必须逐项替换认证、数据库访问、文件存储、环境密钥、定时任务和健康检查；在这些依赖可用前，只能建设预发布基础环境，不能对外宣称已完成可用生产迁移。

## 宝塔面板进一步核验

宝塔网站页当前列出了 6 个既有 PHP/静态站点，其中包含正在运行的站点及停用的历史站点。宝塔 Node 项目页显示当前没有已登记的 Node 项目，因此可以创建名称、端口和根目录均独立的 Node 服务。数据库页尚未完成加载，后续必须先确认已安装的 MySQL/MariaDB 版本、账户权限和可用容量，才可创建独立业务数据库。

## 终端核验结果与部署结论

服务器终端确认未发现 `/root/AGENTS.md` 或 `/AGENTS.md`，因此不存在额外项目操作指令。服务器系统为 CentOS 7，MySQL 8.0.24、Nginx 1.21.4 与 Docker 20.10.21 已安装并运行；没有可用的 Node.js 运行时。MySQL 已监听本机数据库端口，Docker 已运行，当前也有 Java、MongoDB、Redis、Memcached、Nginx 等既有服务占用资源与端口。

服务器内存总量约 3.5 GB，当前可用内存仅约 0.9 GB，且未配置交换分区；根分区可用空间约 84 GB。由于 CentOS 7 已结束维护、Node.js 尚未安装且可用内存不足以安全增加新的 Node 服务与独立数据库，当前不能直接开始应用部署。若强行部署，可能影响服务器既有站点和数据库。

推荐先将服务器升级或迁移至受支持系统（Ubuntu 22.04/24.04、Debian 12 或 AlmaLinux 9）并将内存提升至至少 8 GB；如必须在当前服务器继续，最低也应先将内存扩容至 4 GB 以上、配置交换分区、确认完整数据库备份，并使用现有 MySQL 创建独立数据库而不再运行额外数据库容器。
