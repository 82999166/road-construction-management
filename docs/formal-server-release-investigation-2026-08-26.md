# 正式服务器发布链路排查记录

截至 2026-08-26，正式域名的 HTTPS 请求可到达用户确认的新服务器，但该主机的 Nginx 生效配置未发现该正式域名的显式 `server_name` 站点块。直接使用正式域名 Host 访问新服务器时，仍返回悦信云智管的旧前端内容，说明需要继续定位默认 HTTPS 虚拟主机或额外反向代理规则。

新服务器上发现一个持续运行的 Node 应用实例，其工作目录为用户 GitHub 连接对应的项目目录，监听本机业务端口。该端口对 `/admin` 的响应指纹与正式域名响应指纹不同，因此不能直接把该目录当成正式域名当前流量的唯一来源并覆盖发布。

后续发布前必须先完成以下只读核验：确认正式域名请求命中的 Nginx HTTPS server 块、其静态根目录或 `proxy_pass` 后端；确认实际运行服务的工作目录、运行账户与健康检查方式；仅在确认目标后按 release/current 原子切换并保留旧前端分包。本文不记录服务器地址、登录凭据、密钥、数据库连接信息或业务数据。
