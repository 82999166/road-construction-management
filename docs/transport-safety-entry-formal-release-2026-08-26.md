# 运输安全入口正式服务器发布记录

本次将“运输闭环与安全阈值”固定展示于超级管理员 PC 后台“运输管理 → 线路配置”卡片内的修复，同步到用户确认的悦信云智管正式主机。发布仅更新应用文件；未执行数据库迁移、未修改业务数据、未更换服务器、未处理无关项目。

发布采用新 release 目录解包、校验构建产物、保留上一发布包的历史前端分包、原子切换 `current` 指针、重启应用服务的顺序。若服务重启失败，脚本会将 `current` 恢复到上一个 release 后再次启动服务。

| 核验项目 | 结果 |
|---|---|
| 修复发布包 | 已完成自建服务器构建，并在上传前完成 SHA-256 校验。 |
| 前端入口内容 | 已在新发布包分包中检出“仅限超级管理员维护”标记。 |
| 原子切换 | 已从上一稳定 release 原子切换至本次运输安全入口修复 release。 |
| 应用服务 | `yx-cloud-management` 重启后处于 active 状态。 |
| 本机后台路由 | 后台路由返回 HTTP 200 和 HTML 内容类型。 |
| 正式 HTTPS 域名 | 首页与后台路由响应头均返回 HTTP 200。 |
| 数据库 | 未迁移、未写入、未恢复、未更换连接。 |

用户在服务器控制台明确授权永久允许 root 使用密码 SSH 登录，并已完成该策略配置，之后的发布访问按该策略执行。文档不包含服务器地址、账号、密码、密钥、连接串或数据库名称。
