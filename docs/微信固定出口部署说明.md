# 微信服务号固定出口部署说明

## 目标

本网关将道路施工承包管理系统对 `api.weixin.qq.com` 的服务端请求固定从单一公网 IP 发出，避免托管运行环境弹性伸缩导致微信 API IP 白名单频繁变化。它**不**替代网页授权域名，也不构成通用 HTTP 代理。

## 安全边界

网关只接受带 HMAC-SHA256 签名且五分钟内有效的请求，并严格限制微信 API 路径。它不记录 access_token、OpenID、消息正文、签名或 AppSecret；运行日志仅保留上游状态码。网关通过 HTTPS 对外提供服务，而 Node 进程仅监听本机回环地址。

| 项目 | 配置要求 |
|---|---|
| 微信 API IP 白名单 | 仅添加固定出口服务器的公网 IP |
| 网关域名 | 使用独立 A 记录，例如 `wechat-egress.yx.maomaoyx.com` |
| TLS | 由反向代理自动签发并续期证书 |
| 系统设置 | 发布“微信 API 固定出口网关地址”和加密的“固定出口网关签名密钥” |
| 失败策略 | 网关配置未成对发布时，系统安全降级为原有直连；配置成对发布后，签名失败或网关异常会被审计为投递失败而不回退主业务 |

## 上线顺序

先确认 DNS A 记录已从公共网络解析到固定出口服务器，再开通 HTTPS、部署服务和添加网关签名密钥。最后在系统后台发布两个固定出口配置项，并先进行单收件人受控测试；确认微信模板可下发后再执行群发和每日项目汇总验收。
