# 移动采购仓储用户专属权限项目范围修复

移动采购仓储页会读取 `purchasing.projectOptions`。此前路由仅接受采购、仓储、后勤、财务或项目管理岗位角色，即使后台已给用户配置“采购仓储读取”专属操作权限，也会被路由拒绝，无法得到已授权项目。

现已将采购访问断言与机械模块保持一致：除既有岗位角色外，拥有 `PURCHASING/read` 用户专属操作权限的人员可以读取其既有项目范围。该修复仅放开“进入受控项目列表”的读取前置，不授予审批、库存管理、结算或跨项目权限；各写入接口继续校验具体操作权限、项目范围和业务状态机。

移动端此前已增加项目范围查询失败与真实无授权的区分，并支持重新获取授权项目。本次修复发布后，使用后台已配置采购读取权限且已有项目范围的后勤人员应能看到相应项目；若仍无法加载，页面会显示请求失败而不是错误提示“暂无授权项目”。
